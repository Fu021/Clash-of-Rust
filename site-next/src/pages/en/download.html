Windows

x64 and ARM64

    Run the installer and follow the prompts. Upgrading over an older version keeps your subscriptions and settings.

    If Windows Defender raises an alert, check the SHA256 first, then read the alert notes. An alert you cannot explain is not a false positive until it has been checked.

    Debian / Ubuntu

    Ubuntu 20.04 or later

      In the folder where you saved the file, run sudo apt install ./the-file-name.deb. The cor command is on your PATH afterwards.

      Not sure which architecture you have? dpkg --print-architecture prints it.

      macOS

      macOS 14 or later

        Open the DMG and drag Clash of Rust into Applications, then start it from there.

        The app is not notarized by Apple, so macOS stops it the first time. Allow it under Privacy & Security as Apple describes.

        Android

        Android 8.0 or later

          Most phones and tablets take the ARM64 package. Android will ask you to let your browser or file manager install apps. On the first connection, allow the VPN request.

          You can add a quick-settings tile for the switch. Giving individual apps their own exit needs Android 10 or later.

          Check the file before you install it

          Each installer has a .sha256 file beside it holding one hash. Compute the hash of what you downloaded and compare the two. Install only if they match.

          # Windows PowerShell
Get-FileHash .\the-file-name.exe -Algorithm SHA256

# Linux
sha256sum the-file-name.deb

# macOS
shasum -a 256 the-file-name.dmg

          The app does the same check on its own before it installs an update.

          After installing

          Add a subscription, pick a node, choose a mode and connect. The guide walks through it in five steps, and the same thing takes five commands with cor.

          Questions people ask

          Stable or preview?

          Stable is for everyday use. Preview carries newer features first, at the moment the network toolbox and the terminal interface, and has been through a narrower round of validation. Back up your configuration before you try it. The desktop app can switch back to stable from inside the app.

          Is there an iOS version?

          No. The repository has an interface prototype for iOS and nothing you can install.

          What about other Linux distributions?

          Only DEB packages are published, and they are validated on Debian and on Ubuntu 20.04 and later. On other distributions you would need to build from source; see the developer docs in the repository.

          Does the Linux package work without a desktop?

          Yes. The DEB includes cor, which needs no display. Run cor start, and use TUN on a server.

          Will an update lose my settings?

          No. Upgrades keep subscriptions and personal settings. The Windows uninstaller can delete all data if you ask it to; that option is off by default.
