桌面安装包附带 cor。在服务器上、SSH 里，也能管理同一个后台。

$ cor profile add home 'https://example.com/subscription'
$ cor profile use home
$ cor start            # 在后台运行
$ cor node select      # 选择策略组和节点
$ cor status
