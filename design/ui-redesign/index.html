设计要点（v1.3）

黄金比例（v1.3）

  • 字号按 14·φ^(n/4) 取整：11 / 12 / 14 / 16 / 18 / 20 / 23 / 26 / 29 / 32。相邻两级约 ×1.128，每四级正好 ×φ（如 14 → 23）。
  • 间距按 8·φ^(n/2)：3 / 5 / 8 / 10 / 13 / 16 / 21 / 27 / 34 / 43 / 55，主干就是斐波那契数列。
  • 控件高 27 / 34 / 43 / 55；开关 34×21（比值即 φ）；圆角 5 / 8 / 13 / 16。
  • 侧栏从 216 收窄到 180：默认 950 窗口下侧栏与主区约为 1 : φ³；收起后的图标栏 55。
  • 首页在窗口 ≥ 1100 时分两栏，左右宽度比为 φ : 1；流量图高度取宽度 / φ³，限制在 89–144。

对应 issue #33（空间利用率）

  • 订阅页改为卡片网格，950 窗口一行两个，更宽时一行三个；不再一行一个。
  • 代理页节点卡最小宽 168、高 55，950 窗口一行四个；测速直接点延迟数字，不另占按钮。
  • 首页连接卡加了“我的订阅”入口，节点名可直接点开切换：经常换节点、换订阅的人少走一步。
  • 订阅里的国旗 emoji 用 Twemoji 图片绘制（Windows 系统没有国旗字形，原来会显示成 DE、GB）；图片加载失败时退回两字母代码。
  • 订阅卡补了更新失败状态：写明原因，并说明仍在使用上次的配置。

视觉语言

  • 中性色改为不偏暖的灰：侧栏 #f0f2f2、画布 #f8f9f9、卡片白；深色 #17191a / #1d2022 / #24282a。
  • 默认强调色恢复软件原有的青绿 #0f766e，可选色与 palette.slint 的 6 色同序（青绿、蓝、紫、玫红、琥珀、石墨）。
  • 状态色不随强调色变化；成功色偏黄绿 #3a7a2c，与青绿分开。
  • 次要文字加深到 #646b6f，小字对比度达到 4.5:1。

按 impeccable 去掉的痕迹

  • 米色底加陶土色：这是 Claude 自己的配色，用在别的产品上就像套壳。
  • 连接卡背后的强调色光晕、电源键外圈、状态点的脉冲动画与外圈。
  • 每张卡片的大范围柔和阴影；卡片只留 1px 细线，阴影只给浮层。
  • 节点名上方的小字眉标；状态并入名字下面那一行。
  • 四格数字加迷你折线的模板，改为一张有坐标的流量图。
  • 卡中卡：代理节点改为无描边的平铺按钮。
  • 页面切换的淡入位移、按钮高光、字标里单独着色的“of”（现在只靠笔画粗细区分）。
  • 元信息里的间隔点，改为间距分组或完整句子；订阅里的节点原名照常显示。
  • 12.5、13.5 这类半号字号，统一收到整数字号。
  • 补上文字选中色、输入光标色和细滚动条，跟随强调色。

布局

  • 主区是浮在侧栏之上的圆角画布（左上 12px），页头 55px，只放标题与本页操作。
  • 侧栏顶部是连接入口（电源键 + 当前代理方式），底部只保留设置与版本号。
  • 说明文字收进悬停提示（带虚线下划线的标题可悬停查看）；状态数据照常显示。
  • 窗口宽度低于 880px 时侧栏自动收为图标栏，也可手动收起；请切换到 800×450 查看。

首页

  • 节点名是卡内唯一的大字，点击即切换节点；下面一行依次是状态与时长、协议、代理组、延迟。
  • 运行模式（规则 / 全局 / 直连）× 代理方式（系统代理 / TUN / 关闭）。系统代理与 TUN 互斥；电源键在“关闭”和上次选择的方式之间切换。
  • 流量图：下载与上传共用一条纵轴，图例带当前速度；悬停可读任意一秒的数值。

手机与平板

  • 手机沿用现有 5 个底部入口（首页 / 代理 / 订阅 / 工具 / 设置）；Android 用胶囊指示，iOS 用强调色着色。
  • 平板横屏显示完整侧栏，与桌面一致；详情在宽度 ≥ 880px 时常驻右侧。
  • 触控行高不低于 48px，正文 15–16px；VPN 开关就是连接卡上的电源键。

交互状态（可点击）

  • 切换节点、全部测速、展开/折叠代理组、打开连接详情侧板、删除订阅确认框、流量图悬停。
  • 在规则页关闭任一规则后，底部会浮出“未应用修改”条；日志可按级别筛选。
  • 设置页的主题和强调色与顶部审阅工具条联动。

落到 Slint 时

  • 只用纯色、细线和圆角；阴影只用于浮层，不用模糊或毛玻璃，软件渲染器可承受。
  • 令牌替换 theme/palette.slint：中性色改为冷灰，新增 raised、hover/press 透明层与 4 级圆角；强调色沿用现有 6 色。
  • 标志用 Image.colorize 跟随强调色；字标是 SVG 路径，可直接作为图片。
  • 非 Windows 平台若缺 Segoe UI Variable，建议随包附带 Noto Sans SC（OFL 许可）。
  • 国旗图片随包附带 Twemoji 的 SVG（图形 CC-BY 4.0，需署名），不要依赖系统 emoji 字体。

待确认

  • 行内图标按钮和导航项的可见高度为 28–36px，低于现规范的 40px 控件高度（点击区可补足）。
  • 一体式标题栏需要无边框窗口，并自绘拖动区和窗口按钮。
  • 平板竖屏（640–1023px，图标栏）本稿未画，沿用现有 76px 图标栏即可。
