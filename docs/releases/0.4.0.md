# Clash of Rust 0.4.0 — 开发预览版

**本版本仍然是开发预览版，不保证任何功能。** 功能完整性、稳定性及不同环境下的兼容性均不作保证，仅供开发和测试。

## 本次变更

- 保存运行模式（规则 / 全局 / 直连）与代理模式（系统代理 / TUN / 关闭），下次启动自动恢复。
- 正常退出仍恢复系统代理并关闭 TUN，清理不会覆盖已保存的模式选择。
- 恢复 TUN 时使用现有 Windows UAC 提权流程；取消或失败会显示错误并保留选择。
- 修复提权交接时重复启动内核的问题。
- 修复新版 Clippy 在 Windows CI 中报告的检查问题。

## 下载

- `Clash-of-Rust-0.4.0-windows-x64-setup.exe`：Windows x64 安装包，包含 mihomo v1.19.32、GeoIP / GeoSite / Country / ASN 数据及默认配置，启动无需下载这些资源。
- 同名 `.sha256`：安装包 SHA-256 校验值。

目前发布 Windows 版本。Linux 适配尚未完成，本次没有 Linux 安装包。

## 验证边界

Windows 静态检查、自动测试和安装包资源检查通过；真实 GUI、系统代理、TUN/UAC 以及安装/升级行为仍需实际环境复测。
