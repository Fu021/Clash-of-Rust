# Clash of Rust 0.5.10

适用于 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上），以及 macOS 14 及以上的 Intel / Apple Silicon；升级保留订阅和个人设置。

## 更新内容

- 修复 macOS 开启 Claude 保护后，Safari 等使用系统解析器的应用仍可能通过局域网 DNS 解析公网域名的问题。保护期间临时接管系统 DNS，经 TUN 送入保护节点的加密 DNS。
- 保存原有 DHCP／静态 DNS 设置；关闭保护、退出或客户端异常结束时恢复，重启客户端后重新接管。局域网名称继续使用接管前的解析服务器，避免解析回环，并保留其他程序后来修改的 DNS 设置。
- 修复 macOS 登录自启后进行更新时，旧应用退出可能连带结束安装助手的问题。安装助手与重启后的客户端使用独立进程组。
- macOS Intel 与 Apple Silicon 的[原生专项验证](https://github.com/Fu021/Clash-of-Rust/actions/runs/38701348475)均通过，覆盖真实登录任务退出、系统解析经过保护节点的 DoH，以及重启、关闭和异常退出后的 DNS 恢复。

**macOS 升级说明**：旧版发起更新时仍执行旧版安装助手，这项更新交接修复在安装 0.5.10 后发起的后续更新中生效。若升级后仍显示旧版，可下载本页 DMG 覆盖安装。网络助手新增 DNS 接管能力，旧助手首次更新时需完成一次管理员授权，之后继续复用。

## 下载与安装

每个安装包附带 `.sha256` 校验文件。

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | [Clash-of-Rust-0.5.10-windows-x64-setup.exe](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.10/Clash-of-Rust-0.5.10-windows-x64-setup.exe) |
| Windows ARM64 | [Clash-of-Rust-0.5.10-windows-arm64-setup.exe](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.10/Clash-of-Rust-0.5.10-windows-arm64-setup.exe) |
| Debian / Ubuntu 22.04+ amd64 | [Clash-of-Rust-0.5.10-linux-amd64.deb](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.10/Clash-of-Rust-0.5.10-linux-amd64.deb) |
| Debian / Ubuntu 22.04+ ARM64 | [Clash-of-Rust-0.5.10-linux-arm64.deb](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.10/Clash-of-Rust-0.5.10-linux-arm64.deb) |
| macOS Intel | [Clash-of-Rust-0.5.10-macos-x64.dmg](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.10/Clash-of-Rust-0.5.10-macos-x64.dmg) |
| macOS Apple Silicon | [Clash-of-Rust-0.5.10-macos-arm64.dmg](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.10/Clash-of-Rust-0.5.10-macos-arm64.dmg) |

Windows 双击安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。

macOS 安装包使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。首次打开若提示无法验证开发者，可确认来源及校验值后，在“系统设置 → 隐私与安全性”中选择“仍要打开”，见 [Apple 说明](https://support.apple.com/zh-cn/102445)。
