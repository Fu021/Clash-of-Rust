# Clash of Rust 0.6.5

本次更新修复断网启动后代理无法随联网恢复的问题，完善 macOS 与 Tailscale 的 DNS 共存，并统一桌面与 Android 的规则拖动、订阅管理和下载恢复。支持 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上）、macOS 14 及以上的 Intel / Apple Silicon，以及 Android 8.0 及以上的 ARM64 / ARMv7 / x86_64。

## 更新内容

### 网络恢复与系统代理

- 修复 Windows 在无网络时启动、联网后代理目标仍持续 `unreach` 的问题；桌面后台在默认路由恢复或变化稳定后刷新内核出站与 DNS，并清理旧连接。Windows、Linux、macOS 的 GUI 与 `cor` 共用恢复机制，保留当前节点、运行模式、TUN、Claude 保护与订阅配置。
- 修复系统代理已经开启、窗口却显示关闭的状态不同步问题。后台按实际托管的代理字段判断状态，窗口重建与 `cor` 查询保持一致。
- macOS、Windows、GNOME 和 KDE 恢复系统代理时保留用户后来修改的绕过项；macOS 同时保留新增网络服务与非托管属性。

### Claude 保护与 DNS 检测

- macOS 开启 Claude 保护时，公网 DNS 通过本机转发器进入保护线路，保留 Tailscale 私有分域、搜索域与接口绑定，无需用户手动调整 DNS。
- 保护就绪检查等待系统原生解析器实际接管，并处理 Tailscale 重连与 DNS 配置变化；公网解析失败时不回退到 VPN 或物理网络 DNS，关闭保护后恢复仍由客户端管理的设置。
- 开启保护后先中断已有内核连接，再验证加密 DNS；失败时恢复原网络配置。桌面、Android 与 `cor` 使用相同的切换语义。
- 保护期间，代理模式、规则页与相关网络设置灰置并禁止修改，保留尚未应用的规则草稿；关闭保护后恢复操作。Android 保留保护失败快照，并将实时保护异常列为风险。
- 修正 Google 递归 DNS 地址的国家误报：匹配官方地理清单并保留原始标签与来源；修正后仍与出口国家不同的继续列为风险，不隐藏地区差异。无法确认的结果单独标注。
- 桌面与 Android 的实际递归 DNS 国家复用 IP 检测国旗素材；港澳台保留文字，不显示旗帜。调整检测卡片布局，避免保护框顶部被遮挡。

### 订阅、Geo 与客户端更新

- 新增远程订阅定时更新，默认间隔 360 分钟，可在设置或 `cor config` 调整，设为 0 时关闭；Claude 保护期间跳过当前受保护订阅。
- 订阅更新失败时保留原订阅、规则和运行状态。Android 可确认删除正在使用的订阅并自动切换到默认直连；添加与编辑期间显示保存状态，避免重复点击产生同名错误。
- Geo、订阅与客户端更新下载增加慢速及断流检测，优先尝试内核代理，再按条件回退直连；不自动切换用户节点，支持取消并清理未完成下载。
- Geo 更新校验整组新文件后再安装，失败恢复旧数据；修复旧文件损坏、缺失或与旧清单不符时阻塞更新的问题，并在冷启动时恢复未完成事务。
- 关闭“包含预发布版本”时始终跟随最新正式版，即使本地版本号更高；开启后才比较正式版与预发布版。Android 安装预发布版前以红字提醒：无法保证保留数据地返回正式版。

### 规则与移动界面

- 桌面与 Android 规则页统一支持拖动排序，浮起规则跟随鼠标或手指，靠近列表上下边缘连续滚动；保留原位占位和目标反馈，取消、筛选或布局变化时安全结束手势。
- 规则详情显示完整原文、来源和策略，支持编辑、启停、删除、跨页移动及恢复订阅顺序。Android 补齐规则表单与重复规则、数量和位置校验，失败时保留草稿。
- 修复 Android 连接、规则、日志页多条数据重叠成一条的问题；压缩分页与保存操作区域，调整长文本、横屏 Pad 和键盘展开时的布局，让列表与搜索结果保持可见。
- 规则页顶部操作随列表滚动，搜索框在条数、布局或键盘高度变化时保留输入焦点；设置独立于工具入口，Pad 的工具导航与手机保持一致。
- Fake-IP 排除项同时显示自定义与 DNS 覆盖来源，支持还原已移除的内置项；Android 将其放在 Fake-IP 开关下方，并补齐 IP 检测筛选、详情、单项重测与更新操作。
- 桌面进入代理页时，将实际使用的策略组置顶并展开；手动收起后，后台刷新不会反复打开。

### CLI、用户隔离与发布验证

- Linux 普通用户各自保留订阅和后台；`sudo cor` 复用调用者的数据与后台，root 可只读查看普通用户订阅索引，或通过 `--user` 显式选择账户。跨用户执行过滤管理员环境，避免传递凭据。
- 修复 Linux 命令行 TUN 授权入口，SSH 或非活动会话仍需正常管理员认证；无图形服务时使用 `cor`，直接启动桌面程序会给出对应提示。
- 补充 CLI 预发布更新与用户目录文档，GUI 与 CLI 的订阅定时更新、保护和更新通道使用共享业务逻辑。
- 更新依赖与平台接口，替换停止维护的 YAML 和序列化实现。Windows 打包增加安装包及未压缩 EXE/DLL 的 Defender 扫描，版本与逐文件校验信息写入打包收据。

Windows 运行安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。Linux Server 安装同一份 DEB 后，可在 SSH 中直接使用 `cor`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。桌面升级保留订阅和个人设置。

Android 安装对应架构的 APK，首次连接允许 VPN 授权；可在系统快捷设置中添加开关磁贴。在线更新由系统确认安装，使用长期发行签名；系统仍会拒绝覆盖签名不同或版本代码更低的安装包。

macOS 网络助手升级后首次启用可能需要管理员授权；当前安装包使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。DNS 国家是地区风险线索，不能单独证明泄漏或 Claude 服务资格；真实 Tailscale 网络变化、休眠恢复及设备交互仍需结合现场验收。
