# 0.7.3-dev.2.live-language

## 更新

- 桌面、Android、TUI 和 CLI 已加入中英文语言选项及主要界面翻译，默认跟随系统语言；在设置中切换后立即生效，TUI 首页也可调整语言。
- Claude 保护和 IP 检测报告按主题分组，合并相近项目，展示检测服务的分流出口和多源 IP 属性。
- 新增 Arch Linux x86_64 原生包，支持通过 pacman 安装及应用内更新；提供 Linux x64 RPM 包。
- TUI 首页可切换代理方式和订阅、启停内核及检查更新；桌面代理组和订阅列表可切换全量显示与分页。
- 修复跨页面滚动卡住、窗口最小化响应延迟及自动检查更新未恢复的问题。

## 验证与已知问题

- 发布前执行同提交 CI、Android 与 Linux 兼容验收及安装包校验；实际结果以 Actions 和发布收据为准。
- 订阅用量和到期时间、网络诊断返回信息、日志及部分警告尚未完全翻译。Android 真机交互及 Arch 跨版本应用内更新仍待实测。
- Fedora 和 openSUSE 的应用内更新目前提示使用系统包管理器。Linux 压力场景下，多次退出 TUI 后的后台内存可能高于纯 CLI。
- 使用应用内更新检查本预发布时，需在设置中开启“包含预发布版本”。

## Updates

- Desktop, Android, TUI, and CLI now offer Simplified Chinese and English, with translations for the main interface and the system language as the default. Language changes apply immediately, and the TUI home page also offers a language setting.
- Claude protection and IP detection reports are grouped by topic, combine related items, and show service routing exits and IP attributes from multiple sources.
- An Arch Linux x86_64 native package is available, with installation through pacman and in-app updates. A Linux x64 RPM package is also available.
- The TUI home page can switch proxy modes and profiles, start or stop the core, and check for updates. Desktop proxy groups and profile lists can show all entries or use pagination.
- Fixed scrolling getting stuck after switching pages, delayed window minimization, and automatic update checks not resuming.

## Verification and known issues

- Same-commit CI, Android and Linux compatibility checks, and package verification are run before release. See Actions and the release receipt for the actual results.
- Subscription usage and expiration dates, network diagnostic responses, logs, and some warnings are not fully translated yet. Android device interactions and Arch in-app updates across versions still need testing.
- In-app updates on Fedora and openSUSE currently direct users to the system package manager. Under Linux stress workloads, backend memory after repeated TUI sessions may remain higher than with CLI alone.
- To find this prerelease through the in-app updater, enable “Include prereleases” in settings.
