# 0.7.1-fix.3.autostart-app-rules

## 更新

- 修复 Linux 旧自启动入口未迁移时仍打开窗口的问题，保留托盘异常提示和启动诊断。
- Android 应用出口支持命名规则组、搜索选应用，以及指定节点、策略组、直连或拦截；目标消失时默认拦截并通知。Android 8、9 继续支持范围分流，暂不支持指定出口。
- 改进 Claude 保护的状态提示，外观设置与只读操作保持可用，网络修改继续锁定。

## 验证与已知问题

- 发布前核对同提交 CI、Android 8.0～16 和 Ubuntu 20.04 两种架构的兼容结果。
- 已在隔离 COSMIC Wayland 环境验证旧入口迁移、下次登录隐藏窗口及手动打开复用后台；真实用户桌面配置仍需反馈确认。
- Linux 快速缩放、长期网络切换及间歇 TLS 失败仍有未验证或未定位的情况。
