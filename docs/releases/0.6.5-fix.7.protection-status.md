# 0.6.5-fix.7.protection-status

本版本承接 `0.6.5-fix.6.tailscale-dns`，继续保留此前的 DNS 国家修正、Tailscale 共存及规则拖动改进。

- Android 的实时保护错误与桌面统一列入风险，避免混入“其他线索”。
- 原生保护线程停止时，Android 仍读取失败快照，保留可用于排查的错误与拦截记录；普通关闭不会用空快照覆盖历史。
- 控制接口恢复后清除暂时的不可用提示，避免恢复成功仍显示旧告警。短暂断连与恢复不会覆盖已有通知失败、拦截失败或异常连接历史。
- 精简 Agent 指令与最近复盘，将工作流、CLI、Claude 保护及平台排障拆为按需查阅的主题文档，并同步入口和旧章节链接。

本轮默认仅进行 Actions 验证和不发布打包，公开预发布需另行确认。实机、真实 Tailscale 网络及实际下载吞吐仍需现场验收。
