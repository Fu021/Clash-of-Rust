# Clash of Rust 0.6.1

本次更新统一桌面与 Android 的交互动效，并让 Claude 保护支持全局模式。继续支持 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上）、macOS 14 及以上的 Intel / Apple Silicon，以及 Android 8.0 及以上的 ARM64 / ARMv7 / x86_64。

## 更新内容

### 界面与交互

- 为按钮、开关、导航、页面切换、策略组展开与节点选择加入统一过渡，弹窗、通知、检测详情和任务进度同步调整；主题与强调色切换更平滑。
- 复制成功后显示短暂反馈，以系统剪贴板写入结果为准；Geo 更新等进度仅在对应任务进行时显示。
- 修复 Android 使用自选强调色后，打开界面先显示默认绿色的问题，首帧直接采用保存的外观设置。
- 策略组折叠立即保存状态，切走页面后仍然生效。页面继续按需创建，退出动画结束后释放内容，空闲时停止动效时钟；连接与日志列表保持实时更新，不逐条播放入场动画。

### Claude 保护

- 支持在规则或全局模式下开启，保护期间锁定当前运行模式及具体节点；直连模式开启时沿用规则模式。
- 全局模式开启前检查实际出口，包含嵌套策略组；最终为 DIRECT 时拒绝开启，避免误用直连。
- 全局出口临时固定到保护节点，重启后继续生效；关闭保护恢复原运行模式、节点选择与自动策略组设置，保留原订阅配置。
- 检测按当前锁定的运行模式核验，避免将正常的全局保护误报为模式异常。

### 验证与内存

- 补充动效生命周期、空闲刷新、复制反馈、快速排序与策略组节点释放测试；全局保护测试覆盖嵌套直连拒绝、模式锁定、冷启动及关闭后的配置恢复。
- 完成 [0.6.1 低强度内存基准](https://github.com/Fu021/Clash-of-Rust/actions/runs/39566842514)：100 节点、5 个策略组、1,000 条规则，首页 GUI RSS 44.63 MiB、GUI 与内核合计 PSS 82.99 MiB；节点搜索时分别为 54.71 MiB 和 99.47 MiB。实验条件及其他场景见 [README](../../README.md#内存占用)。

Windows 运行安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。桌面升级保留订阅和个人设置。

Android 安装对应架构的 APK，首次连接时允许 VPN 授权。可在快捷设置中添加 Clash of Rust 磁贴；在线更新需要允许本应用安装更新包，由系统确认安装。后台使用可结合系统 VPN 与电池设置调整，强行停止应用会断开连接。
