# 0.6.7-fix.10.memory-projection

## 更新

- 减少桌面界面刷新时重复构造列表和文字，保留滚动位置、节点选择及折叠动效。
- 页面切换与节点收起后回收已空闲的内存，减少浏览大量节点后的闲置占用。
- 首页服务探测共享 HTTP 客户端，桌面与 Android 同步减少重复初始化。
- 控制接口 JSON 分块直接复用接收缓冲，保留大小限制、取消和错误校验。
- Android 编译与 APK 打包使用同一套指定的 NDK。

## 验证与已知问题

- 发布前核对同提交 CI、安装包和内存基准；实际内存变化见[内存记录](../workflows/memory.md)。
- 真机、厂商 ROM、长期 TUN 及公网间歇超时仍未验收或定位。
