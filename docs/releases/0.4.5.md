# Clash of Rust 0.4.5

本版将地区检测与 Linux 桌面集成迁移到原生 Rust，整理构建工具与项目目录，并提供 Windows EXE 和 Debian/Ubuntu DEB 安装程序。

## 更新内容

- 183 个 IP 与地区检测项由 Rust 直接请求和解析，其中 181 项保留 RegionRestrictionCheck 的上游检测逻辑；移除安装包中的 Bash、MSYS、curl、jq 和相关动态库。
- 资源准备、打包和安装器测试改为 Python 开发工具。应用运行无需 PowerShell、Python 或 Bash。
- Linux 系统代理使用原生 GNOME GSettings 与 KDE 配置/D-Bus；链接与目录通过 GIO 打开。
- 修复 WSLg 启动时出现 `Io error: Broken pipe` 后退出的问题：WSL 中自动使用 X11/XWayland。
- 检查实际托盘宿主；没有可用托盘时关闭窗口会退出，后台启动也会显示窗口，避免程序隐藏后无法操作。
- Windows/WSL 构建流程统一。WSL 将源码与资源同步到 Linux 文件系统编译，仅复制最终 DEB 与校验文件回 Windows。
- 清理旧安装包、重复 Linux 工具链、历史构建缓存及旧检测运行资源；发行附件仅保留 EXE、DEB 和 SHA256。
- README 补充双平台安装与构建说明，记录实际 API 解析内存占用。

## 下载与安装

| 平台 | 文件 | 安装 |
| --- | --- | --- |
| Windows x64 | `Clash-of-Rust-0.4.5-windows-x64-setup.exe` | 运行安装程序 |
| Debian/Ubuntu amd64 | `Clash-of-Rust-0.4.5-linux-amd64.deb` | `sudo apt install ./Clash-of-Rust-0.4.5-linux-amd64.deb` |

每个安装包附带同名 `.sha256` 文件。内置 mihomo v1.19.32、Geo 数据及默认配置；升级保留订阅和个人设置。

Linux amd64 包在 Ubuntu 24.04 构建，其他 Debian 系发行版需要满足包声明的依赖。WSL2 需要 WSLg 图形支持。GNOME/KDE 的完整桌面集成及 Linux TUN 仍需在对应环境验证；公开检测平台的接口可能变化。

可能造成 Windows Defender 误判查杀，需自行规避。
