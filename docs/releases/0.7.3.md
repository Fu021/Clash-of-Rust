# 0.7.3

## 更新

- 桌面、Android、TUI 和 CLI 支持简体中文和英文，默认跟随系统。更改语言后，已打开的客户端界面立即刷新。Windows 安装器也会跟随系统语言。
- 在交互终端中运行 `cor` 即可打开 TUI，可直接启停内核、切换订阅和代理方式、检查更新。新增 `cor agent guide`，提供命令和排障指南。Windows 安装器默认将 `cor` 加入 PATH。macOS 从「应用程序」目录启动后也会为当前用户配置 PATH。
- 桌面代理组和订阅列表可在全部显示和分页之间切换，并记住显示偏好。Android 在页面间切换时保留代理、规则和订阅的列表视图。桌面和 Android 的单行输入随光标横向滚动，方便查看和修改长链接、导入表单以及搜索内容。
- Claude 保护和 IP 检测报告按主题整理，展示各服务的实际分流出口和多源 IP 检测结果。Claude 报告卡片按屏幕宽度分列。macOS 启动遇到上次运行遗留的 DNS 恢复时，会短暂等待网络助手就绪，失败后可重试。
- 改进订阅、Geo 数据和应用更新在下载停滞或临时中断后的恢复。桌面和 Android 的 Mihomo 内核更新至 1.19.34。
- 降低 TUI 浏览大量节点和快捷规则时的内存占用，并改进 Linux 后台在界面关闭后回收空闲内存的方式。
- Linux 提供 x64 和 ARM64 的 DEB、RPM，以及 Arch Linux x86_64 原生包。官方 Arch 包支持通过 `pacman` 安装和在客户端内更新。GitHub Releases 的下载按钮使用仓库内置的 SVG。

## 验证与已知问题

- 发行门禁覆盖同提交 CI、Android 8.0–16 和八套 Linux 发行版的基础代理与 TUN 验收，以及发行签名、安装包和 SHA256 核验。结果以本版的 Actions 和发布收据为准。
- Fedora 和 openSUSE 的应用内更新仍提示使用系统包管理器。Android 不同厂商设备的输入法、外接鼠标和首次授权仍需实机验证。
- 在 Linux 压力测试中，浏览大量节点并关闭界面后，后台和 Mihomo 仍可能保留额外内存。其他平台和长时间运行的表现仍待验证。

## Updates

- Desktop, Android, TUI, and CLI support Simplified Chinese and English, with the system language as the default. Open client interfaces refresh immediately when the language changes. The Windows installer also follows the system language.
- Run `cor` in an interactive terminal to open the TUI. From there, you can start or stop the core, switch profiles and proxy modes, and check for updates. The new `cor agent guide` provides command and troubleshooting guidance. The Windows installer adds `cor` to PATH by default. Launching the macOS app from an Applications folder also configures PATH for the current user.
- Desktop proxy groups and profile lists can switch between showing all entries and pagination, and remember the selected view. Android remembers the proxy, rule, and profile list views when switching pages. Single-line fields on desktop and Android scroll with the cursor, making long URLs, import form entries, and search queries easier to review and edit.
- Claude protection and IP detection reports group related results and show the routes used by each service and IP checks from multiple sources. Claude report cards adapt to the screen width. On macOS, if the network helper is still restoring DNS settings from an earlier run, the app waits briefly for it and offers a retry if recovery fails.
- Improved recovery from stalled or briefly interrupted downloads of profiles, Geo data, and app updates. Desktop and Android now use Mihomo 1.19.34.
- Reduced TUI memory use when browsing large node lists and shortcut rules, and improved how the Linux backend reclaims idle memory after the interface closes.
- Linux has DEB and RPM packages for x64 and ARM64, plus a native Arch Linux x86_64 package. The official Arch package supports installation via `pacman` and in-app updates. GitHub Releases download buttons use SVGs stored in the repository.

## Verification and known issues

- Release gates cover CI on the same commit, basic proxy and TUN checks on Android 8.0–16 and eight Linux distributions, release signing, and package and SHA256 verification. See this release’s Actions runs and release receipt for the results.
- On Fedora and openSUSE, in-app updates still direct users to their system package manager. Input methods, external mice, and first-time authorization on devices from different Android vendors still need actual device testing.
- In Linux stress tests, the backend and Mihomo may retain additional memory after browsing large node lists and closing the interface. Other platforms and sustained workloads still need testing.
