# Clash of Rust 0.5.9

适用于 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上），以及 macOS 14 及以上的 Intel / Apple Silicon；升级保留订阅和个人设置。

## 更新内容

### Claude 一键保护

- A÷检测新增默认关闭的“Claude 保护”：固定当前具体代理节点，优先加入 Claude 与关联服务规则，启用规则模式、TUN、严格路由、IPv6、UDP 转发和经保护节点访问的公网加密 DNS。
- 后台实时监测所覆盖的连接，关闭偏离保护节点的异常连接并弹出系统提示；隐藏窗口或切换页面后继续运行，保留最近 32 条异常记录。
- 开启前显示影响说明，确认按钮倒计时 3 秒。共享服务规则可能影响其他应用，DNS 与 TUN 变化可能影响国内网站及内网访问，请确认后启用。
- 原始订阅与个人偏好保持完整；重启后继续保护并保留恢复记录，关闭后恢复原代理模式、DNS、UDP、规则和节点选择，不自动重新检测。
- 代理集合中的节点按集合与精确名称固定；节点缺失或不支持所需 UDP 转发时拒绝对应请求，避免继续匹配到直连。补充纯 IP 请求的 HTTP、TLS 与 QUIC 域名识别，保留已知的 DNS／代理域名。
- Linux 使用独立系统警告框，安装包补充弹窗工具及中文字库依赖；提示合并去重，关闭保护时取消尚未完成的弹窗。

### 检测与报告

- 扩展多 STUN 的 IPv4/IPv6、WebRTC、Cloudflare trace、浏览器 Canvas／WebGL 和轻量连通性线索，补充官方支持地区及 IP 归属／信誉信息。缺失、受限或采样失败的结果保持未确认。
- “检测选项”提供手动 RDAP、Globalping 远端探针和小流量测速；这些补充采样不会随保护自动运行。
- “其他线索”改为整行可点击的按钮，显示项目数量和详情入口，适配深浅主题。异常记录独立保留，详情包含域名、匹配规则、线路及传输类型。
- 检测不读取 Claude Cookie 或账号凭据，实时监测不解密应用的 HTTPS 流量；第三方地区与指纹线索不代表 Claude 服务资格。具体范围见 [检测说明](../claude-region-detection.md)。

### UDP 设置

- 设置新增默认开启的“启用 UDP”，覆盖普通节点、代理集合及策略组，代理集合刷新后仍按偏好生效。
- Claude 保护期间临时强制开启 UDP，关闭后恢复用户原先的选择。AnyTLS 节点可使用其内置 UDP 转发；不额外改写 TFO、MPTCP 或协议专用的 UDP-over-TCP 选项。

### 验证

- Windows、Ubuntu、macOS 的 x64 / ARM64 六平台 [CI](https://github.com/Fu021/Clash-of-Rust/actions/runs/38679788717)、[原生验证](https://github.com/Fu021/Clash-of-Rust/actions/runs/38679788696)、[测试打包](https://github.com/Fu021/Clash-of-Rust/actions/runs/38680912428)及安装后的基础系统代理／TUN 测试通过。
- 临时原生验证覆盖每平台 23 类场景，包括 IPv4/IPv6 TUN、代理加密 DNS、TCP/UDP DNS 接管、异常连接关闭、通知去重、代理集合节点、重启与原状态恢复。
- 通过真实回环 AnyTLS 服务验证 UDP 转发；不支持 UDP 的受保护请求不会退回直连，正常 TCP、UDP 与无关连接保持可用。
- 六平台共生成 72 张实际 Iced 深浅色报告与确认框截图，并验证 Linux 系统弹窗可见性和取消清理。网络响应使用受控测试数据，不代表真实订阅或 Claude 服务可用性。
- [低强度内存基准](https://github.com/Fu021/Clash-of-Rust/actions/runs/38681658363)实测版本为 `0.5.9-dev.1`（`e5cdc2a`），使用 100 节点、5 个策略组、1,000 条规则，数据见 [README](../../README.md#内存占用)。

Windows 双击安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。

macOS 首次启用系统代理或 TUN 时，请完成网络助手安装授权；登录自启仍以普通用户运行。安装包使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。首次打开若提示无法验证开发者，可确认来源及校验值后，在“系统设置 → 隐私与安全性”中选择“仍要打开”，见 [Apple 说明](https://support.apple.com/zh-cn/102445)。
