# Clash of Rust 0.4.6

本版增加客户端内更新：发现新版本后可直接下载、校验并自动安装。

## 更新内容

- 新版本提示提供“更新”和“更新（代理）”，分别使用直连和当前客户端内核的代理下载。
- 下载期间显示百分比和已下载大小，完成 SHA256 校验后自动启动安装，并在安装完成后重新打开客户端。
- 下载、校验、授权或安装失败时，上方状态栏简要显示原因，撤掉进度条并允许重试。
- Windows 更新通过安装器正常退出客户端，恢复系统代理并停止自身内核；升级保留订阅与个人设置。
- Linux 自动安装 DEB；普通用户通过桌面授权服务请求管理员权限。

## 下载与安装

| 平台 | 文件 | 安装 |
| --- | --- | --- |
| Windows x64 | `Clash-of-Rust-0.4.6-windows-x64-setup.exe` | 运行安装程序 |
| Debian/Ubuntu amd64 | `Clash-of-Rust-0.4.6-linux-amd64.deb` | `sudo apt install ./Clash-of-Rust-0.4.6-linux-amd64.deb` |

每个安装包附带同名 `.sha256` 文件。旧版本升级至 0.4.6 需手动安装，之后可使用客户端内更新。代理更新需先启动内核；自动更新适用于通过安装包安装的客户端。

Windows 自动安装需完成 UAC 授权。Linux 普通用户需要 `pkexec` 与可用的桌面授权服务；DEB 在 Ubuntu 24.04 构建，其他 Debian 系发行版需满足包声明的依赖。WSL2 需要 WSLg 图形支持。

可能造成 Windows Defender 误判查杀，需自行规避。
