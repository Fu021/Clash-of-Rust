# Clash of Rust 0.4.2

本版本作为正式版发布，新增 GitHub Release 自动更新检测。

## 自动更新检测

- 启动时检查新版本，之后每 6 小时自动检查一次。
- 设置页显示当前版本、检查时间与结果，支持手动检查更新。
- 发现新版本后显示独立提示，可打开对应的 Release 页面下载安装包。
- 使用语义版本比较，正确区分 `0.4.9` 和 `0.4.10`，避免重复提示当前版本或降级版本。
- 内核运行时通过当前混合端口检查更新；请求在后台执行，不阻塞界面。
- 同一时间只执行一次检查，请求总超时为 15 秒，响应大小上限为 2 MiB；检查完成后释放 Release 响应及详情，只保留版本与检查结果。
- 网络失败不会清除已发现的新版本提示；网络错误、GitHub 请求限制与异常响应会在设置页显示。

## 本版包含

- 中文字体使用内嵌的思源黑体，英文与数字使用 Segoe UI。
- IP、GitHub 连通性、AI 服务与流媒体平台地区访问检测。
- 连接和规则分页展示，非当前页面的数据及时释放；API 流式解析、日志与后台缓冲容量限制，以及配置和轮询复制优化。

## 下载

- `Clash-of-Rust-0.4.2-windows-x64-setup.exe`：Windows x64 正式安装包。
- `Clash-of-Rust-0.4.2-windows-x64-setup.exe.sha256`：安装包 SHA-256 校验值。

安装包内置 mihomo、Geo 数据、默认配置和 IP 检测工具。安装新版本会保留订阅及个人设置。

## 验证

- 46 项常规测试、格式化和 Clippy 检查通过。
- 实际 GitHub Release 接口验证通过，旧版本能检测更新，较新版本不会提示降级。
- Windows 安装测试通过，覆盖版本信息、新安装、运行中拒绝、重复安装拒绝、重装、旧目录迁移、卸载及无关文件保留。
- 安装包内部版本号与 SHA-256 校验一致。
