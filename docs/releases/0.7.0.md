# 0.7.0

## 更新

- 更新桌面、Android 手机和平板界面，支持折叠桌面侧栏、代理与订阅的宫格／列表切换，统一规则列表和拖动样式。
- 重做 Android 应用分流，可选择代理全部、仅代理选中或排除选中应用；支持应用图标、搜索和保存后重连。
- 改善订阅、Geo 和客户端更新：代理不可用时尝试独立直连，失败保留原有配置；自动检查更新的间隔可在设置中调整，设为 0 可关闭。
- 优化 `cor` 命令补全、无图形界面的更新安装和诊断；修复部分 Linux 终端的 polkit TUN 授权问题。
- 修复 Windows 更新和 Geo 数据写入、恢复相关问题，改善 Android 订阅输入法及界面重建。
- 错误提示按影响程度展示，并提供导出诊断和新建 Issue 入口；优化节点列表离开后的闲置内存回收。

## 验证与已知问题

- 本次正式版的同提交 CI 和安装验证待完成。
- Linux 快速连续调整窗口大小时，可能短暂出现画面拉伸，仍在排查。
- Android 真机、厂商 ROM 和长期 TUN 尚未全面验收；部分网络环境中的间歇性 TLS 超时仍在排查。
