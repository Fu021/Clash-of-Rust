# 0.6.7-fix.3.diagnostics

此预发布版在 `0.6.7-fix.2.android-ime-flags` 基础上改进错误反馈、Android 输入和页面空间利用率。

- 桌面、Android 与 `cor` 共用有界诊断采集和脱敏。GUI 错误提供导出、复制与“新建 Issue”按钮，日志页保留常驻入口；CLI 报错提供 `cor diagnose --output` 命令，后台不可用时可用 `--no-start --offline` 先保存本地现场。
- [通知按实际影响分级](../../crates/client-ui/README.md#通知与故障反馈)：Geo 更新、检查更新、测速等可恢复失败使用顶部详细错误栏；内核无法启动、意外停止、VPN 无法启动和保护恢复失败使用居中弹窗。错误由用户关闭，普通后台成功不能覆盖；关闭、Escape 与 Android 返回保留底层页面和表单草稿。
- 将诊断、反馈与关闭按钮集中排列，手机窄屏分两行，长错误正文可滚动。点击“新建 Issue”自动预填脱敏摘要；桌面同时保存完整报告，Android 可导出或复制。完整附件由用户检查后提交，不静默上传或保存 GitHub 凭据。
- 修复 Android 输入文本与占位提示重叠，名称和地址字段在输入或组合文本期间隐藏提示。输入法回归同时核对真实键盘、文字稳定性、返回键、字段避让、前后台及旋转；旧版 Android 和厂商 ROM 的验证边界见[输入法记录](../agent-failures/android-ime.md)。
- 桌面订阅与代理页面按可用空间增加列数，压缩重复信息；Android 同步紧凑的卡片与操作层次，兼顾长文本、小屏及系统字号。
- 节点与策略组名称完整保留订阅原文，不再删除、替换或自动添加旗帜。桌面和 Android 使用随包 Noto Color Emoji，回移 Slint 软件渲染器的彩色字形支持。IP 检测与 Claude 报告使用 emoji 国旗，移除独立图集及图片缓存；港澳台在报告中映射中国国旗，保留地区文字。
- GUI 与 CLI 根据实际路由观察提示外部 TUN 接管，显示可读取的接口与进程归属；去掉日常页面的多用户说明，完整采样保留在诊断中。该观察不等于有权控制其他用户的内核。
- Windows 控制服务回写状态时保留运行时 Geo 更新事务，避免状态快照覆盖事务相关设置。旧版备份缺失问题的文件恢复已有回归；真实用户目录中最初备份丢失的唯一根因及 Windows 10 端到端故障注入仍未确认。
- 三个 Android ABI job 自行验证移动运行时，桌面构建不再代跑移动包；公共业务库继续随各端检查。
- 四份 Geo 原包在 CI 初始快照中统一校验和分发，各平台再次核对摘要与大小，避免排队期间上游附件变化或私网临时不可用阻断构建。前后台输入回归先核验系统恢复的键盘与布局，再单次点击字段，避免测试在恢复动画中重复触摸。
- 新增[文档导航](../README.md)及[仓库目录职责树](../development.md#目录与职责)，集中使用、开发、工作流和排障入口。

本版保留 `fix.2` 的键盘、旧 Android 窗口生命周期、Geo 启动恢复和缓存分工修复。待本提交的全部 CI、签名、打包及安装后验证成功后才公开；历史成功和静态预览不能代替当前提交验证。

MIUI / Redmi K30、第三方输入法、API 27、真实设备及人工授权仍需复验。iOS 仅有界面原型。长时间 TUN 运行后部分服务不可达仍作为[待排查问题](../agent-failures/network-recovery.md#长时间运行后的服务不可达)，本版不声称已修复。

试用前备份配置；不能保证保留数据降级。Android 使用长期发行签名；macOS 为 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。
