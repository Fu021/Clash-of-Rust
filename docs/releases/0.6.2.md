# Clash of Rust 0.6.2

本次更新加入无界面的 `cor` 命令行，改善 Android VPN 的连接与取消，并完善客户端更新检查和下载反馈。支持 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上）、macOS 14 及以上的 Intel / Apple Silicon，以及 Android 8.0 及以上的 ARM64 / ARMv7 / x86_64。

## 更新内容

### CLI 与 Server 使用

- Windows、Linux、macOS 安装包内附带 `cor`，无需打开 GUI，可在终端、SSH 和 Server 环境使用；与桌面窗口共用内核、订阅和设置。
- 支持内核启停、代理模式、订阅、节点测速与选择、自定义及快捷规则、连接、日志、DNS、IP/Claude 检测、客户端更新和当前用户登录自启，覆盖 GUI 中的大部分配置与维护操作。
- 默认使用中文状态、分组表格和易读单位；窄终端分条展示，保留完整名称与 ID。提供分级 `help`、Shell 补全和 JSON/JSONL 输出，便于脚本调用。
- 日常使用 `cor start` 在后台运行，关闭终端后继续使用；`cor run` 仅用于前台调试。建议纯 CLI 的服务器使用 TUN，减少逐个配置程序代理的麻烦。
- Linux 显式以 root 运行时可直接使用已有权限启动内核与 TUN；普通用户保留原有授权方式。配置校验失败时，终端显示实际原因。

命令、安装路径、授权与带注释示例见 [CLI 使用文档](https://github.com/Fu021/Clash-of-Rust/blob/v0.6.2/docs/cli.md)。

### Android

- 首页选择节点时，定位到正在使用的策略组。
- 修复取消连接后，迟到的 VPN 授权、服务启动或排队请求重新开启连接的问题；连接过程中可直接取消。
- 修复检查更新与下载更新时重复显示进度条的问题。

### 客户端更新

- 更新下载显示已下载大小、速度及实际连接的出站节点链；回退直连时明确标注，暂无法确认时显示正在确认。
- 下载使用固定大小写盘缓冲，减少小块网络数据带来的磁盘调度开销。
- 桌面、Android 和 CLI 检查更新遇到网络错误或发布附件暂未完整时，会重新获取发布信息，最多尝试 4 次，总等待上限约 75 秒；避免过早报缺少本平台安装包或校验文件。
- 继续只检查正式版，并校验平台、安装包大小、SHA256 与下载来源。

### 内存基准

完成 [0.6.2 低强度内存基准](https://github.com/Fu021/Clash-of-Rust/actions/runs/39739609814)：100 节点、5 个策略组、1,000 条规则，首页 GUI RSS 45.91 MiB、GUI 与内核合计 PSS 83.49 MiB；节点搜索时分别为 55.96 MiB 和 100.39 MiB。

新增关闭窗口驻留托盘与纯 CLI 后台测量。托盘场景关闭前后，GUI RSS 均为 46.80 MiB，合计 PSS 从 85.01 MiB 变为 84.79 MiB；纯 CLI 后台客户端 RSS 14.01 MiB、与内核合计 PSS 53.29 MiB。实验版本、环境及其他场景见 [README](https://github.com/Fu021/Clash-of-Rust/blob/v0.6.2/README.md#内存占用)。

Windows 运行安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。Linux Server 安装同一份 DEB 后，可在 SSH 中直接使用 `cor`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。桌面升级保留订阅和个人设置。

Android 安装对应架构的 APK，首次连接允许 VPN 授权；可在系统快捷设置中添加开关磁贴。在线更新由系统确认安装。
