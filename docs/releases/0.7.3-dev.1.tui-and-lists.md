# 0.7.3-dev.1.tui-and-lists

## 更新

- 桌面代理组和订阅默认显示全部，页脚可切换分页。重新打开窗口会恢复已保存的分页偏好以及代理组的宫格或列表布局。组内节点保留分页。
- TUI 首页可直接启停内核、切换代理方式和订阅、检查更新。订阅与快捷规则支持在 TUI 内选择和确认。窄终端会对长条目换行，调整尺寸时保留选中项。
- Linux 后台会在处理完大快照和规则文档响应后回收空闲堆页，加快 TUI 退出后的内存回落。桌面窗口关闭后收到的页面响应也会触发回收。

## 验证与已知问题

- 本版的发布门禁覆盖同提交 CI、Android 8.0～16、Ubuntu 20.04 x64 与 ARM64、发行签名及安装包校验。实际结果和包身份以本版 Actions 和发布收据为准。
- 已在 Linux 基准中测量界面关闭与重开。快捷规则全开的压力负载下，反复开关 TUI 后的后台内存仍可能高于纯 CLI。退出 TUI 或关闭桌面窗口后，运行中的内核继续驻留。长期流量和其他平台的内存表现待测。

## Updates

- Desktop proxy groups and profiles show all entries by default. Use the footer to switch to pagination. Reopening the window restores the saved pagination preferences and the grid or list layout for proxy groups. Nodes within each group remain paginated.
- From the TUI home page, you can start or stop the core, switch proxy modes or profiles, and check for updates. You can select and confirm profiles and shortcut rules in the TUI. Long entries wrap in narrow terminals, and resizing preserves the selection.
- On Linux, the backend reclaims unused heap pages after processing large snapshots and rule document responses, helping memory settle sooner after TUI exit. Page responses that arrive after the desktop window closes also trigger reclamation.

## Verification and known issues

- Release gates cover CI for the same commit, Android 8.0–16, Ubuntu 20.04 x64 and ARM64, release signing, and package verification. See this version’s Actions runs and release receipt for actual results and package identities.
- Linux benchmarks measured closing and reopening the interfaces. Under stress with all shortcut rules enabled, backend memory after repeated TUI sessions can still exceed the CLI-only baseline. A running core stays resident after you exit the TUI or close the desktop window. Memory under sustained traffic and on other platforms remains to be measured.
