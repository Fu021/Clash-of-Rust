# Clash of Rust 0.4.13-dev.1

开发预览版本，集中修复配置一致性和内存问题。

- 统一内存测试为 `examples/memory_benchmark.rs`，支持规则、连接、代理的流式/缓冲解析、连续刷新及 GUI/内核进程采样；支持 JSONL 结果和独立子进程重复测试。
- 压缩 API 快照：同一次响应中的重复文本共享存储，独有文本使用紧凑存储，代理只保留最后一次延迟，列表容量收紧；解析结束后释放文本索引。
- 代理组增加全局分页，每页最多四组，每组最多六十个节点，限制同时展开或搜索时的界面内存。
- 平台检测常量改为借用，正常 UTF-8 响应直接复用缓冲区，丢弃正文时不缓存正文；减少 JSON 遍历和字符串切片中的临时分配。
- 并发平台检测复用同一代理端口的 HTTP 客户端，Cookie 仍按检测隔离；TLS 1.3 客户端按需创建，全部检测结束后释放共享客户端。
- 本地订阅在读取前检查大小，读取过程同样受 10 MiB 上限约束，避免超大文件先分配内存再被拒绝。
- 保存端口时合并执行时的最新设置，避免排队操作覆盖测速间隔、模式或当前订阅。
- 配置更新、重启、模式/节点切换时取消旧测速和网站检测；使用任务代数拒绝旧结果，包括同一订阅 ID 更新的情况。
- 订阅导入、更新、激活、删除和模式保存先准备磁盘事务，提交失败恢复旧文件与运行状态；进程中断后下次启动先恢复未完成事务。

同构建、同数据的修改前后结果和原始记录见 [内存报告](../benchmarks/0.4.13-dev.1/README.md)。
