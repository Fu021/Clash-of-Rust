# Clash of Rust 0.4.10

本版调整 Linux 构建环境，解决 Ubuntu 22.04 无法使用安装包的问题。

## 更新内容

- Linux amd64 与 ARM64 安装包改用 Ubuntu 22.04 原生构建，降低系统库要求。
- 构建缓存按系统版本隔离，并在 Ubuntu 22.04 上测试安装包的窗口启动、内核运行与关闭退出。

## 下载与安装

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `Clash-of-Rust-0.4.10-windows-x64-setup.exe` |
| Windows ARM64 | `Clash-of-Rust-0.4.10-windows-arm64-setup.exe` |
| Debian/Ubuntu amd64 | `Clash-of-Rust-0.4.10-linux-amd64.deb` |
| Debian/Ubuntu ARM64 | `Clash-of-Rust-0.4.10-linux-arm64.deb` |

Windows 运行对应架构的安装程序；Debian/Ubuntu 使用 `sudo apt install ./安装包文件名.deb`。每个安装包附带同名 `.sha256` 文件，升级保留订阅和个人设置。

支持自动更新的已安装客户端也可直接更新。Windows 自动安装需要 UAC 授权；Linux 需要 `pkexec` 与桌面授权服务。

可能造成 Windows Defender 误判查杀，需自行规避。
