# 0.6.7-fix.6.cross-user-tun

相对上一次公开的 `0.6.7-fix.4.direct-downloads`，本轮改善 CLI 配置、Linux TUN 观察、控制连接恢复、桌面滚动和侧栏，并精简通知。

- Bash、Zsh、Fish 和 PowerShell 增加上下文补全，覆盖命令、选项、`config get/set` 配置键及枚举值；补全本身不创建后台或用户数据目录。
- 更新安装交接保留实际用户数据目录，重新打开同一份设置，避免预发布通道等选项因重启进入另一目录而看似丢失；仍兼容旧版更新计划。
- `cor status`、`cor proxy`、`cor stop` 与 `cor diagnose` 在 Linux root 下接受 `--all-users`。该标志只扩大只读 `/proc` 观察范围，显示其他用户持有的 TUN 进程 PID/UID；文本输出即使在本实例自身也使用 TUN 时仍单独显示持有进程摘要。它不会停止、切换或修改其他用户的内核。
- 默认扫描仍只核对当前有效用户，普通用户不再因无权读取其他用户的 `/proc/<pid>/fd` 而得到误导性的“持有进程无法读取”。观察到 TUN 但没有当前用户持有者时，文本提示给出 `sudo cor status --all-users`。
- JSON 的 `host_routes.holder_scope` 与 `tun_holders.scope` 标明 `current_user` 或 `all_users`；`tun_holders.skipped_other_users` 记录默认范围内被跳过的其他用户进程数。
- `proxy --all-users` 仅允许只读观察，不能与 `system`、`tun` 或 `off` 切换同时使用。
- Linux 启用 TUN 后核对示例 IPv4/IPv6 路由，确认仍绕过 TUN 时报告覆盖异常并回退；诊断报告增加路由与 DNS 劫持配置摘要，保留未知或无权限状态，不伪装成完整覆盖。
- root 已具有必要有效网络 capabilities 时允许在 `NoNewPrivs` 环境使用 TUN；不为普通用户放宽提权和 capability 检查。
- 控制接口只读查询遇到连接错误或超时后，最多使用新连接重试一次；写操作不重放，HTTP 拒绝不重试，也不会因超时擅自切换已有内核的控制端口。
- 桌面修正滚动内容高度与偏移约束，短内容保持顶部对齐，内容缩短及窗口变高后不留在无效滚动位置；连接列表采用统一自然布局。
- 设置页分组高亮跟随实际滚动位置，点击分组仍可定位；滚到底部显示“计划任务”，窗口放大至内容无需滚动时回到“常规”。
- 节点全不可达提示缩短为结果、接管状态与操作建议；后台复测直接更新原警告，不再堆叠“测速失败”和“双目标复测”两段说明。技术细节保留在日志，诊断入口保留；桌面、移动端及 CLI 将“停止接管”明确为“关闭代理”，仍须主动点击或执行，不自动关闭代理或 TUN。Claude 保护期间不提供该操作。
- 桌面和移动端普通通知改为 5 秒自动消失，再次通知重新计时；可恢复错误和严重错误继续保留到主动关闭，具体错误原因不截断。
- Android 网络集成在重载后再次核对真实 TUN 连接，并在有限预算内验证域名请求；冷启动磁贴的测试配置提前保存，避免前项失败污染后项。该调整增加验证和诊断，不代表已定位持续断网的根因。
- Ubuntu 20.04 ARM64 和 x64 的客户端安装验证接入[私网预装模板](../workflows/prepared-vm-images.md)，分别冻结环境和精确恢复；按服务端 `vm_limits` 声明的架构与限制启用，未就绪或恢复失败时保留冷准备。模板独立清理、关机、校验及二次启动后上传，只存私网，不占 GitHub Cache。SSH 就绪检查允许单次探测超时后在总预算内继续等待，不提前中断慢速启动。原包、安装及代理/TUN 验证仍完整执行，真实入库、恢复和冷暖耗时另行验收。
- 镜像客户端对齐 `2026-11-08-x64` 协议及完整 46 条共用向量，核对 health 兼容字段的一致性、完整环境和回执身份，接受小数时间戳；上传应答丢失先查询原回执，回执过期则按精确环境键确认，不把发送完成或 pending 当作保存成功。
- 字标右侧新增收起/展开侧栏按钮，保留页面及窗口重建后的手动选择；窄窗口继续自动使用图标栏。侧栏宽度和节点网格重排增加轻量动效，尊重桌面系统减少动态效果设置。
- README 标题使用与应用相同的几何路径字标，分别适配浅色和深色。
- 清理已完成重构的旧 HTML 设计稿，文档以正式 Slint 组件与预览为准。
- 正式版和预发布版的发布说明自动附上九种安装包下载徽章及各附件下载量；链接固定到本次版本。版本文案使用统一模板，历史文案归 Git 历史和 GitHub Releases 查阅。

发布前以同提交 CI、九组安装包和安装后验证结果验收。跨用户结果依赖 root 能读取目标进程的 `/proc`；扫描预算、进程退出和隐藏进程仍可能产生 `partial`。路由采样不等于已经验证所有连接或所有 DNS 组合；长时间运行后的间歇 TLS 握手失败仍未定位首次触发原因。真实设备、长期 TUN、重启/休眠及人工授权交互不以静态预览代替。
