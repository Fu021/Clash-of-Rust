# 0.7.1-fix.2.ipv6-startup

## 更新

- 修复 Linux 没有 IPv6 上联时误报 TUN 或 Claude 保护失败；网络恢复 IPv6 后重新检查接管，保留真实绕行警告。
- 修复旧 Linux 自启动入口升级后仍前台打开窗口的问题，统一“后台自启动”名称，并保留托盘失败提示与启动诊断。
- Android 应用出口改为可命名规则组，支持搜索选应用、指定节点或策略组、直连与拦截；目标消失时默认拦截并通知。Android 8、9 继续支持范围分流，暂不支持指定出口。
- 减少 Claude 保护刚开启时的瞬时误报，允许主题、强调色等外观设置和只读操作，继续限制网络改动。
- 统一桌面与移动端的连接卡片、IP 检测和地区线索报告布局，改进 Geo 下载回退与诊断信息。

## 验证与已知问题

- 发布前核对同提交 CI、Android 8.0～16 和 Ubuntu 20.04 两种架构的兼容验证；结果以 Actions 和发布收据为准。
- COSMIC 登录自启、Linux 快速缩放、真实设备与长期网络切换仍需现场验证；间歇 TLS 失败尚未确定根因。
