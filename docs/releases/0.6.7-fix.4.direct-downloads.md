# 0.6.7-fix.4.direct-downloads

基于 `0.6.7-fix.3.diagnostics`，本轮改进更新回退、界面视觉和 Linux 发布验证。

- 故障反馈只保留导出诊断与新建 Issue，移除重复复制入口；重启内核及恢复直连操作融入同一轻量操作区，手机按可用空间换行。
- 桌面测试系统通知改为点击左上角应用图标，移除右上角文字按钮；保留键盘操作、发送并发限制和权限引导。
- 订阅手动/定时更新、Geo、客户端更新发现与安装包下载共用独立内核 DIRECT 入口。节点全部失效时不再把关闭 HTTP 代理误作绕过 TUN；无需用户切换订阅或全局模式。开启 DNS 覆盖时直连 DNS 同样明确绕过节点，关闭覆盖时保留自定义上游。
- 一次节点测速全部失败时，桌面/CLI 与 Android 使用两个目标复测全部真实叶子节点；确认全失联后保留接管并报告可恢复错误。TUN、Android VPN 和系统代理下的更新均先代理、失败后独立 DIRECT，无需关闭接管或切换配置；“停止接管”仅为其他应用仍无法联网时提供可选操作。复测限时、取消和保护边界统一见[联网恢复](../agent-failures/network-recovery.md#全部节点不可达时的更新与警告)。
- Claude 保护及切换期间桌面、Android 与 CLI 统一只读：暂停订阅、Geo、客户端更新和自动网络刷新，阻止规则、订阅、节点、模式、端口及网络设置修改；桌面确认框只放行退出与关闭草稿，Android 保留取消在途更新，各端仍可关闭保护。保护启动不再预留或等待 DIRECT 下载监听器。
- 桌面、Android 与 `cor` 的新增、编辑和启用规则统一拒绝重复的启用规则，允许保留禁用副本；拒绝后不污染原草稿。定时订阅更新使用可取消门禁，保护期间跳过，下载完成前复核订阅、来源、文件、开关和保护状态，过期结果丢弃；Android 跨 Activity 会话的并发限制仍见[订阅说明](../subscriptions.md#自动更新)。
- 桌面与移动端采用暖色中性背景、轻边框和柔和卡片。桌面和平板移除侧栏竖向分割线与内容区外框，各页隐藏可见滚动条，保留滚轮与触摸滚动；桌面底部留白缩至 8px，平板背景延伸至系统操作栏后，控件保留安全距离。桌面页头缩为 52px，窄窗将导航收为图标栏，节点卡片按 196px 参考宽度与字号增加列数；移动节点把延迟与名称同排，保留至少 48px 的触控操作。
- 融合 PR #36 的桌面网络概览、隐私遮盖、连接数量、订阅多列和设置行布局，并把网络概览接入 Android 手机/平板，共用探测目标、分类、隐私与取消规则；iOS 只同步界面原型。保留当前 Android 键盘、emoji、诊断分级及 Windows Geo 事务修复；具体回归范围见[界面融合与兼容](../ui-design.md#pr-36-的融合与兼容)。
- 成功通知可点击正文关闭；可恢复错误采用底部浮层，严重错误居中，两类错误使用操作区的明确“关闭”，点击正文或空白不关闭。详细错误可滚动，诊断和恢复操作保持可见；Escape/Android 返回可以关闭，诊断按钮不会顺便关闭原错误。
- 配置、订阅、策略组和节点的长名称在摘要处单行省略，状态和按钮优先分配空间；详情保留完整原文，桌面/手机/Pad 共用长名称预览夹具。
- Ubuntu 20.04 在 Linux 包可用前启动 VM、解包 Python，并由宿主按签名 APT 清单下载、校验和传入 GUI/测试依赖；先准备测试环境，再等待和核验同提交包，由应用包声明和安装其自身依赖，不减少图形授权、代理/TUN 与最低内核断言。
- guest 原包只回传来源与校验记录，移除整批 DEB 复制收尾；GNOME 就绪探测的短暂失败进入诊断附件，真正就绪超时仍失败。macOS 复用官方 Tailscale Action 二进制缓存，避免重复源码编译。
- 依赖快照更新兼容范围内的 Rust 和 Go 锁文件、Gradle 及 Geo 原包。应用继续使用最新正式版 Slint 1.18.1；预览使用带彩色 emoji 字体回退的主线 Viewer，版本和字体身份写入截图目录。
- 修正桌面动画回归仍断言旧背景色的问题，使用当前主题实际颜色核对首帧；同步紧凑布局的指针测试位置，保留真实点击、动画释放和重绘断言。
- 移动框架补齐默认焦点转发，修复严重警告中按 Android 返回键可能直接关闭 Activity 的路径；回归同时检查按键消费、前台窗口、实时诊断与订阅草稿，随后继续输入法、前后台和旋转检查。

当前为待验证版本；不以历史绿色结果代替本提交 CI 和不发布打包。真实设备、MIUI/第三方键盘、长期 TUN 故障及自定义 DNS 的可用性仍需对应现场验收。此次不操作用户正在使用的网络，也不修改服务端或恢复 README/agent 反馈通道。
