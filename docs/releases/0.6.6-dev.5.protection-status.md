# 0.6.6-dev.5.protection-status

本次预发布让 Claude 保护状态在各页和 Android 通知中更清楚，同时完善订阅格式错误提示。包含 `0.6.6-dev.3.subscription-compat` 以来的改进，旧预发布继续保留，正式版仍为 `0.6.5`。

- 桌面、Android 手机和 Pad 的各页标题栏统一增加紧凑盾牌：绿勾表示接管与实时拦截就绪，黄沙漏表示切换或待确认，红叉表示异常。点击进入 A÷检测；异常原因直接显示在内容上方，便于排查。
- 去掉与盾牌重复的状态线，避免长文案挤压手机标题。保留内核状态徽标、移动点击区域和无障碍说明，并检查窄屏、大字号、横屏和 Pad 布局。
- Android 常驻 VPN 通知标注 Claude 保护状态。关闭应用窗口或隐藏通知网速后仍会更新，模式、节点和可选网速继续保留；关闭保护后移除标注。
- 状态读取失败时回到待确认，实时拦截任务停止时显示异常，避免沿用旧绿色状态。`cor claude watch` 同步输出共享接管状态。
- macOS DNS 接管和冲突分域隔离增加原生响应确认，避免探针刚到达本机就过早判定系统解析已切换；未确认时保持未就绪，继续保留现有无外流检查。
- 订阅最终返回非 Mihomo/Clash Meta YAML 时，桌面和 Android 的顶部状态通知明确报错，`cor` 同步提示；手动或定时更新失败均保留原订阅和运行状态，不自动转换其他订阅格式。
- 精简订阅 User-Agent，移除 v2rayN、v2rayNG 和自身版本号。GUI、`cor` 与 Android 共用 `clash.meta mihomo ClashMeta clash-verge ClashVerge ClashMetaForAndroid clash-of-rust`，相同标识不再重复请求。
- 延续 Ubuntu 20.04 双架构支持和安装后 GUI、代理/TUN 验证，以及此前 IPv6 解析、Geo 更新恢复和 macOS 启动改进。

盾牌表示客户端当前可确认的保护状态，不能证明所有应用流量、浏览器独立 DNS 或 STUN 路径均无泄漏。真实网络、设备通知权限及机场定制接口仍需复测。

预发布版本可能存在尚未发现的问题，建议先备份配置。Android 使用长期发行签名；从预发布返回正式版时，无法保证保留数据完成降级。macOS 安装包使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。
