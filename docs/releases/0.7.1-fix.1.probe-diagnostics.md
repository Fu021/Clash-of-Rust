# 0.7.1-fix.1.probe-diagnostics

## 更新

- 修复控制接口异常被误判为全部节点不可达的问题；诊断报告增加最近四轮测速结果，以及 Android 网络、VPN 和套接字保护状态。
- 修复 Android 8、9 的网络诊断兼容性；安装正式版时不再因开启预发布通道而显示预发布风险提示。
- 修复 Linux 将未配置的 IPv6 TUN 误判为启动失败；保留真实绕行提示，桌面诊断补齐 TUN 配置摘要。
- Claude 保护拒绝已确认的 IPv6 绕行，避免将不完整接管显示为保护成功。
- 桌面登录自启等待托盘就绪时保持后台，避免登录稍慢就意外弹出窗口。

## 已知问题

- 部分 Android 订阅不可用的现场原因仍需确认。复现后请尽快在日志页导出诊断，附上操作步骤和发生时间；分享前检查敏感信息。
