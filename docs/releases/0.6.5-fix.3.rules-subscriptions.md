# 0.6.5-fix.3.rules-subscriptions

此版本为修复分支预发布版本，供确认功能、兼容性和发布流程使用。

- 桌面与 Android 规则页统一支持拖动排序；Android 增加长按拖动和拖到列表边缘时的连续滚动，并显示完整规则原文。
- 调整手机分页、放弃修改与应用修改区域，避免底部操作拥挤；修正 Android Pad 连接页等页面的宽度，并将 Pad 的工具入口与手机版对齐。
- Android 的 Fake-IP 排除项移至对应设置下方；连接、规则、日志和诊断列表继续适配窄屏与横屏布局。
- Android 可直接删除正在使用的订阅，并原子切换回默认直连；创建订阅增加请求门控，避免卡顿期间重复点击产生同名错误。
- Android 规则保存补齐重复启用、1,000 条上限和位置越界校验；保存失败保留当前草稿，拖动期间切换筛选或布局会安全取消手势。
- Windows 打包增加未压缩程序的 Defender 扫描、版本证据和失败阻断，降低带毒产物或版本不一致产物通过校验的风险。

Android 继续使用系统 VPN、前台服务、通知与安装确认，不扫描 Claude Desktop 或 CLI 项目。关闭“包含预发布版本”可能提示返回正式版；Android 不支持直接覆盖较低 versionCode，需备份配置后由用户手动卸载重装。
