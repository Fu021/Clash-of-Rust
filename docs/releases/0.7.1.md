# 0.7.1

## 更新

- 修复 Linux 无 IPv6 网络时无法启动内核、误报 TUN 绕行或 Claude 保护失败的问题；IPv6 出现或消失后重新核对接管。
- 修复 Linux 旧自启动入口升级后仍打开窗口的问题，完善后台自启动、托盘异常提示和诊断导出。
- Android 应用分流支持命名规则组、搜索选择应用，以及指定节点、策略组、直连或拦截；目标消失时默认拦截并通知。Android 8、9 支持范围分流，指定出口需 Android 10 及以上。
- 改进节点测速、更新与 Geo 下载的错误诊断和回退，安装正式版不再误显示预发布风险提示。
- Claude 保护允许外观设置和只读操作，继续锁定网络修改；减少启用瞬间的状态误报，统一跨端报告与连接卡片。

## 验证与已知问题

- 发布前完成同提交 CI、Android 8.0～16、Ubuntu 20.04 两架构及发行签名验证，结果以 Actions 和发布收据为准。
- 旧自启动入口迁移已在隔离 COSMIC Wayland 环境验证；真实设备、厂商 ROM 和长期网络切换仍需反馈确认。
- Linux 快速调整窗口大小、间歇 TLS 失败和部分长连接下载慢速仍在排查。
