# 0.7.3-dev.3.memory

## 更新

- 在交互终端运行 `cor` 即可打开 TUI。新增 `cor agent guide`，为 AI 助手提供命令用法、诊断步骤与项目文档入口。
- Windows 安装器默认将 `cor` 加入 PATH，旧版升级也会补加。在 macOS 的「应用程序」目录启动客户端后，应用会静默配置当前用户的 PATH。重新打开终端即可使用 `cor`。
- 补齐桌面、Android、TUI 和 CLI 的中英文文案，覆盖订阅用量与到期时间、诊断报告及更多提示和错误。Windows 安装器跟随系统语言。
- Android 的代理、规则与订阅列表更接近桌面端，切页会保留列表视图。连接页移除了滑动时可能导致崩溃的流量汇总。
- 改进应用更新、Geo 数据和订阅下载遇到停滞或临时中断时的恢复。
- 降低 TUI 浏览大量节点和快捷规则时的内存占用。快捷规则页按需读取规则摘要。
- Linux 新增 ARM64 RPM，适用于 Fedora 和 openSUSE。DEB 继续提供 x64 和 ARM64，Arch Linux 继续提供 x64 原生包。

## 验证与已知问题

- 全平台 CI、Android 与八套 Linux 发行版的基础兼容检查，以及安装包核验，均以本版的 Actions 记录和发布收据为准。
- 在 Linux 压力测试中，浏览大量节点后，Mihomo 在界面关闭时仍可能保留较多内存。
- Fedora 和 openSUSE 的应用内更新仍提示使用系统包管理器。使用应用内更新查找本版时，需在设置中开启「包含预发布版本」。

## Updates

- Run `cor` in an interactive terminal to open the TUI. The new `cor agent guide` gives AI assistants command usage, troubleshooting steps, and links to project documentation.
- The Windows installer adds `cor` to PATH by default, including when upgrading from an older version. On macOS, launching the app from an Applications folder silently configures PATH for the current user. Open a new terminal to use `cor`.
- Expanded Chinese and English translations across desktop, Android, TUI, and CLI, including subscription usage and expiration, diagnostic reports, and more notices and errors. The Windows installer follows the system language.
- Android proxy, rule, and subscription lists behave more like their desktop counterparts and remember their view when switching pages. Removed the connection traffic summary that could crash when swiped.
- Improved recovery from stalled or briefly interrupted app update, Geo data, and subscription downloads.
- Reduced TUI memory use when browsing large node lists and shortcut rules. The shortcut rules page loads a compact summary.
- Added a Linux ARM64 RPM for Fedora and openSUSE. DEB remains available for x64 and ARM64, and the Arch Linux native package remains available for x64.

## Verification and known issues

- See this version’s Actions records and release receipt for cross-platform CI, basic compatibility checks on Android and eight Linux distributions, and package verification.
- In Linux stress tests, Mihomo can retain additional memory after browsing a large node list and closing the interface.
- The in-app updater on Fedora and openSUSE directs users to their system package manager. To find this prerelease through the in-app updater, enable “Include prereleases” in Settings.
