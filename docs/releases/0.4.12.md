# Clash of Rust 0.4.12

## 更新内容

- 修复 Ubuntu 开机自启动后托盘缺失；托盘暂不可用时显示窗口，兼容无托盘环境。
- 优化 Windows 开机自启动，减少登录后托盘出现缓慢的问题。
- 修复 Linux 切换 TUN 时连续弹出授权的问题，首次授权后通常无需重复输入密码。
- 修复 Ubuntu 窗口宽度卡在 1200、无法恢复默认 `950 × 700` 的问题。

| Debian/Ubuntu ARM64 | [Clash-of-Rust-0.4.12-linux-arm64.deb](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.4.12/Clash-of-Rust-0.4.12-linux-arm64.deb) |

Windows 双击安装程序；Debian/Ubuntu 执行 `sudo apt install ./安装包文件名.deb`。升级保留订阅和设置，也可使用客户端自动更新。每个安装包附带 `.sha256` 校验文件。

升级后首次开启 Linux TUN 需完成一次管理员授权，之后切换模式与重启客户端通常无需再次授权。
