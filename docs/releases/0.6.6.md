# Clash of Rust 0.6.6

本次更新将 Ubuntu 最低支持版本降至 20.04，新增各页可见的 Claude 保护状态，并修复订阅兼容、IPv6 慢解析、Geo 更新恢复与 macOS 启动问题。支持 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 20.04 及以上）、macOS 14 及以上的 Intel / Apple Silicon，以及 Android 8.0 及以上的 ARM64 / ARMv7 / x86_64。

## 更新内容

### Ubuntu 20.04 与安装验证

- Linux 两种架构统一使用 Ubuntu 20.04 用户空间构建，检查安装包 ELF 依赖及 `GLIBC 2.31` 上限。使用同一份 DEB 验证 Ubuntu 20.04、22.04 和最新版；20.04 另在 5.4 GA 内核虚拟机中检查 GUI、代理与 TUN。Ubuntu 18.04 仍不在支持范围内。
- 补齐 Linux 安装后的 X11/Wayland、托盘、窗口重建、GUI/CLI 共用内核与图形授权验证；Windows 增加普通用户安装后窗口检查，Android 增加 Activity 重建验证，并沿用 macOS 原生生命周期检查。
- 修复 Ubuntu 窗口标题中的缺字方块，调整旧系统图形会话和授权夹具，避免将测试环境的时序问题误判为客户端故障。

### Claude 保护状态

- 桌面、Android 手机与 Pad 的各页标题栏统一显示紧凑盾牌：绿勾表示接管与实时拦截就绪，黄沙漏表示切换或待确认，红叉表示异常。点击进入 A÷检测，异常原因显示在内容上方，不遮挡页面。
- Android 常驻 VPN 通知同步标注保护状态；关闭窗口或隐藏通知网速后仍会更新，保留节点与模式信息。关闭保护后移除标注。
- 状态读取失败或实时拦截任务停止时，不再沿用旧绿色状态；`cor claude watch` 输出相同的共享保护状态。
- macOS DNS 接管及冲突分域隔离等待系统原生解析器收到本机转发器的匹配响应，避免请求刚到达转发器就过早判定就绪。继续保留私有分域与关闭保护后的恢复机制，无需用户手动调整 DNS。

### 订阅与下载

- 订阅请求统一使用 `clash.meta mihomo ClashMeta clash-verge ClashVerge ClashMetaForAndroid clash-of-rust`，改善机场客户端识别兼容；不携带 v2rayN、v2rayNG 或自身版本号，不重复发送相同标识的请求。
- 服务器最终返回非 Mihomo/Clash Meta YAML 时，桌面与 Android 顶部通知明确提示格式不兼容，`cor` 同步报错。手动和定时更新失败均保留原订阅、规则草稿及运行状态，不自动转换其他订阅格式。
- 修复合法空配置段被误拒绝，以及机场返回兼容提示节点时被误当成可用订阅的问题；解析错误不输出可能含节点凭据的原始内容。
- 桌面订阅、Geo 与 CLI 客户端更新下载移出共享后台锁，保留取消和迟到结果校验，减少下载期间其他操作被阻塞的问题。macOS 安装包校验和授权等待同样移到锁外，交接前重新核对请求。

### 网络、启动与界面

- 延长 IPv6 节点域名的 AAAA 解析等待，减少慢解析被误判为无地址的情况；保留已有网络恢复机制。
- Geo 更新完成后的备份清理失败，不再回退已经安装成功的新数据；重启后继续清理遗留备份，Android 重载时保留现有 VPN。
- macOS 从已保存的 TUN 或 Claude 保护状态启动时直接使用授权助手；窗口连接已有后台时委托实际所有者启动，减少升级或重启后的内核启动等待。
- 修复托盘启动所有者、窗口重建后的运行状态与 Android 渲染表面释放；优化手机和横屏 Pad 的设置卡片布局，Geo 显示上次更新时间，并与软件更新归入同一分组。

Windows 运行安装程序；Debian/Ubuntu（Ubuntu 仅支持 20.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。Linux Server 安装同一份 DEB 后，可在 SSH 中直接使用 `cor`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。桌面升级保留订阅和个人设置。

Android 安装对应架构的 APK，首次连接允许 VPN 授权；在线更新由系统确认，使用长期发行签名。系统仍会拒绝覆盖签名不同或版本代码更低的安装包，不能保证跨签名或降级时保留数据。

macOS 网络助手升级后首次启用可能需要管理员授权；当前安装包使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。盾牌表示客户端可确认的保护状态，DNS 国家仍是风险线索，均不能单独证明所有应用、浏览器独立 DNS 或 STUN 路径无泄漏。真实硬件、通知权限、交互授权、休眠恢复及机场网络仍需结合现场验收。
