# 0.7.3-dev.4.input-recovery

## 更新

- 桌面和 Android 的单行输入框随光标横向滚动。订阅快捷地址、导入表单的名称和地址，以及搜索等长文本都可以查看和编辑被遮住的部分。
- Claude 报告按屏幕宽度分列。高矮不同的卡片各自在同列保持固定间距。
- macOS 启动时，若网络助手正在恢复上次运行留下的 DNS 设置，客户端会短暂等待助手就绪再继续。恢复失败时仍会显示错误和重试入口。

## 验证与已知问题

- 本版的同提交 CI、Android 与八套 Linux 发行版兼容检查，以及发行签名与安装包核验，以 Actions 记录和发布收据为准。
- 导入表单的名称和地址已在 Linux ARM64 客户端实测保存。Android 原生软键盘及 Windows、macOS 手动编辑长文本仍待实测。
- macOS 上开启保护后整机重启仍待实测，已报告的首次启动错误尚未确认根因。

## Updates

- Single-line fields on desktop and Android scroll horizontally with the cursor. You can reach and edit text beyond the visible area in the quick subscription URL field, both fields in the import form, and search fields.
- Claude reports adapt the number of columns to the screen width. Cards of different heights keep consistent spacing within each column.
- On macOS, if the network helper is restoring DNS settings left by the previous run, the app waits briefly for the helper before continuing. Recovery failures still show an error and offer a retry.

## Verification and known issues

- See the Actions records and release receipt for CI on this commit, compatibility checks on Android and eight Linux distributions, release signing, and package verification.
- The Linux ARM64 client was tested by saving both the name and URL from the import form. Long text editing with the native Android keyboard and manual checks on Windows and macOS are still pending.
- A full macOS reboot with protection enabled still needs native testing. The cause of the reported first-start error remains unconfirmed.
