# Clash of Rust 0.6.0

新增 Android 支持，适用于 Android 8.0 及以上的 ARM64、ARMv7 与 x86_64；继续支持 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上），以及 macOS 14 及以上的 Intel / Apple Silicon。iOS 暂不提供安装包。

## 更新内容

### Android 客户端

- 接入 Slint 原生界面、内嵌 mihomo 与系统 VPN，覆盖订阅与文件导入、节点选择与测速、连接速率和详情、规则编辑、日志、网络诊断、IP 检测及 A÷检测。界面适配手机竖屏、横屏与平板，字号跟随 Android 系统设置，支持系统非线性字体缩放。
- 支持按应用分流、系统快捷设置磁贴与前台 VPN 服务。完成首次 VPN 授权后，磁贴可静默连接或断开，也可在应用进程退出后恢复内核；磁贴显示真实连接状态。关闭界面保留连接，可在系统 VPN 设置中启用始终开启的 VPN。
- Claude 保护先完成系统授权，再临时启用 VPN、代理加密 DNS、IPv6、UDP 与实时拦截；固定当前具体节点并锁定自动策略组。开启成功后自动检测，关闭或失败时恢复原设置与应用分流，取消授权后不会因迟到的确认而连接。
- 支持正式版更新检查，验证 APK 校验值、包名、签名、版本与架构后交给系统安装界面确认。APK 按架构提供，保持单包体积；多数手机和平板请选择 ARM64。

### 桌面与共享交互

- 连接列表统一背景，表头保留正序、倒序与恢复原序；使用固定尺寸矢量箭头并主动重绘，修复 Windows、Linux 等平台快速切换排序时箭头未刷新的问题。
- 修复 Geo 更新期间无法调整强调色的问题，保留节点延迟原有的绿、黄、红颜色。简化订阅页入口，将文件导入合并到“添加订阅”；桌面和移动端统一浮动通知、内核状态及“订阅 | 节点”显示。
- 图标通知测试与 Claude 拦截共用原生系统通知入口。Windows 补齐应用通知身份与激活注册，兼容首次通知尚无设置记录的情况；macOS 首次启动请求通知授权，Linux 使用桌面 D-Bus 通知。
- 修复 Windows 窗口移出屏幕后重新显示产生白边，以及拖动窗口时界面停止刷新的问题。
- 单组与全部测速覆盖独立、嵌套的自动策略组及 provider 节点，使用各组自己的测试地址；测速完成后让普通自动组重新选优。Claude 保护期间继续锁定节点，关闭后恢复原自动或手动选择。

### 构建与验证

- CI 与 Publish Release 增加三种 Android ABI 的构建和打包，检查 APK 架构与 16 KiB 对齐；x86_64 模拟器覆盖实际界面、系统字号、首次 VPN 授权、代理/TUN、后台运行、重建及快捷磁贴操作。
- 构建优先使用 GitHub 缓存，缺失时从私有完整快照恢复，再回退上游；每次检查依赖与工具更新，网络故障使用兼容缓存。打包复用同一提交已通过 CI 的程序、资源与依赖清单，附件保留 3 天。
- 桌面继续覆盖源码单元测试及真实系统代理/TUN。内存基准使用 100 节点、5 个策略组和 1,000 条规则的低强度固定输入，实验条件与实测结果见 [README](../../README.md#内存占用)。

Windows 运行安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。桌面升级保留订阅和个人设置。

Android 安装对应架构的 APK，首次连接时允许 VPN 授权。可在快捷设置中添加 Clash of Rust 磁贴；在线更新需要允许本应用安装更新包，由系统确认安装。后台使用可结合系统 VPN 与电池设置调整，强行停止应用会断开连接。
