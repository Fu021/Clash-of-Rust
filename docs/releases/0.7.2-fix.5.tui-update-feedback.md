# 0.7.2-fix.5.tui-update-feedback

## 更新

- TUI 节点排序改为一个入口，循环切换名称、延迟升序和延迟降序并显示当前模式；小终端自动压缩，手机 SSH 等极小窗口仍尽力显示和操作。
- TUI 常用业务设置提供开关、选项和编辑框，保存后读回实际状态，失败保留草稿；连接详情补齐原始域名与嗅探信息，搜索覆盖两种域名。
- 网络工具箱收敛为十二项，各自提供独立证据；运行信息回归连接和节点详情，路由追踪逐跳解释无响应，不将星号误判为断网。
- 桌面更新安装失败后恢复可见警告，重新打开仍可查看未确认的失败；初始化成功、通道刷新和其他错误关闭不会吞掉待确认的提示。
- Android 服务警告在前台实际呈现后才确认事件，严重提示遮挡、后台回调或确认失败时保留待呈现事件。

## 验证与已知问题

- 发布提交 `c40b9136d319473294f4c2e42a3d9499c6e7fc0c` 的 CI、Android 8.0～16 十一个系统版本、Ubuntu 20.04 双架构及发行签名流程均通过；实际验证范围以同提交 Actions 与发布回执为准。
- TUI 连接详情的空字段展示、设置分类、部分空值、快捷规则去重与订阅选择交互仍需完善。
- Linux TUI 内存基准来自本轮功能实现提交：退出后前端释放，后台内存未完全回落；不保证长期或其他平台零增长。
