# 0.6.7-fix.7.settings-storage

本次预发布主要改善安装与设置保存、代理恢复，以及桌面和 Android 的使用体验。

## 主要更新

- 修复 Windows 安装后部分下载和设置写入的权限问题；更新重启保留原数据目录与个人设置。
- CLI 增加命令、配置键和值的 Tab 补全；Linux root 可用 `--all-users` 查看其他用户的 TUN 持有进程。
- 改进 TUN 启动检查与控制连接恢复；订阅、Geo 和应用更新继续优先代理，失败后尝试内核直连。
- 桌面加入窗口内控制按钮与侧栏折叠，优化设置页导航、滚动和窗口缩放表现。
- 代理与订阅页支持宫格／紧凑列表切换；修复本地订阅无法编辑、删除，以及移动订阅页的布局崩溃。
- Android 新增应用分流，可选择代理全部应用、仅代理选中应用或排除选中应用。
- 精简节点不可达提示；普通通知 5 秒后关闭并显示倒计时，错误提示保留诊断与恢复入口。
- CI 集中完成候选包和基础代理／TUN 验证，发布复用已验收的安装包。

## 已知限制

- 长时间 TUN 运行后间歇 TLS 握手失败的首次触发原因仍未定位；路由检查不代表所有网络环境均已覆盖。
- 真实设备、长期运行、重启／休眠与人工授权交互仍需结合实际反馈。完整窗口、更新回滚等专项按需执行，不能从常规 CI 通过推断全部场景通过。
