# Clash of Rust 0.5.3

适用于 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64，以及 macOS 14 及以上的 Intel / Apple Silicon；升级保留订阅和个人设置。

## 更新内容

- 新增 macOS 原生客户端与 DMG 安装包，支持 Intel 和 Apple Silicon，沿用深浅主题、订阅、节点、规则管理、连接与 IP 检测页面。
- macOS 系统代理使用原生接口，保留原有代理、PAC 与例外设置；关闭时检查设置是否仍由客户端持有，避免覆盖其他软件后续的修改。
- macOS 支持托盘和登录后台启动；托盘在系统主线程创建、更新与销毁，登录自启以普通用户运行。
- macOS TUN 按需请求管理员授权，界面保持普通用户权限；会话结束或界面进程异常退出后清理内核与网卡，并恢复内核生成缓存的用户写入权限，无需安装永久管理员服务。
- 适配 macOS 应用资源、数据目录与自动更新安装流程，支持更新校验、替换失败恢复及重新启动。
- CI 与打包扩展至六个平台，macOS 两种架构均原生编译；增加真实系统代理、登录自启、TUN 生命周期与安装后运行测试，保存逐项诊断报告、日志、崩溃信息和九个页面的深浅色截图。

Windows 双击安装程序；Debian/Ubuntu 执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）**，随后从应用程序目录启动。每个安装包附带 `.sha256` 校验文件。

macOS 开启系统代理或 TUN 时可能请求管理员授权；登录自启在下次登录后生效，后台启动不会自动弹出 TUN 授权。

## macOS 使用说明

当前 Mac 安装包使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。首次打开若提示无法验证开发者，确认安装包来自本项目且校验值一致后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在尝试启动后进入“系统设置 → 隐私与安全性”，选择“仍要打开”。

两种 Mac 架构已通过自动 CI 和安装包测试。首次下载的 Gatekeeper 提示、授权弹窗、真实注销登录、休眠、多显示器及客户端自动更新交互仍需实机确认，自动测试范围见 [macOS 测试清单](../macos-ci-checklist.md)。
