# 0.6.5-fix.9.user-isolation

此预发布版承接 `0.6.5-fix.6.tailscale-dns`，此前预发布版本继续保留。

- Linux 普通用户使用 `cor` 时保留各自订阅与后台；`sudo cor` 复用调用者的数据和后台，root 可用 `cor profile list --all-users` 只读查看默认目录中的订阅索引，或用 `--user` 指定账户。降权执行时过滤管理员环境，避免跨用户传递凭据。
- 修复 Linux 命令行 TUN 授权和无图形会话的提示：普通用户通过固定助手授权，SSH 和非活动会话仍需管理员认证；没有图形服务的服务器使用 `cor`。
- Claude 保护期间，桌面与 Android 的规则页和代理模式灰置并禁止操作，保留未应用的规则草稿；桌面受保护网络设置同步锁定。关闭保护后恢复操作。
- 新增远程订阅定时更新，默认间隔 360 分钟，可在设置或 `cor config` 调整，设为 0 时关闭。更新失败保留原订阅和运行状态；当前受保护订阅不会定时更新。
- 桌面进入代理页面时将当前使用的策略组置顶并展开，手动收起后不会被后台刷新反复打开。
- Android 将实时保护错误列入风险，并在保护线程停止后保留失败快照。控制接口恢复后清除暂时不可用提示，同时保留通知失败、拦截失败和异常连接历史。

预发布版本可能存在尚未发现的问题，建议先备份配置。Android 使用长期发行签名；从预发布返回正式版时，无法保证保留数据完成降级。macOS 安装包使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。

真实设备上的交互式授权、登录自启、长时间订阅定时更新、Tailscale 网络变化和实际下载吞吐仍需现场验收。
