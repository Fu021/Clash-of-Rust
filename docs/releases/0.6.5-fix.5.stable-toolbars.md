# 0.6.5-fix.5.stable-toolbars

此修复分支预发布版本承接 `0.6.5-fix.3.rules-subscriptions`，上一版预发布继续保留。

- Geo、订阅和应用更新下载补充慢速及断流检测与路线回退。失败时保留现有 Geo 数据、用户节点选择和可用代理状态，不因下载异常覆盖现有内容。
- 桌面与 Android 规则页支持拖动排序；拖动中的规则跟随鼠标或手指，列表边缘可连续滚动。手机规则、连接和日志页调整搜索与操作栏布局，为列表内容留出空间。
- 桌面系统代理状态按应用管理的代理字段判断，绕过列表等辅助设置变化不会误报为已关闭；关闭时保留用户后来修改的绕过项。
- macOS 代理恢复合并到最新网络设置，保留非托管属性和新增服务。Windows、GNOME 与 KDE 同步改进绕过项变更后的状态判断和恢复。
- 桌面窗口与 `cor proxy`、`cor status` 使用同一后台实时代理状态，窗口重建不会覆盖后台状态或已保存的启动偏好。

macOS 网络助手升级后首次启用可能需要重新授权。
