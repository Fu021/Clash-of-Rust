# Clash of Rust 0.5.7

适用于 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上），以及 macOS 14 及以上的 Intel / Apple Silicon；升级保留订阅和个人设置。

## 更新内容

### A÷检测

- 新增 **A÷检测** 页面。点击“开始检测”后，自动扫描已记录的 Claude 项目配置，采集本机与内核网络线索，并打开默认浏览器自动检测、回传结果。
- 报告统一显示“正常”和“风险”数量，点击卡片查看具体项目、来源、原因与建议。辅助线索和未确认结果单独查看；语言、时区和字体偏好本身不判为风险。
- 配置扫描检查全局、项目、本地与文件托管设置中的代理绕过、API 地址与提供方覆盖、TLS 验证和格式问题。只读配置、脱敏展示，不执行项目脚本或读取会话对话。
- 可开启“实时检测 Claude 请求”，记录网页版、Desktop 和 Code 使用的 Claude 相关域名连接，查看匹配规则、线路与拨号失败；保留最近 32 条记录及累计数量，切页或隐藏窗口后继续检测，断线自动重连。
- 详情中保留网页同域补充采样和独立终端诊断报告导入。检测用于核对可观察的地区线索与配置风险，结果可能与 Claude 的服务端地区判断不同，详见 [检测说明](https://github.com/Fu021/Clash-of-Rust/blob/v0.5.7/docs/claude-region-detection.md)。

### 桌面操作

- 订阅支持编辑名称和来源，通过原生文件选择器导入 YAML。修改来源后保留现有缓存，更新时校验并载入新内容。
- 删除订阅前确认影响；关闭规则编辑器、放弃草稿、切换规则所属订阅和退出程序时，保护尚未保存的修改。
- 点击连接可查看并复制域名、目标、匹配规则、代理链、实时速度与累计流量。
- 托盘支持快捷选择当前线路的手动决策组节点，可选显示上传与下载速度，默认关闭速度显示。
- 外观支持跟随系统主题及 80–150% 字号。增加 Ctrl/⌘+F 搜索、Esc 关闭弹窗、Enter 提交表单和 Tab/Shift+Tab 焦点切换。

### macOS 交互修复

- 修复关闭窗口后点击 Dock 图标无法重新显示窗口的问题。
- 修复菜单栏图标创建与布局问题，增加图标状态检查和恢复，覆盖 Intel 与 Apple Silicon。
- 原生退出入口先保存窗口尺寸、关闭内核并恢复系统代理，再退出程序。

六平台 [CI](https://github.com/Fu021/Clash-of-Rust/actions/runs/38513690149) 与 [测试打包、安装验证](https://github.com/Fu021/Clash-of-Rust/actions/runs/38515945231) 均已通过；扩充真实浏览器、内核事件、项目配置扫描和桌面交互测试，并保存深浅色界面的实际渲染截图。

Windows 双击安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。每个安装包附带 `.sha256` 校验文件。

macOS 安装包使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。首次打开若提示无法验证开发者，可确认来源及校验值后，在“系统设置 → 隐私与安全性”中选择“仍要打开”，见 [Apple 说明](https://support.apple.com/zh-cn/102445)。
