# Clash of Rust 0.4.7

本版修复客户端更新检查的代理回退，统一更新按钮颜色并调整 Rust 构建配置，也可用于验证 0.4.6 的客户端内更新流程。

## 更新内容

- “更新”和“更新（代理）”使用相同的按钮颜色与交互样式。
- 更新检查依次尝试当前内核代理、系统代理和直连；GitHub API 不可用时改用官方 Release 订阅源，避免网页可达却无法检查版本。
- 检查失败时区分连接超时、域名解析、代理连接和证书校验等原因。
- Release 构建保留最高运行优化等级，改用 16 个代码生成单元、增量编译和局部 LTO；开发构建减少调试信息，降低重复编译和链接开销。

## 下载与安装

| 平台 | 文件 | 安装 |
| --- | --- | --- |
| Windows x64 | `Clash-of-Rust-0.4.7-windows-x64-setup.exe` | 运行安装程序，或从 0.4.6 客户端选择更新 |
| Debian/Ubuntu amd64 | `Clash-of-Rust-0.4.7-linux-amd64.deb` | `sudo apt install ./Clash-of-Rust-0.4.7-linux-amd64.deb`，或从 0.4.6 客户端选择更新 |

每个安装包附带同名 `.sha256` 文件；升级保留订阅和个人设置。代理更新需先启动内核。Windows 自动安装需完成 UAC 授权；Linux 普通用户需要 `pkexec` 与可用的桌面授权服务。

可能造成 Windows Defender 误判查杀，需自行规避。
