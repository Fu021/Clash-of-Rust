# Clash of Rust 0.5.0

适用于 Windows x64 / ARM64 与 Debian/Ubuntu amd64 / ARM64；升级保留订阅和个人设置。

## 更新内容

- 统一九个页面的深浅主题、导航、卡片、表格和表单，提升浅色文字与状态的可读性；代理节点使用紧凑双列布局，选中状态显示边框和勾选标记，小窗口支持滚动查看。
- 设置新增五项订阅附加规则：广告拦截、本地域名、私有 IP、国内域名和国内 IP 直连，默认全部关闭；私有 IP 使用 `GEOIP,Private,DIRECT,no-resolve`。
- 附加规则仅补充订阅缺少的内容，并优先匹配；已有规则的内容与位置、原有兜底规则保持不变。保存后更新运行配置，订阅更新与客户端重启后保留，取消勾选恢复原订阅规则；配置校验失败时保留旧设置与运行配置。
- 内核启动失败或退出时显示原因，提供“重启内核”和“查看日志”；初始化失败也可重新尝试，启动期间避免重复重试。
- 修复点击 IP 检测总结后筛选控件文字残影，代理排序控件同步修复；删除检测总结底部说明小字。
- IP 检测分类计数仅累计绿色和黄色结果，排除受限、失败和未检测项；分类总数与检测完成进度维持各自统计口径。
