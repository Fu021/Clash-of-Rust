# Clash of Rust 0.5.1

适用于 Windows x64 / ARM64 与 Debian/Ubuntu amd64 / ARM64；升级保留订阅和个人设置。

## 更新内容

- 修复 Windows 普通权限开关开机自启时可能出现的 `0x80070005` 拒绝访问：新任务明确授权当前用户；旧任务权限不足时可通过 UAC 修复，校验原账号与安装路径。已提权的 TUN 实例会修复旧任务权限并保留其启用状态。
- 修复任务计划程序不可用时，已成功启用注册表备用启动项仍报告失败的问题。
- 修复自启动、外观等操作失败被误显示为“内核启动失败或退出”的问题，保留真正的内核故障原因；日志与文件保存提示包含完整错误链和失败路径。
- 改善 Windows 配置保存、Geo 文件复制和中断配置事务恢复：关闭临时写入句柄后原子替换，对短暂访问拒绝或共享冲突进行有界重试；持续失败时保留原文件及必要的恢复记录。
- 完善 Windows x64 / ARM64 普通账号回归测试，覆盖真实 GUI 前台与后台启动、旧设置升级、事务恢复、自启动管理和桌面控制；测试分组报告在失败时也会保留。
