# 0.6.7-fix.9.session-lifecycle

## 更新

- Android 界面重建时先结束旧会话及下载，避免迟到结果与新界面同时修改配置。
- Windows 更新新安装包时，授权等待不再阻塞后台状态查询；取消或交接失效保留旧版本。
- 自动检查更新可在设置页保存分钟间隔，0 关闭，默认 360；桌面、Android 和 CLI 配置保持一致。
- Android 检出新版本后显示跨页更新栏，下载进度与安装入口更明显。
- 重做 Android 应用分流：显示应用图标和已保存状态，全部模式收起清单，仅选中与排除选中互切自动反选；支持筛选、撤销及保存后自动重连，修复打开分流页时的布局崩溃。
- 更新兼容范围内的 Rust／Go 依赖及 Geo 数据，同步兼容性与缓存容量说明。
- 优化 CI 重复编译及大缓存收尾，复用 Linux 构建环境与 Android Go 编译，保留 macOS Tailscale；预装 VM 继续仅存私网。

## 验证与已知问题

- 应用修复基线 `8312c60` 的 CI `42785818645` 必需 14 项、不发布核验 `42789444224` 和 Android 8.0～16 截图 `42789444152` 均通过；本轮缓存优化仍须取得新提交的验证，不能复用旧候选包发布。
- 旧 Windows 安装包仍沿用兼容交接，等待授权可能阻塞查询。
- 真机、厂商 ROM、交互授权及长期 TUN／公网间歇超时仍未验收或定位。
