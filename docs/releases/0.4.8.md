# Clash of Rust 0.4.8

客户端更新和订阅更新统一为一个“更新”按钮，自动选择可用代理并在失败时回退。

## 更新内容

- 客户端安装包下载、订阅导入与更新，和版本检查共用连接策略：依次尝试当前运行内核的代理、系统代理和直连。
- 内核未启动时，可通过系统代理或直连完成更新，无需手动选择下载方式。
- 安装包下载切换连接时从头下载，重新验证文件大小与 SHA256，校验完成后自动安装并重启。
- 所有连接均失败时，上方状态栏显示简要原因并撤掉下载进度条，允许再次尝试。订阅仍在校验成功后才保存配置。

## 下载与安装

| 平台 | 文件 | 安装 |
| --- | --- | --- |
| Windows x64 | `Clash-of-Rust-0.4.8-windows-x64-setup.exe` | 运行安装程序，或从已支持自动更新的客户端选择更新 |
| Debian/Ubuntu amd64 | `Clash-of-Rust-0.4.8-linux-amd64.deb` | `sudo apt install ./Clash-of-Rust-0.4.8-linux-amd64.deb`，或在客户端选择更新 |

安装包由对应提交的 Windows/Linux CI 构建，每个安装包附带同名 `.sha256` 文件。升级保留订阅和个人设置。Windows 自动安装需完成 UAC 授权；Linux 普通用户需要 `pkexec` 与可用的桌面授权服务。

可能造成 Windows Defender 误判查杀，需自行规避。
