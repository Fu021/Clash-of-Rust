# Clash of Rust 0.6.3

本次更新降低关闭窗口后的常驻内存占用，关闭窗口后释放界面进程，并完善 macOS 通知权限、GUI 与 CLI 联动、DNS 兼容及预发布版本更新。支持 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上）、macOS 14 及以上的 Intel / Apple Silicon，以及 Android 8.0 及以上的 ARM64 / ARMv7 / x86_64。

## 更新内容

### 桌面内存与窗口

- 界面改为可单独退出的进程。关闭窗口后释放界面资源，托盘、内核和代理继续运行；再次打开时重建窗口并恢复页面。
- 减少界面数据传递、常驻代码与启动缓存占用，隐藏页面不再保留不需要的列表。
- 保存普通窗口的位置与尺寸，并恢复最大化状态。
- 修复 macOS 多次关闭、打开窗口后 Dock 出现重复应用图标的问题，统一宿主与界面进程的应用身份。

### 通知与后台联动

- macOS 在首次安装或更新后检查通知权限；尚未申请时请求授权，已被拒绝时提供前往系统设置的入口。
- GUI 与 `cor` 共享后台状态；CLI 修改订阅、规则、节点或设置后，窗口及时刷新，并保留尚未保存的编辑草稿。
- 避免 GUI 与 CLI 重复执行定时测速；后台退出或重启后，窗口可重新连接。
- 内部控制端口由后台管理，遇到冲突自动选择可用端口，不再作为用户设置项；继续仅监听本机并使用随机密钥。
- Android 常驻 VPN 通知显示当前节点、运行模式和上下行速度，关闭界面或使用快捷磁贴启动时仍可更新。
- 调整 Android VPN 重建顺序，待系统确认新接口与路由就绪后再交接内核收包栈；加强连续五次重建的真实流量测试，并在失败时记录接口、路由与描述符诊断。

### DNS 与 Claude 检测

- DNS 覆盖补充 Tailscale、NetBird、WARP、RustDesk、Syncthing、STUN/TURN 及常见本地与系统探测域名的真实 IP 解析，减少与 Fake-IP 的冲突；保留订阅已有过滤规则及其匹配方式。
- 这些 DNS 例外只改变解析结果，出站仍按用户规则处理。
- Claude 连通性检测遇到 Cloudflare 验证挑战时列为其他线索，避免仅凭 HTTP 403 判定地区风险；不自动完成验证或提交账号信息。

### 客户端更新与界面

- 默认只检查正式版，设置中可开启“包含预发布版本”；关闭该选项后，预发布版本可选择返回正式版。CLI 沿用同一设置。
- 桌面与 Android 安装预发布版前显示风险提示，等待 3 秒后才能确认；切换更新通道会清除旧版本提示，过期检查结果不再覆盖当前状态。
- Android 仍遵循系统安装限制：无法覆盖安装更低的版本代码，遇到该情况会明确提示；不自动卸载或删除用户数据。
- 订阅流量与到期信息改为简写，桌面订阅链接移至卡片下方；统一连接详情样式，压缩快捷规则区域并保留规则分页。
- 更新 Geo 数据时按钮文字保持不变，进度由进度条显示。
- 修复日志详情正文不可见及分页、筛选后滚动位置残留；桌面与移动端的新页面、分类和详情从顶部显示，后台刷新保留阅读位置，内容缩短时自动校正。
- 修复 GNOME 系统代理遗留旧 SOCKS 端口的问题，HTTP、HTTPS、SOCKS 同步使用混合端口，并兼容旧版本的设置恢复记录。

### 内存基准

完成 [0.6.3 低强度内存基准](https://github.com/Fu021/Clash-of-Rust/actions/runs/39991398433)，固定输入为 100 节点、5 个策略组、1,000 条规则：

| 场景 | 客户端 RSS | 客户端 PSS | 客户端与内核合计 PSS |
| --- | ---: | ---: | ---: |
| 首页 | 47.23 MiB | 37.52 MiB | 83.13 MiB |
| 关闭窗口、驻留托盘 | 19.44 MiB | 14.23 MiB | 59.66 MiB |
| 纯 CLI 后台运行 | 14.00 MiB | 10.17 MiB | 53.34 MiB |

已验证窗口关闭后界面进程退出、内核持续运行，以及连续开关窗口 20 次。完整环境、其他场景与测量口径见 [README](https://github.com/Fu021/Clash-of-Rust/blob/v0.6.3/README.md#内存占用)。

Windows 运行安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。Linux Server 安装同一份 DEB 后，可在 SSH 中直接使用 `cor`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。桌面升级保留订阅和个人设置。

Android 安装对应架构的 APK，首次连接允许 VPN 授权；可在系统快捷设置中添加开关磁贴。在线更新由系统确认安装。
