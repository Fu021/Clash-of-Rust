# 0.6.6-dev.2.vm-package-timeout

此预发布版承接 `0.6.5`，此前预发布版本继续保留。

- Linux x64/ARM64 改用 Ubuntu 20.04 用户空间构建，并以 Ubuntu 20.04 5.4 GA 内核、22.04 和最新版验证同一份 DEB；最低支持基线降至 Ubuntu 20.04，Ubuntu 18.04 仍不在支持范围内。安装包逐个检查 ELF 依赖与 `GLIBC 2.31` 上限。
- 发布验证补齐 Ubuntu 安装后的 X11/Wayland、托盘、窗口重建、GUI/CLI 共用内核、图形授权、系统代理与 TUN 检查；Windows 增加普通用户安装后窗口和共享状态验证，Android 增加 Activity 重建检查，并沿用 macOS 原生生命周期验证。
- 延长 IPv6 节点域名的 AAAA 解析等待，避免慢解析被误判为无地址；mihomo 版本声明改为按实际桌面或 Android 依赖生成，避免自动更新后保留过期来源。
- Geo 更新区分提交失败与提交后的备份清理失败，已成功安装的新数据不会因旧备份清理异常而回退；后续恢复会继续清理遗留备份，Android 重载保留现有 VPN。
- macOS 从保存的 TUN 或 Claude 保护状态启动时直接交给授权助手，窗口连接已有后台时委托实际所有者启动；动态 DNS 分域在变化后通过原生探针确认就绪。
- 桌面订阅、Geo 和 CLI 客户端更新不再占用共享后台锁，下载可取消，迟到结果不能覆盖新状态；macOS DMG 校验和授权等待移到锁外，并在交接前复核请求。
- 修复订阅导入兼容、窗口重建后的运行状态、托盘启动所有者、Android 渲染表面释放和更新设置布局，统一 Geo、软件更新与测速的显示位置。

预发布版本可能存在尚未发现的问题，建议先备份配置。Android 使用长期发行签名；从预发布返回正式版时，无法保证保留数据完成降级。macOS 安装包使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。

真实设备上的交互式授权、登录自启、休眠、真实下载吞吐、旧系统实际硬件及 macOS 更新现场仍需单独验收。
