# Clash of Rust 0.5.11

适用于 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上），以及 macOS 14 及以上的 Intel / Apple Silicon；升级保留订阅和个人设置。

## 更新内容

### Slint 桌面界面

- 桌面界面迁移到 Slint，统一页面、表单、列表及弹窗的字号、对齐与间距，改善浅色主题的文字和控件对比度；保留深色、浅色及跟随系统，提供六种强调色与 80–150% 字号设置。
- 节点单击选择，策略组标题单击展开或收起；新配置默认按名称排序，保留延迟升降序及已保存的排序偏好。修复下拉框选择不生效的问题，覆盖节点排序、规则编辑和检测筛选等操作。
- 统一按钮的按下与松开反馈，修复鼠标点击后持续高亮的问题；保留键盘焦点提示及主题、代理模式等真实选中状态。
- 连接详情补全域名、IP、端口、协议、规则、代理链、速率及流量等信息，支持换行与复制；缺失目标 IP 时按需查询，关闭详情即取消，保留内核已知地址。
- 日志支持按等级和文本组合筛选，逐条点击查看完整内容并复制；选中规则的操作面板移到列表上方。IP 检测使用离线国旗图片，避免系统字体缺失造成显示异常。
- 顶部通知增加计时细线，8 秒后自动收起；网络切换进度显示在页面内，点击左上角图标可触发“喵!”系统提示。设置中的网络端口、窗口尺寸与恢复按钮重新整理；macOS 按屏幕可用范围恢复窗口，避免超出屏幕或反复调整尺寸。
- 修复 Linux 启动时 Slint 后端未初始化导致窗口无法打开的问题；macOS 托盘与界面共用原生菜单依赖，避免菜单类冲突。

### 网络与 Windows TUN

- Windows 通过按需启动的网络服务管理 TUN。首次安装或助手需要修复时完成管理员授权，之后重启电脑仍可复用，GUI 与日常设置操作保持普通权限；空闲服务自动退出，并清理异常退出客户端遗留的内核。
- 补充连接域名嗅探，同时保留已有的 DNS／代理域名，避免被其他 SNI 名称覆盖后匹配错误规则。
- Claude 保护优先保留原有节点 DNS、分流与引导配置，兼容 IPv6 DNS 地址，避免固定公网引导 DNS 不可达导致节点和加密 DNS 一起失效；公网解析仍固定经过保护节点。macOS 保留接管前的系统 DNS，避免节点解析递归。
- 开启保护后实际验证上游 DNS，失败时恢复原网络及配置；关闭后恢复原代理模式、DNS、UDP、规则和节点选择。相关限制与隐私范围见 [检测说明](../claude-region-detection.md)。

### 项目与验证

- 项目整理为共享业务、Slint 界面与桌面宿主的 Cargo workspace；Android、iOS 和移动桥接目录仅作后续宿主占位，本版仍为桌面应用。
- 长期工作流保留 CI、Publish Release、Memory Benchmark；截图与临时工作流已移除并禁用。打包复用同一提交的成功 CI 产物，界面使用正式 Slint 组件独立预览。
- [六平台 CI](https://github.com/Fu021/Clash-of-Rust/actions/runs/38874532203) 和[安装包验证](https://github.com/Fu021/Clash-of-Rust/actions/runs/38876537885)通过，包含普通用户系统代理/TUN、Windows 服务恢复与清理，以及 Ubuntu 新版兼容检查。Linux 额外验证双栈节点、固定引导 DNS 不可达、经节点的加密 DNS、TCP/UDP DNS 接管、实际 HTTP 转发、冷重启和失败恢复。
- 完成 [0.5.11-dev.1 低强度内存基准](https://github.com/Fu021/Clash-of-Rust/actions/runs/38878584013)：Ubuntu 22.04 x64、Release、100 节点与 1,000 条规则，首页 GUI RSS 43.46 MiB、GUI 与内核合计 PSS 81.67 MiB；节点搜索时分别为 53.07 MiB 和 97.51 MiB。实验版本与条件及其他场景见 [README](../../README.md#内存占用)。

每个安装包附带 `.sha256` 校验文件。

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | [Clash-of-Rust-0.5.11-windows-x64-setup.exe](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.11/Clash-of-Rust-0.5.11-windows-x64-setup.exe) |
| Windows ARM64 | [Clash-of-Rust-0.5.11-windows-arm64-setup.exe](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.11/Clash-of-Rust-0.5.11-windows-arm64-setup.exe) |
| Debian / Ubuntu 22.04+ amd64 | [Clash-of-Rust-0.5.11-linux-amd64.deb](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.11/Clash-of-Rust-0.5.11-linux-amd64.deb) |
| Debian / Ubuntu 22.04+ ARM64 | [Clash-of-Rust-0.5.11-linux-arm64.deb](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.11/Clash-of-Rust-0.5.11-linux-arm64.deb) |
| macOS Intel | [Clash-of-Rust-0.5.11-macos-x64.dmg](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.11/Clash-of-Rust-0.5.11-macos-x64.dmg) |
| macOS Apple Silicon | [Clash-of-Rust-0.5.11-macos-arm64.dmg](https://github.com/Fu021/Clash-of-Rust/releases/download/v0.5.11/Clash-of-Rust-0.5.11-macos-arm64.dmg) |

Windows 双击安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。

Windows 网络服务首次安装或修复时需要管理员授权，正常使用及重启后复用服务；macOS 的系统代理与 TUN 继续共用本机网络助手。

macOS 安装包使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。首次打开若提示无法验证开发者，可确认来源及校验值后，在“系统设置 → 隐私与安全性”中选择“仍要打开”，见 [Apple 说明](https://support.apple.com/zh-cn/102445)。
