# Clash of Rust 0.4.9

本版增加取消更新下载，并提供 Windows 和 Debian/Ubuntu 的 ARM64 安装包。

## 更新内容

- 客户端更新下载期间显示“取消下载”按钮：取消后停止下载、清理临时文件并撤掉进度条，可重新点击更新。已取消的下载不会继续安装；进入安装阶段后不再提供取消下载按钮。
- 增加 Windows ARM64 与 Linux ARM64 的原生 CI 构建、测试和打包，并适配 ARM64 内核资源、Windows 安装器与客户端自动更新。
- 精简 README，明确支持的系统与架构。

## 下载与安装

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `Clash-of-Rust-0.4.9-windows-x64-setup.exe` |
| Windows ARM64 | `Clash-of-Rust-0.4.9-windows-arm64-setup.exe` |
| Debian/Ubuntu amd64 | `Clash-of-Rust-0.4.9-linux-amd64.deb` |
| Debian/Ubuntu ARM64 | `Clash-of-Rust-0.4.9-linux-arm64.deb` |

Windows 运行对应架构的安装程序；Debian/Ubuntu 使用 `sudo apt install ./安装包文件名.deb`。每个安装包附带同名 `.sha256` 文件，升级保留订阅和个人设置。

支持自动更新的已安装客户端也可直接更新。Windows 自动安装需要 UAC 授权；Linux 需要 `pkexec` 与桌面授权服务。

可能造成 Windows Defender 误判查杀，需自行规避。
