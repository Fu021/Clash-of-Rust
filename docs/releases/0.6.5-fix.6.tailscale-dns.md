# 0.6.5-fix.6.tailscale-dns

此预发布版承接 `0.6.5-fix.5.stable-toolbars`，此前预发布版本继续保留。

- 修复 macOS 开启 Claude 保护时与 Tailscale MagicDNS 的共存问题：公网解析进入本机 DNS 转发器并经保护节点访问加密 DNS，保留 Tailscale 私有分域、搜索域与接口绑定，不要求用户手动调整 DNS。
- DNS 就绪检查等待原生解析器实际接管，处理 Tailscale 重连和配置变化；公共解析失败不会回退到 VPN 或物理网络 DNS。关闭保护时恢复仍由本应用管理的字段，保留外部修改。
- 修复 DNS 就绪探针注销后的延迟重发，避免内部探针进入上游；修复 macOS 内核退出后端口释放等待的误判，保留实际绑定成功的启动门槛与等待上限。
- 开启 Claude 保护后先中断已有内核连接，再验证加密 DNS，失败时恢复原配置；桌面、Android 与 `cor` 使用相同的保护切换语义。
- 修复 Geo 更新时旧文件损坏、缺失或与旧清单不符导致的校验阻塞，保留新数据校验、整组安装与失败恢复。
- 修复桌面规则拖动手柄的命中区域，保持 Windows、macOS、Linux 与 Android 的规则浮起跟随和边缘自动滚动。
- 修复递归 DNS 国家数据误报：按 Google Public DNS 官方 geofeed 匹配地址，修正检测服务的错误国家并保留原始标签和来源。修正后国家仍与出口不同的继续列为风险，不把递归 DNS 整体移入“其他线索”；清单不可用、冲突或没有匹配时保留原数据与差异判定，无法获得国家的结果列为未确认。桌面、Android 与 `cor` 同步，正常、风险与其他线索的数量不再重复计数。
- 桌面与 Android 的实际递归 DNS 国家显示复用 IP 检测国旗素材；港澳台保留国家文字，不显示旗帜。

macOS 网络助手协议升级为 7，首次启用新版助手可能需要正常管理员授权。当前 macOS 安装包使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。

递归 DNS 的地区与代理出口仍可能不同。本次对照中检测服务将 Google 地址标为美国，Google 官方清单则将对应网段标为德国法兰克福；此版本修正地区来源与告警判定，不代表客户端的完整 DNS 路径已排除泄漏。真实 Tailscale 网络、接口与出口变化及用户现场仍需实机验收。

预发布版本可能存在尚未发现的问题，建议先备份配置。Android 使用长期发行签名；从预发布返回正式版时，无法保证保留数据完成降级。
