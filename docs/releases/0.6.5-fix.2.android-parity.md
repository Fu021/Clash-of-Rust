# 0.6.5-fix.2.android-parity

此版本为修复分支预发布版本，供确认功能和兼容性使用。

- Android 补齐 Fake-IP 排除项的来源展示、添加/删除及内置项一键还原。
- 规则表单与桌面共用类型，支持 no-resolve 和启停；移动规则页使用长按拖动与独立操作菜单，支持跨页移动、来源筛选和恢复订阅顺序。
- IP 检测增加搜索、结果/地区筛选、详情与单项重测；A÷检测适配 Android 网络和浏览器，支持取消及可选信誉密钥。
- 更新下载可取消并清理未完成缓存，提供 Release 入口；默认更新通道跟随最新正式版，包含预发布选项开启时才比较正式与预发布版本。
- 修复 Android 连接、规则、日志列表重叠，压缩 Pad 分页操作区，并将桌面和 Android 的设置入口独立放在底部。
- 更新直接依赖与平台接口，替换停止维护的 YAML 和私有协议序列化依赖。

Android 继续使用系统 VPN、前台服务、通知与安装确认，不扫描 Claude Desktop 或 CLI 项目。关闭“包含预发布版本”可能提示返回正式版；Android 不支持直接覆盖较低 versionCode，需备份后由用户手动卸载重装。
