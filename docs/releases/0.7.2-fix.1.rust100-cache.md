# 0.7.2-fix.1.rust100-cache

## 更新

- 修复 Claude 保护开启瞬间短暂误报 TUN 绕行，以及保留保护状态退出后再次启动内核失败的问题。
- 修复 Android 应用分流把含 Emoji 的正常节点误判为失效；恢复保护前的 UDP 设置，继续遵守用户的 UDP 开关。
- 改进自动策略组切换节点时的更新下载恢复，避免长时间停留在无进展的直连阶段。
- 加强安装包资源压缩，保留内核、Geo、字体、签名和诊断功能；升级 Rust 1.100，关闭 ThinLTO，重建按平台隔离的编译缓存。

## 验证与已知问题

- 发布前完成同提交 CI、Android 8.0～16、Ubuntu 20.04 两架构及发行签名验证；安装包大小、缓存与内存以实际产物和基准为准。
- 真实设备、厂商 ROM、长期 TUN 和网络切换仍需反馈确认；间歇 TLS 失败和部分长连接下载慢速仍在排查。
