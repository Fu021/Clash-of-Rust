# Clash of Rust 0.5.6

适用于 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上），以及 macOS 14 及以上的 Intel / Apple Silicon；升级保留订阅和个人设置。

## 更新内容

- 修复 macOS 使用过 TUN 后切回系统代理，自动更新或重启内核时误报端口占用的问题。等待旧内核退出及连接状态释放后复用原端口，无需来回修改端口；真实端口占用仍会提示错误。
- 减少 macOS 切换系统代理与 TUN 时的重复授权：复用有效授权会话，代理设置已符合目标时跳过重复写入；授权失效或需要新权限时仍由系统确认。
- 修复 macOS 登录自启时先恢复、再启用系统代理造成的重复授权。启动时保留属于本客户端且端口一致的代理设置，内核启动失败则恢复原系统代理。
- 修复 macOS 关闭开机自启可能终止当前程序的问题。开关自启只修改当前用户的登录配置，无需管理员授权，当前窗口与内核继续运行。
- 扩充 macOS Intel 与 Apple Silicon 原生测试至 16 个 GUI 场景，覆盖代理切换、开机自启、TUN 切回系统代理后的更新，并增加真实 root TCP 连接关闭后的端口复用测试。六平台 CI、打包与安装测试均已通过。

Windows 双击安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。每个安装包附带 `.sha256` 校验文件。

macOS 安装包使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。首次打开若提示无法验证开发者，可确认来源及校验值后，在“系统设置 → 隐私与安全性”中选择“仍要打开”，见 [Apple 说明](https://support.apple.com/zh-cn/102445)。
