# 0.7.4-dev.1.yaml-overrides

## 更新

- 新增全局 YAML 覆写。可添加规则集及前置、追加规则，刷新订阅后会重新合并，不改写原始订阅。规则页已经应用的自定义规则也会按订阅保留。
- 订阅详情可查看原始 YAML 和运行 YAML。内置编辑器提供行号、基础高亮、复制和查找；桌面也可用系统默认编辑器修改全局覆写。
- 更新客户端后，若安装包内的 Geo 数据经校验且更新，会自动替换旧数据；本机有更新或无法比较时保留有效的本机数据。

## 验证与已知问题

- Linux ARM64 实测了编辑、查找、复制、外部保存和临时文件清理，以及规则集在订阅刷新前后的实际分流。
- Android 真机输入法及 Windows、macOS 默认外部编辑器的保存和清理尚未手动验收。全局覆写暂不支持策略组合并。
- 本版同提交 CI、Android 和八个 Linux 发行版的兼容性检查，以及发行签名和安装包核验，以 Actions 和发布收据为准。

## Updates

- Added global YAML overrides for rule providers and rules that are prepended or appended. Overrides are reapplied after a subscription refresh without rewriting the original subscription. Applied custom rules from the Rules page are also kept per subscription.
- Subscription details can show the original YAML and the runtime YAML. The built-in editor provides line numbers, basic highlighting, copying, and search. On desktop, you can also edit the global override with your system's default editor.
- On app upgrade, verified bundled Geo data replaces older local data. Valid local data is kept if it is newer or the versions cannot be compared.

## Verification and known issues

- Editing, search, copying, external saves, temporary file cleanup, and actual rule-set routing before and after a subscription refresh were tested on Linux ARM64.
- Native Android input methods and saving and cleanup with the default external editor on Windows and macOS have not been manually tested. Global overrides do not yet support merging proxy groups.
- See Actions and the release receipts for CI on this commit, Android and eight Linux distribution compatibility checks, release signing, and package verification.
