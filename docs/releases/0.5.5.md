# Clash of Rust 0.5.5

适用于 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上），以及 macOS 14 及以上的 Intel / Apple Silicon；升级保留订阅和个人设置。

## 更新内容

- 新增客户端网络配置：DNS 覆盖与 IPv6 默认开启，可在设置中独立关闭，修改后自动校验、保存并应用。DNS 覆盖使用 Fake-IP 与腾讯、阿里 DoH，保留订阅的解析策略、节点解析与过滤列表；关闭后沿用订阅配置，订阅缺少 DNS 时补充默认配置。IPv6 同时控制内核与 DNS，原始订阅文件保持不变。
- 启用 TCP 并发、统一延迟与 30 秒连接保活；TUN 使用 mips 协议栈，Geo 数据采用节省内存的加载方式，出站网卡继续自动检测，日志级别保持不变。
- 修复 macOS 自动更新停留在等待授权或安装阶段的问题：安装助手就绪后正常退出旧客户端，再替换应用并以普通用户身份重启；支持用户目录与系统目录安装，替换失败时恢复旧版，在只读 DMG 中运行时提示先安装应用。
- 改善 macOS 系统代理与 TUN 授权，明确反馈取消、拒绝与超时；修复长时间使用后内核重启失败、数据目录路径别名和授权内核关闭后的端口误判问题，保留对真实端口占用的检查。
- 扩充 macOS Intel 与 Apple Silicon 原生 CI 和安装后测试，覆盖 12 个真实 GUI 场景，包括 TUN、授权取消与超时、自动更新校验、普通用户重启和替换失败恢复；保存逐项报告与日志，DMG 操作对资源忙进行有限重试。

Windows 双击安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。每个安装包附带 `.sha256` 校验文件。

macOS 安装包使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。首次打开若提示无法验证开发者，可确认来源及校验值后，在“系统设置 → 隐私与安全性”中选择“仍要打开”，见 [Apple 说明](https://support.apple.com/zh-cn/102445)。
