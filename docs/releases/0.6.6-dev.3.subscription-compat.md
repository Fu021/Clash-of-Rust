# 0.6.6-dev.3.subscription-compat

本次预发布重点修复部分机场误识别客户端后返回提示节点或错误订阅格式的问题。包含 `0.6.6-dev.2.vm-package-timeout` 的全部改进，上一版预发布继续保留。

- 补齐订阅请求中的 Clash Meta/mihomo 能力标识，以及 Clash Verge、Clash Meta for Android、v2rayN、v2rayNG 等兼容标识，桌面 GUI、`cor` 与 Android 同步生效。
- 为订阅格式增加有界回退：服务端返回非 YAML、拒绝客户端或只下发重复的“不支持协议”提示节点时，移除可能触发其他格式的 v2rayN/NG 标识后重试，保留 Mihomo 系客户端兼容标识。两次请求共用原有超时上限，不转换 VLESS、Shadowsocks 等节点协议。
- 协商失败保留现有订阅、设置及运行状态；提示旁仍有真实节点或 provider 的配置继续保留。认证失败、限流和服务端故障不会反复切换客户端标识请求。
- 延续 Ubuntu 20.04 x64/ARM64 基线及安装后 GUI、代理/TUN 验证，保留此前 IPv6 慢解析、Geo 更新恢复、macOS 启动和后台下载改进。

如果机场链接已固定为旧格式，请在机场重新获取 Mihomo/Clash Meta YAML 订阅链接。客户端标识兼容不能保证所有机场定制接口可用，Issue #30 的真实订阅仍需用户复测。

预发布版本可能存在尚未发现的问题，建议先备份配置。Android 使用长期发行签名；从预发布返回正式版时，无法保证保留数据完成降级。macOS 安装包使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。
