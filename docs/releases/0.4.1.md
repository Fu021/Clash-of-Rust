# Clash of Rust 0.4.1 — 开发预览版

**本版本仍为开发预览版，欢迎反馈使用中遇到的问题。**

本次更新更换中英文字体，新增 IP 与平台地区访问检测，并优化界面、配置处理和后台任务的内存占用。

## 字体与界面

- 中文字体更换为**思源黑体（Source Han Sans CN）**，英文与数字使用 **Segoe UI**，覆盖中英文混排与输入框。
- 思源黑体随程序内嵌，无需额外安装；Segoe UI 使用 Windows 提供的系统字体。
- 地区旗帜使用内置图像显示，减少系统字体差异对显示效果的影响。
- 移除规则页底部的说明文字。

## 新增 IP 检测

- 新增“IP检测”页面，集成 RegionRestrictionCheck 平台检测。
- 提供出口 IP 查询、GitHub 连通性检测，以及 AI 服务、流媒体与多个地区的平台访问检测，覆盖 ChatGPT、Claude、Gemini、Netflix、Disney+、YouTube 等项目。
- 支持一键检测、取消、进度显示，以及按平台、地区或结果搜索；展示检测结果、识别地区和响应耗时。
- 安装包内置检测工具与运行依赖，使用者无需额外安装 Git 或 Python。
- 检测遵循当前代理规则，出口由当前规则与策略组决定。平台验证拦截、接口变化可能影响结果；检测结果不代表已验证账号登录或实际播放。

## 内存与运行效率优化

- **减少界面控件与缓存占用**：连接和规则每页最多构建 60 行控件，搜索仍覆盖完整列表；切页或隐藏窗口时释放非当前页面的数据及缓冲容量。
- **降低 API 解析峰值**：大体积 JSON 边接收边解析，使用有限队列与后台解析，减少完整响应字节与完整结果对象同时驻留。
- **减少配置复制**：移除 YAML 根映射与 TUN 配置的深拷贝、重复解析和重载时的额外文本复制，及时释放启动与重载时不再需要的缓冲区。
- **限制日志与校验输出**：日志保留最多 500 条、每条最多 1000 字符；日志帧与配置校验输出有大小限制，超长记录不会阻止后续完整日志处理。
- **改善后台任务与轮询**：托盘只保留最新状态，减少重复通知；清理已失效的节点与策略组缓存，释放内核退出后的日志读取任务，减少轮询请求和订阅元数据复制。
- **优化搜索与测速**：ASCII 搜索减少临时字符串分配，连接与规则支持跨字段多词搜索；节点组测速减少成员列表复制，并在请求开始前释放完整代理数据。

### 本地内存基准

同一 HTTP 数据、同一结果类型，对比此前的完整响应解析与当前的流式解析。每种模式在独立进程中运行三次，以下为中位数。

| 数据集 | 优化前堆峰值 | 优化后堆峰值 | 降幅 |
| --- | ---: | ---: | ---: |
| 50,000 条规则 | 9.44 MiB | 6.98 MiB | 约 26% |
| 50,000 条连接 | 35.30 MiB | 24.20 MiB | 约 31% |

测量范围为 API 解析期间新增的 Rust 堆峰值，不包含客户端整体工作集、字体与渲染缓存或 mihomo。完整连接与规则结果仍保存在当前页面，结果对象内存随数据量增长。基准程序见 `examples/memory_benchmark.rs`。

API 响应新增 **32 MiB** 大小上限，超过限制会提示错误。

## 下载

- `Clash-of-Rust-0.4.1-windows-x64-setup.exe`：Windows x64 安装包。
- `Clash-of-Rust-0.4.1-windows-x64-setup.exe.sha256`：安装包 SHA-256 校验值。

安装包包含 mihomo v1.19.32、GeoIP / GeoSite / Country / ASN 数据、默认配置及 IP 检测工具；启动无需额外下载内核与 Geo 数据，平台检测本身需要联网。

目前仅提供 Windows x64 安装包。Linux 适配尚未完成。
