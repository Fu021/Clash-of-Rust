# Clash of Rust 0.5.2

适用于 Windows x64 / ARM64 与 Debian/Ubuntu amd64 / ARM64；升级保留订阅和个人设置。

## 更新内容

- 规则页支持按订阅独立管理自定义规则：新增、编辑、删除、启停，上移、下移、移到首尾或指定位置，并可恢复订阅顺序；显示完整匹配顺序与规则来源。
- 五项广告拦截与本地、国内直连快捷规则从设置页移入规则页，默认收起，开关默认全部关闭；已有设置保留，仅补充订阅缺少的规则，避免重复添加。
- 自定义规则支持表单与规则文本编辑，空草稿可自由切换；修改先保存为草稿，应用前由内核校验，保存或重载失败时恢复原配置。原始订阅 YAML 保留，订阅更新及重启后重新叠加自定义规则和排序。
- IP 检测改为整页分类报告，点击分类或结果状态进入详情，支持返回报告、组合筛选与单独重测分类；进度条与滚动条预留空间。
- 连接页新增上传、下载速度与表头排序，再次点击可切换升降序；筛选与排序覆盖全部连接，移除未知进程显示和进程名称检测。支持搜索嗅探域名及命中规则内容，便于检查实际分流。
- 右上角显示“订阅 | 节点”，点击进入对应页面；规则模式显示默认匹配线路的最终选择，全局模式跟随全局决策组，直连模式显示 DIRECT。
- 记住上次普通窗口尺寸，最大化和最小化不覆盖记录；客户端检查更新仅接受正式版，忽略预发布版本。
- Windows 卸载新增“删除所有配置和数据”选项，默认不勾选；升级、静默卸载与重装保留用户数据。
