# 0.6.7-fix.2.android-ime-flags

此预发布版基于 `0.6.6`，重点修复 Android 订阅输入、emoji 显示和 Geo 更新中断后的启动恢复。

- 修复 Android 12/12L 输入框已有光标却未绘出键盘的兼容问题；合并显示请求、等待窗口焦点并延后可取消的隐藏请求，减少切换字段时键盘消失。一次显示只使用一套系统入口。
- 将 Android 系统键盘高度同步至共享布局，排除系统栏并避免重复扣除安全区；名称和地址字段按实际可见区域滚动避让。横屏或低矮窗口中的保存/取消操作随表单滚动，恢复前台、旋转及 Back 后重新输入沿用相同处理。
- 修复旧版 Android 前后台切换时向失效窗口表面绘制的问题；表面、焦点及生命周期变化时暂停和恢复渲染。
- 桌面与 Android 使用随包 Noto Color Emoji，修复 Slint 软件渲染器缺少彩色字形的问题；节点及策略组名称保留订阅原文，不删除、推断或自动添加旗帜。IP 检测和 Claude 保护/检测的摘要、结果、递归 DNS 及详情改用 emoji 国旗，移除独立图集与图片缓存；港澳台在报告中仍显示中国国旗，保留地区文字。
- 修复 Geo 更新中断且备份缺失时，即使当前整组数据有效仍无法启动的问题。仅保留通过完整校验的数据，归档原事务与清单，保留残余备份；损坏数据仍报错，不将中断更新记为成功。资源缺失报错补充实际程序与资源目录。
- 改进 `cor` 分组帮助，支持 `cor node help`；状态与 TUN 操作补充接管范围和 Linux 路由观察提示。`diagnose` 分别检查系统路由与本地代理，后台未运行时仍可输出系统侧结果；修复出口查询按 JSON 解析纯文本 IP 导致的 `trailing characters`，严格校验 HTTP 状态及 IP。
- 精简 GUI 与 CLI 的多用户文案：Linux 共用实际路由与 TUN 持有进程观察，仅在发现外部接管或代理状态无法读取时提示，附接口、可读取的 UID/PID 与诊断入口。桌面可见时低频刷新并在各页显示有效提醒，关闭后重新观察；CLI 状态合并为简短摘要，停止不再声称全机网络恢复。完整采样仍保留在 JSON 和诊断报告中。
- GUI 报错、校验失败与异常状态提供诊断导出，保留具体错误供提交 issue；日志页提供常驻入口。桌面、Android 与 CLI 共用有界现场采集及脱敏，后台不可用时保留可采集部分；错误不再自动消失，正常操作只显示完成结果。诊断不会自动上传或宣称已修复，iOS 仍为界面原型。
- 桌面和移动端的报错改为屏幕中央弹窗，直接展示详细错误和诊断入口，背景暂不可操作；过长内容可滚动，关闭按钮始终可见。关闭、Escape 或 Android 返回优先关闭报错并保留原页面与草稿。Android 输入回归先真实关闭后台报错，再验证订阅输入、键盘与生命周期，避免误把弹窗覆盖的点击当作输入法失败。
- 移动会话与 Android 请求门禁的源码测试归三个 Android 构建任务执行，六种桌面任务只编译和测试桌面相关包，避免重复编译移动端运行时；共用业务库继续随各端验证。
- 增加 `cor restart --network-only`，用于明确确认后刷新当前出站与 DNS、关闭旧连接；它不重启内核，也不代表长时间 TUN 故障的根因已修复。
- 修复 macOS TUN 助手在探测连接提前关闭后因单次响应写入失败退出的问题，并补充控制连接回归。
- 调整工作流缓存：Rust 编译对象仅使用 GitHub Actions 缓存，macOS ARM64 最高优先，其余按近期恢复与编译耗时排序；原始工具与依赖优先官方来源，失败后回退私网。已校验原包通过持久清单交服务器代拉，保留接收及分页回执，区分排队、就绪、失败与未接收；不主动删除私网内容。
- 更新已审计的依赖、构建工具及固定 Actions 身份，修复工具版本优先级、Android 模拟器磁盘预算和日志导出。输入法回归同时检查截图、布局、日志边界及输入法崩溃，诊断对照不能替代原回归成功。

历史输入法修复及 `6612005` 的 Android API 31、36 输入、布局、Back、前后台与旋转检查已有成功证据；更早的十版本专项及跨提交边界见[输入法兼容性记录](../agent-failures/android-ime.md)。本轮报告 emoji 和桌面裁切回归修正仍待新提交的完整 CI、打包及安装后验证；不能用历史结果代表本轮全部通过。全部必需检查通过后才公开新的预发布包。

MIUI / Redmi K30、第三方输入法、API 27 和真实设备仍需复验。此前出现过的模拟器 Gboard 空指针本轮未复现，根因尚未确认，不能据此承诺 Android 8 起所有设备完全兼容。长时间 TUN 运行后部分服务不可达的问题仍保留在[网络恢复记录](../agent-failures/network-recovery.md#长时间运行后的服务不可达)，本版不将其列为已修复。

预发布版本可能存在尚未发现的问题，建议先备份配置。实际公开发布仍须使用长期 Android 发行签名；从预发布返回正式版时，无法保证保留数据完成降级。macOS 安装包使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。
