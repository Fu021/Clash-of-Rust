# Clash of Rust 0.5.8

适用于 Windows x64 / ARM64、Debian/Ubuntu amd64 / ARM64（Ubuntu 仅支持 22.04 及以上），以及 macOS 14 及以上的 Intel / Apple Silicon；升级保留订阅和个人设置。

## 更新内容

### macOS 授权与代理

- 系统代理和 TUN 共用本机网络助手，首次安装或助手需要更新时请求管理员授权，之后复用。修复登录自启、切换系统代理与 TUN 时反复弹出授权的问题。
- 退出程序及系统关机时，恢复原有代理设置不再请求管理员授权；仅恢复本程序持有的设置，避免覆盖其他程序后续修改的代理。
- 网络助手重启后可恢复代理管理状态；客户端异常退出时清理其代理和 TUN 会话。修复普通用户安装应用时，助手文件权限校验导致安装失败的问题。

### 客户端更新

- 修复 macOS 更新时旧客户端退出与代理恢复互相阻塞的问题，减少下载完成后仍停留在旧版本、需要再次下载才能安装的情况。
- 显示挂载安装包、校验资源、请求安装授权、替换应用和重启等阶段；准备安装失败后，再次点击安装会复用已校验的安装包。
- 更新交接失败或取消时保留旧版本；继续校验安装包、应用签名、版本、架构、内核与资源。

### 验证

- macOS Intel 与 Apple Silicon 均覆盖系统代理启动、后台恢复、网络助手重启、模式切换和更新安装测试；CI 与最终安装包分别运行 20 项 GUI 场景。
- 正常系统代理连续三轮启动的授权次数为 **1、0、0**；系统代理与 TUN 往返切换复用同一次首次授权。
- 内存基准使用 **100 节点、5 个策略组、1,000 条规则**的低强度场景，实测数据见 [README](https://github.com/Fu021/Clash-of-Rust/blob/v0.5.8/README.md#内存占用)。

Windows 双击安装程序；Debian/Ubuntu（Ubuntu 仅支持 22.04 及以上）执行 `sudo apt install ./安装包文件名.deb`。macOS 打开 DMG，将 **Clash of Rust.app** 拖入 **Applications（应用程序）** 后启动。每个安装包附带 `.sha256` 校验文件。

macOS 首次启用系统代理或 TUN 时，请完成网络助手安装授权；登录自启仍以普通用户运行。安装包使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。首次打开若提示无法验证开发者，可确认来源及校验值后，在“系统设置 → 隐私与安全性”中选择“仍要打开”，见 [Apple 说明](https://support.apple.com/zh-cn/102445)。
