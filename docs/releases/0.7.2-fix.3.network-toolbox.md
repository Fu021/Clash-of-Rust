# 0.7.2-fix.3.network-toolbox

## 更新

- 扩展网络诊断，新增 DNS 对照、连接耗时、IPv4/IPv6、规则出口、TLS、稳定性、UDP、Ping、路由追踪及限量下载工具。
- 桌面、手机和平板统一工具导航与结果展示，支持取消、参数调整和诊断导出，不保留检查历史。
- TUI 与 CLI 同步提供工具入口；保留现有命令和 JSON 接口，完善非法输入、权限、超时及代理失败提示。

## 验证与已知问题

- 发布前完成同提交 CI、Android 8.0～16、Ubuntu 20.04 两架构及发行签名验证。
- Ping 与路由追踪依赖系统能力，Claude 保护期间不可用；真机、厂商 ROM 和长期网络仍需进一步验证。
