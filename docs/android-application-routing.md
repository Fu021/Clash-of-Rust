# Android 应用分流

[文档导航](README.md) · [Android 客户端](../apps/android/README.md) · [Claude 保护](claude-protection.md)

设置 → 应用分流决定哪些应用进入 VPN。进入后的具体出站仍遵循当前模式和订阅规则，不等于强制选中应用使用代理节点。

| 模式 | 选中应用 | 其余应用 |
| --- | --- | --- |
| 全部应用 | 进入 VPN | 进入 VPN |
| 仅代理选中应用 | 进入 VPN | 使用系统原有网络 |
| 排除选中应用 | 使用系统原有网络 | 进入 VPN |

Android 系统 VPN 的“阻止不使用 VPN 的连接”若开启，仍可能阻止这些直连应用；该开关由用户在系统设置决定，客户端不会擅自修改。

## 选择与保存

应用选择页使用 Slint，与其余页面共用主题、字体、通知与导航；Java 仅通过 `ApplicationCatalog` 枚举应用和持久化选择，不绘制业务页面。列表提供名称/包名搜索、通用离线应用图标、系统组件开关、全选当前结果、反选当前结果、清空全部和已选计数。默认显示有启动入口的预装应用及用户应用，已选系统组件也保持可见，避免将所有预装应用一并过滤后只剩本应用。隐藏或过滤应用不丢掉选择；清空会同时清除不可见项。读取和保存放在独立工作线程；失败保留草稿，可重试或导出诊断。已安装应用可见性权限只用于本地选择，应用清单不上传。

宿主声明 `QUERY_ALL_PACKAGES`，因为仅查询带启动图标的 Activity 会漏掉无启动入口的系统应用和后台应用，无法提供完整的分流清单。Manifest 仅对此声明标记 `QueryAllPackagesPermission` 检查例外，理由即本节的全应用选择用途；没有关闭 Gradle lint 或其他权限检查。这不代表已经取得 Google Play 的权限政策审核，当前安装包由 GitHub 分发。

连接中可以保存，当前 VPN 保持原选择，重新连接后才生效；未保存时返回或导航会确认是否放弃，旋转沿用 Slint 草稿。刷新应用清单保留当前模式与选择，重新进入页面才读取已保存设置。设置保存在 Android 私有 `vpn` preferences 中：`application_mode` 为 `all`、`only` 或 `exclude`，`selected_apps` 为去重包名集合。旧版 `excluded` 非空时按排除模式读取，并在保存或清理有效列表时持久迁移；空旧列表等价于全部应用。

连接时通过 `PackageManager` 显式检查已安装状态，再向 VPN Builder 登记，并删除已卸载包名；不只依赖 Builder 抛出异常。仅选中模式不接受空列表；选中应用全部卸载时拒绝本次连接，避免 Android 将空允许列表视为接管所有应用。VPN 就绪检查监听 VPN 网络及其路由更新，不要求本应用的默认网络一定经过 VPN，因此可以将 Clash of Rust 自身排除。

Claude 保护期间锁定编辑并临时覆盖为全部应用，不修改用户保存的模式和清单；关闭保护后恢复原分流。保存按钮会再次检查保护状态，避免打开选择页后启用保护仍能保存。

## 范围与验证

系统按 UID 分流，共享 UID 的应用不能保证独立选择；仅列出当前 Android 用户可见的应用，不代管工作资料或其他用户。[issue #37](https://github.com/Fu021/Clash-of-Rust/issues/37) 进阶的“按应用指定节点/策略组”尚未实现，需要单独接入连接归属和 UID 规则，不能用进入 VPN 的选择替代。

`ProxyTunTest.applicationRoutingPersistsAndKeepsOtherAppsOnline` 沿用现有 Android x64 网络集成入口，覆盖旧设置迁移、三种模式、本应用被允许/未选中/被排除的实际路由、直连请求、保存后重连和卸载清理；保护覆盖另核对有效模式与原列表保留。该网络专项保留在普通 CI，不交由截图工作流，也不重复键盘专项。

新增源码须取得同提交 Actions 结果才算模拟器验证通过。真机、厂商 ROM、多用户、IPv6/UDP/DNS 专项仍需独立验收，不能据 IPv4 模拟器结果认定完整兼容性。

维护者可按需运行独立 [Android 应用列表预览](workflows/android-previews.md)，复用成功 CI 的 x64 APK，在已固定身份的模拟器版本上打开实际 Slint 页面，读取应用清单并保存截图和计数证据。该流程不启动 VPN、不改分流选择、不做流量测试，也不重跑键盘专项；截图不代表实际分流已验收。
