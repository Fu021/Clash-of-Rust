# 桌面与命令行下载

[返回索引](README.md)。

手动订阅、Geo 和 `cor update install` 曾在共享后台锁内等待网络；慢网时其他窗口和命令也无法读取状态。下载改在锁外，最终验证与提交由所有者串行处理。手动订阅提交前核对原订阅、文件摘要和保护状态；定时更新还须核对定时开关。失败或过期结果保留现有数据。Geo 和客户端更新也限制同类任务并发，停止内核会取消尚未安装的下载。

GUI/CLI 的订阅更新在开始下载前也核对当前名称和来源；旧版控制请求和显式导入允许指定新来源，两者下载后均检查原配置未被并发修改。新增的控制字段缺省保留旧请求语义，避免把正常换源误判成过期更新。

本机控制连接中断或超时时，订阅、Geo 和客户端更新取消尚未提交的下载并清理暂存；进入安装事务后继续完成或恢复，不能中途丢弃事务。客户端安装交接一旦开始，系统安装程序可能已启动，断开请求不等于撤销安装。慢速下载、取消、重复请求及订阅被编辑后的回归见 [下载任务](../../crates/client-runtime/src/engine/downloads.rs)和[控制连接](../../crates/client-runtime/src/control/transport.rs)；实际网络、安装授权和设备行为须以同提交 CI、安装验证及用户设备结果为准。
