# Slint 界面与测试稳定性

[返回索引](README.md)。按症状读取，编号沿用历史复盘。

## 4. Slint 界面契约与预览漂移

**典型症状**

- Slint 属性、回调、页面索引或 fixture 与正式入口不一致。
- 编译生成代码出现语法或类型错误，例如 “this looks like an `else if` but the `else` is missing”。
- 旧 UI 截图/预览脚本依赖已删除的测试钩子或固定坐标，出现找不到选择器、卡片或 tray 函数。

**代表证据**

- CI [39773451589](https://github.com/Fu021/Clash-of-Rust/actions/runs/39773451589)：桌面 UI target 在一次界面变更后出现大量生成代码编译错误。
- UI Screenshots [38595379460](https://github.com/Fu021/Clash-of-Rust/actions/runs/38595379460)：旧临时任务引用已不存在的 `native_present`、`remove_native_item_for_test`、`verify_native_state`。
- Memory Benchmark [38102403454](https://github.com/Fu021/Clash-of-Rust/actions/runs/38102403454)、[38058824407](https://github.com/Fu021/Clash-of-Rust/actions/runs/38058824407)、[38058444877](https://github.com/Fu021/Clash-of-Rust/actions/runs/38058444877)：旧预览脚本依赖固定坐标和分类卡片布局。

**首先检查**

- Slint 状态/回调、协议、宿主投影、正式窗口入口和预览 fixture 是否同步。
- 全局标题状态必须在公共投影入口更新，不能藏在仅当前页执行的详情函数中；预览 fixture 直接赋值会掩盖此问题。跨页回归同时检查启用、异常、待确认、关闭及离开详情页后的切换锁释放，避免保留完整页数据。2026-11-02 的 CI `41431510995` 由跨页断言发现保护盾牌只在检测页更新。
- Slint 的 `string` 在桌面协议中映射为 `Text`；报告国旗也使用这个类型，移除旧图像代号转换。新增字段和共享赋值宏按生成契约使用 `.into()`，核对全部构造点及收发端协议号。CI `42024430303` 的旧图像代号和 [CI 40561035810](https://github.com/Fu021/Clash-of-Rust/actions/runs/40561035810) 的国家字段曾出现转换错误；Slint 静态检查不能代替 Rust 宿主类型检查。
- `scripts/preview-slint.py --check` 是否能加载正式入口；预览数据是否含已删除属性。
- UI 测试是否通过正式消息路径，而不是复制状态或依赖临时截图脚本。
- Slint 1.18.1 的重复网格在实例构造中同步读取几何信息会重入未完成的布局。CI `42572458885` 的六种桌面调用栈定位到移动订阅 `MobileProfilesProbe` → `GeometryTarget::user_init` → `solve_grid_layout`，Android x64 的 logcat 也记录相同越界；三个 Ubuntu job 因上游未生成候选包而失败，尚未进入安装验证。此前只改通知区没有修到实际触发位置。订阅宫格改用与桌面一致的纵向行、横向槽位，保留真实坐标与点击断言，补覆盖同批改名并增加卡片、删减、清空、恢复及窄宽屏的宫格/列表。解释器预览不等于 Rust 生成代码验收；相关上游缺陷见 [Slint #13723](https://github.com/slint-ui/slint/issues/13723)，不把相似堆栈直接当作完全相同的根因。
- CI `42576714664` 的订阅软件窗口回归已通过，Android x64 仍在首屏构造时出现 `layout.rs:567` 越界，表明只换订阅布局并未覆盖正式移动入口。`GeometryTarget` 的 `changed bounds` 即使 key 为空也会先求值；将无订阅者的测量改为默认关闭，空 key 不读取坐标，测试注册后显式开启。补充 Android 与 iOS 原型完整页面的冷启动、内核开关、大小字号和手机/Pad 切换回归，实际修复效果由新提交 CI 验收。
- [通知分级](../../crates/client-ui/README.md#通知与故障反馈)由宿主声明实际影响，严重弹窗自行处理焦点与返回键，关闭不退出底层表单；诊断和反馈入口也须通过保护模式的全局操作门禁。新增分级时清除测试夹具的初始化故障，再验证后续通知，不把严重故障优先级误判为业务失败。重试回归先核对后台成功不能覆盖未关闭的错误，再通过正式关闭入口确认，最后核验重试成功；保留原有数据与运行状态断言。
- 诊断草稿的测试应分别包含可保留上下文和含凭据的日志行；整行脱敏不能判为丢失普通文字，也不能为了通过测试放宽隐私规则。摘要预填、报告导出、浏览器打开与附件上传是不同结果，失败须保留原始错误。

**防回归**

- 外观使用持久安装、版本匹配的 Slint Viewer，不恢复截图工作流；固定数据不证明交互、VPN 或系统集成通过。
- 交互测试使用稳定标识/可访问文本和状态等待，不依赖绝对坐标。
- 管理列表与运行配置共用有效数据，标明客户端默认与自定义来源；删除默认项须持久保存移除记录，还原只恢复默认来源。Fake-IP 回归用例覆盖三种过滤模式、同名来源合并和重启恢复，见[配置测试](../../crates/client-core/src/config/mod.rs)。

### 国旗与 emoji 文本

- 节点列表、策略组标题与当前策略、首页和详情直接显示订阅原始名称，选择、测速与控制请求也使用同一名称；删除节点专用旗帜、去前缀及地区推断规则。回归数据包含带组合 emoji 的策略组标题，桌面与移动投影不得清洗组名。IP 检测与 Claude 报告共用 `flag_emoji()` 和随包字体，摘要、结果、递归 DNS 及详情全部传文本；港澳台映射中国国旗，未知地区不猜测旗帜。旧 Twemoji 图集、预览 SVG、图片缓存与生成入口已删除，仅保留有来源和许可证的[国家名称数据](../../resources/countries/SOURCE.md)。
- 字体缺字与绘制缺陷分别检查。Slint 1.18.1 软件渲染器只请求轮廓，CBDT/sbix 字体会留白；上游 [#14567](https://github.com/slint-ui/slint/pull/14567) 于 2026-10-29 合入彩色字形支持，本地在[独立覆盖](../../vendor/slint-renderer-software/PATCHES.md)回移，不切换桌面渲染器。两端注册固定 [CBDT Noto 字体](../../resources/fonts/SOURCE.md#noto-color-emoji)，置于系统通用回退前；COLR v1/SVG 版在本机 Skia 也留白，不能仅凭字体名称声称支持。
- 2026-11-05 静态核对：246 项图集索引与 `72×72×4` 像素长度一致，相关资源与 `v0.6.6` 相同。[issue #33](https://github.com/Fu021/Clash-of-Rust/issues/33) 只有“国旗 emoji 显示 XX”的文字反馈，尚无具体页面截图；这些实现缺口不能直接当作该设备的唯一根因。
- 固定数据保留已有 emoji、普通 emoji、国家代码和没有旗帜的节点，不给无旗帜名称补旗帜。回归覆盖原名到窗口的投影及协议、彩色字形与组合 emoji、输入框、透明度、裁切、部分重绘，以及报告国家到 emoji 的映射。本机官方 Viewer 对照确认 CBDT 字体在 Skia 能显示、旧软件渲染器留白；回移后的软件渲染回归须由同提交 Actions 验证，不以预览代替正式渲染或设备验收。CI `42178628317` 的裁切用例未固定容器坐标，Slint 默认居中导致左边界断言失败；固定 `x/y` 并对比局部与全量重绘，不放宽裁切边界。

### 订阅更新失败与界面状态

- **症状与根因**：下载失败虽未写入订阅，桌面却在发出更新前清除测速和检测报告，CLI 后台也在执行更新前推进界面修订号，失败仍导致已连接窗口失效。HTTP 200 也可能是登录页或空内容，不能直接视为订阅可用。
- **修复与防回归**：每条下载路线先校验 YAML；全部失败时明确提示[保留旧状态](../development.md#修改前后都要检查)，不进入提交事务。订阅提交成功后才推进修订号、刷新托盘并清理网络结果；共享移动会话不得请求内核重载或 VPN 重连。使用回环服务与临时目录，覆盖服务端错误、错误页面、截断、断连、取消及成功重试，不使用真实订阅。
- **验证入口**：[下载路线](../../crates/client-core/src/subscription/mod.rs)、[移动会话](../../crates/mobile-ffi/src/lib.rs)、[桌面交互](../../apps/desktop/src/application/ui_tests.rs)及[桌面/CLI 集成](../../apps/desktop/tests/core_integration.rs)；本次最终提交的 CI 与打包证据以任务汇报为准。

### 定时订阅与保护锁定

- **症状与根因**：只在手动更新时校验订阅不足以保证长时间运行一致性；下载完成前用户可能编辑、删除或受保护锁定同一订阅。保护期间只弹提示仍会产生重复操作与警告噪声。
- **修复与防回归**：唯一后端所有者低频调度；桌面手动与定时下载共用可取消的门禁，忙时不消耗定时重试间隔。提交前比较订阅、来源、文件哈希、开关和保护状态，过期丢弃，失败保留原状态；Android 的生命周期限制见[订阅说明](../subscriptions.md#自动更新)。Claude 保护及切换期间整个客户端只读，UI 灰置规则、代理、订阅、更新和网络设置，业务层继续校验；页面锁定仍须允许退出等全局确认，不能被整页拦截困住。回归覆盖保护暂停全部订阅、失败重试、过期结果、草稿保留、吞掉点击/滚动及退出确认。
- **验证入口**：[调度](../../crates/client-core/src/subscription/schedule.rs)、[后台任务](../../crates/client-runtime/src/control/subscriptions.rs)、[移动提交](../../crates/mobile-ffi/src/lib.rs)、[桌面保护测试](../../apps/desktop/src/application/ui_tests.rs)及锁定页测试；最终结果以同提交 CI 为准。

### 订阅删除与重复提交

- 删除当前订阅需要把默认配置、订阅清单、设置、文件删除和运行配置作为同一事务；重载失败恢复旧运行配置，成功后才更新会话与规则页。默认配置迁移保留已有 ID 和自定义内容，其他订阅的未应用规则草稿保留。回归见[共享移动会话](../../crates/mobile-ffi/src/lib.rs)。
- 网络保存期间的界面反馈应在请求入队前设置，不能只等待完成后的投影；[Android 请求门控](../../apps/android/native/src/request_gate.rs)阻止重复请求，直到完成投影应用后才解锁，避免周期刷新提前解锁及迟到完成清除新请求。失败时保留表单，后台完成也须处理解锁。
- 移动规则保存不能先修改原草稿再调用 `validate`；达到数量上限时会报错却留下无效内容。桌面、移动端与 `cor` 的新增、编辑和启用使用[共享重复校验](../../crates/client-core/src/rules/mod.rs)，允许禁用副本并兼容上游更新造成的历史重复；拒绝后保留原草稿。位置和数量上限仍须先校验。

### 移动虚拟列表重叠与宽屏空间

- **症状**：Android 连接、规则、日志页的计数正常，却只看到最后一条，且记录出现在正文中间；Pad 的分页和规则操作横向铺满并占两行。
- **根因与修复**：Slint 1.18 按重复项直接父组件名 `ListView` 启用虚拟布局，`MList` 不被识别，重复项重叠。保留原名与紧凑布局内容原点；宽屏复用紧凑分页和规则提交，Pad 与手机统一“工具”入口。
- **证据与防回归**：[正式列表](../../crates/client-ui/ui/mobile/shared/controls.slint)、[页面](../../crates/client-ui/ui/mobile/shared/pages.slint)与[软件窗口回归](../../crates/client-ui/tests/mobile_lists.rs)。回归验证多行滚动范围、不同颜色行的实际位置、删至一条仍顶部对齐，以及横向变宽后的不同行高。固定数据预览曾复现“4 条规则仅显示第 4 条”，修复后按序显示；外观检查不代表设备网络已验证。
- 软件窗口的尺寸回归用 `preferred-width` / `preferred-height`，不要用固定宽高后再请求变宽；窗口约束会使宽区域的像素断言落到背景。先核对实际窗口尺寸，再验证重排，见 [CI 40108770502](https://github.com/Fu021/Clash-of-Rust/actions/runs/40108770502) 的 Linux ARM64 列表测试。
- 拖动边缘滚动的手势所有者放在虚拟列表旁，不能依赖可能被回收的源行；列表内只允许单个 `for`，额外手势层会被 Slint 拒绝。工具栏和尾栏不算规则，自动滚动须按实际行高、头部高度与滚动偏移计算目标；松手、取消、筛选和导航后停止。回归覆盖源行回收、双向滚动、中心停滚、头部排除与迟到松手。
- 浮起预览也放在虚拟列表外，复用正式规则行与按下时的数据快照，保留指针在行内的偏移，直接跟随而不叠加位置缓动；自动滚动只改变目标，不能把预览带离指针。原行保留高度并淡化，预览不接收按钮操作，松手及失效立即移除。传入 `@children` 的规则行显式绑定实际行高，不能用 `parent.height` 继承外层视口；拖动态预览与像素断言同时确认文字可见、后续行未被高卡片遮住。交互回归覆盖源行回收与取消；长按前列表已滚动则取消待启动手势。
- 桌面整页的手势命中区要包含规则卡片在滚动内容内的横向偏移，并与行内手柄重合。除共享手势夹具外，还需测试生产规则页的手柄两端、浮起预览位置、松手事件和局部重绘；软件渲染回归不等于 Windows 实机渲染验收。
- 桌面与移动复用同一边缘滚动手势，桌面按下即拖、移动长按启动；规则页顶部控件随列表滚走。按[多尺寸检查](../loop-workflow.md#多尺寸-ui-检查)核对窄屏搜索/筛选、大字号与底部操作，不能只验证一个手机视口或只看列表顶部。键盘展开时规则和连接尾栏随内容滚动；仅按整页高度判断会在临界高度挤空结果。
- 搜索框不能放在条数变化就重建的整数循环模型中，也不能随键盘挤压后的高度切换整个布局。规则、连接与日志使用独立保留的 `ListHeader`，与虚拟列表共享滚动偏移和边界，列表内仅留对应高度的占位；覆盖键盘缩小视口、列表替换和变空后继续输入的焦点回归。Slint 主动清除滚出可视区的输入焦点，滚动回归应与保留可见输入框的键盘/模型回归分开，不能混合后误判为重建失焦，见 [CI 40302078339](https://github.com/Fu021/Clash-of-Rust/actions/runs/40302078339)。
- 应用分流也采用上述共享滚动结构，不能让头部与列表在纵向布局中互相挤压；[截图运行 42651167579](https://github.com/Fu021/Clash-of-Rust/actions/runs/42651167579) 在 Android 9～12L、15、16 横屏滚动时出现 Slint `Recursion detected`。生产页的软件窗口回归覆盖手机、横屏及平板的双向滚动和筛选清空；模拟器截图同时核对实际滚动偏移。Android 13/14 的同轮截图还暴露触摸坐标未加窗口原点，需分别核对设备截图与测试坐标，不能归为应用导航失效。
- 移动列表固定内容宽度为可视宽度；筛选控件按剩余空间伸缩，避免固定最小宽度挤出手机、比例上限又在 Pad 留空。规则行保留原文，不能从简略字段拼接丢失参数。
- [CI 40204541123](https://github.com/Fu021/Clash-of-Rust/actions/runs/40204541123) 暴露内容切换后拖动仍短暂有效：`changed` 回调尚未清理，读取和松手可能沿用旧状态。有效状态应直接绑定起始内容与布局，松手再次核对；桌面手柄同样按起始 ID 提交。保持即时取消断言，不能仅延迟断言掩盖窗口。

## 11. 测试稳定性与外部环境假设

测试时钟、事件循环、系统环境与外部服务的证据和约束见[测试环境与稳定性](test-environments.md)。
