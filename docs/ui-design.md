# 界面设计与审阅

[文档导航](README.md) · [Slint 组件、预览与交互边界](../crates/client-ui/README.md)

本轮按维护者提供的交互 HTML 重构整体界面，覆盖桌面、手机及平板，包含浅色和深色；Android 与 iOS 共用视觉组件，分别保留平台导航与宿主边界。iOS 仍是界面原型，不能据截图声称已有可用客户端。

## 视觉与布局

Pad 设置的双列使用同等固定分配宽度，子控件按各自列内空间排版，避免一侧被长文本挤压。Android 应用分流页也采用 Slint；应用枚举和保存由系统桥接执行，见[应用分流](android-application-routing.md)。

代理与订阅的宫格／列表切换在两个方向均短暂淡入并小幅位移；切换图标交叉淡入，减少动态效果时立即切换。窗口连续拖动不补间内容宽高：桌面在物理尺寸或缩放比变化时补全窗口重绘，向宿主回传尺寸采用 80ms 去抖，减少旧尺寸回流。后两项属于实现层缓解，真实连续拖动仍须在平台验收，不据静态截图声称缩放问题已解决。

统一使用暖色中性画布、实体表面、细边框、柔和阴影及陶土色强调。六个强调色索引与保存方式不变，默认索引 0 的视觉由青绿改为陶土；其他已选颜色保留。语义颜色独立表达成功、警告和错误，不能随强调色改变。

强调色直接点击六个色块选择，桌面不再显示省略号入口，手机及 Pad 的强调色标题也不再打开重复的选择窗口。

字标由 `ui/components/brand.slint` 的两组几何路径绘制，应用内图标和完整字标跟随强调色，不依赖在线资源或字标字体；系统任务栏图标沿用固定资源。正文和 emoji 使用随包字体，名称保持原文；节点与策略组不再推断或补写地区，报告的地区映射不参与节点显示。

| 架构 | 框架与内容 |
| --- | --- |
| 桌面 | 默认 950×700，最小 800×450。44px 品牌/窗口栏、216px 侧栏、圆角主画布、至少 52px 页头；字标右侧按钮可手动收为 60px 图标栏，低于 880px 时自动收起。三平台取消系统标题栏，拖动、双击、边缘缩放和窗口按钮使用真实窗口接口，关闭沿用托盘策略，见[窗口交互](../crates/client-ui/README.md)。 |
| 手机 | 底部首页、代理、订阅、工具、设置五入口，触控区至少 48px。Android 使用选中图标胶囊，iOS 使用平台对应的文字/图标选中状态；页头只保留页名与必要运行状态。 |
| 平板 | 横向大空间使用 236px 完整侧栏、圆角主画布、双栏概览和设置；连接、规则、日志及检测可直接进入。中等宽度与短横屏用紧凑侧栏，可用空间足够时列表和详情并排。 |

页面不保留隐藏的网络任务或第二套业务。桌面正文 15px、辅助信息 13px，控件随字号增高；移动正文 16px、辅助信息 13px，按 Android 系统 SP 换算处理无障碍缩放。小屏、大字号与键盘分别按可用区域降级，不能缩小触控目标换取列数。

## 页面结构

| 页面 | 结构与操作 |
| --- | --- |
| 首页 | 当前连接、订阅和大号节点名组成连接卡，圆形电源入口与模式操作集中；四项现有实时统计和连接入口减少重复卡片。桌面补充网络信息与服务状态，见下文。内核停止时不展示旧速率为实时结果；累计值仍可保留。 |
| 代理 | 组标题、当前节点、展开与组测速；桌面按 196px 参考宽度和字号动态排宫格，工具栏可切为紧凑单列列表。列表只保留名称、延迟和详情入口，协议等元数据进入详情，选中状态用现有强调底色表达而不重复画勾；手机常规宫格双列，过窄或字号超过 125% 改单列，也可主动选择列表，列表沿用名称、延迟和详情并保持至少 48px 触控高度。长名称在详情完整显示。 |
| 订阅 | 顶部链接导入器及本地文件入口，可切换宫格与单列列表；宫格随可用宽度和字号降列，手机常规宽度为单列，平板允许多列。桌面列表只保留名称、状态、操作和详情入口，来源与用量进入详情；卡片随内容压缩，不保留空白摘要行。远程订阅保留更新，本地导入配置可编辑和删除，内置默认直连不可编辑或删除。保护门禁、搜索及分页保留，没有结构化额度时不伪造用量条。 |
| 连接 | 桌面固定表头、可排序列、紧凑悬停行及分页；移动使用触控列表，平板可并排查看详情。完整字段、复制和关闭入口保留。 |
| 规则 | 桌面与 Pad 的快捷规则入口紧邻内核状态左侧，手机状态隐藏时入口靠右；点击打开共用选择窗口，具体交互见 [Slint 说明](../crates/client-ui/README.md)。草稿操作固定在列表外；保持拖动、来源筛选、详情、编辑、跨页移动及应用/放弃语义。手机保留触控排序及独立编辑页。 |
| 日志 | 紧凑行、等级和搜索筛选、单条复制与全文详情；底部常驻诊断入口。 |
| 检测与设置 | 诊断、IP 和 A÷检测沿用统一表面与文字层级，完整结果进入详情；桌面设置分组入口放到页头，与标题和内核状态同行，空间不足则隐藏，不换行或遮挡。点击定位，高亮随实际滚动位置同步，滚到底部选中计划任务；内容无需滚动时选中常规，保留同一滚动内容及尚未保存的输入。 |

导入器先打开已有校验表单，不跳过名称、地址、文件校验或失败恢复。预览展示固定示例，不执行网络探测，也不把演示速度、国旗或连接行当作运行结果。正式首页的探测范围和生命周期见下文，不虚构历史曲线。

代理和订阅的视图选择分别保存在 `PageViews`，不改业务模型、分页、选择或草稿；桌面通过窗口协议保存，关闭并重建界面后恢复。移动端在当前窗口内保留选择。按钮使用随包离线的 [Lucide 宫格/列表图标](../crates/client-ui/ui/icons/SOURCE.md)：宫格态显示列表图标，列表态显示宫格图标，表示点击后要切换到的视图，并保留无障碍名称。列表按资源管理器式紧凑行压缩：代理列表仅名称、延迟和详情，订阅列表仅名称、状态和操作；完整元数据在现有详情展开中显示。预览可用 `--list-view` 检查列表，本地导入配置单独标记为本地；各类订阅保留相同操作入口，不可用按钮置灰，当前项的“使用中”保留强调色但不能重复点击，权限见[订阅操作](subscriptions.md#订阅操作)。桌面添加与编辑表单的名称、来源字段填满弹窗正文，不受短按钮的内容宽度限制。

移动订阅操作和节点测速/详情采用 13sp 紧凑文字，常规字号下按钮表面为 40px 高，实际布局与触控区域保持至少 48px；上下留白也可点击且不侵占相邻按钮。大字号随文字增高，宫格/列表图标仍保留 48px 独立触控区。

## PR #36 的融合与兼容

融合以当前开发分支为基础，吸收贡献提交 `4848f3d` 的桌面网络概览、地址隐私遮盖、连接数量、订阅卡片及设置行组件。保留现有暖色视觉、几何字标和 Android/iOS 手机及平板界面；桌面设置子导航后续调整为页头横向入口。布局以正式 Slint 组件及其预览为准，原交互 HTML 设计稿已移除，历史参考可从 Git 查阅。版本、emoji 字符串和后台协议沿当前开发分支，不能整份覆盖贡献者基于旧 `main` 的文件。

桌面与 Android 手机/平板首页均接入网络信息和服务状态，共用检测目标、结果分类及地址隐私投影；iOS 仅同步共享界面和离线示例，没有可用的原生探测宿主。Android 通过 `ConnectivityManager` / `LinkProperties` 读取已连接的非 VPN 网络地址及 DNS，系统网络变化、VPN、节点或配置变化会使旧结果失效；不读取桌面路由实现，也不修改系统网络。

移动首页按可用内容宽度及字号重排：常规手机的网络字段与服务卡片可用双列，窄屏或大字号退为单列；标题与隐私/刷新操作同排，触控范围保持 48px。服务名称与耗时同排，详情另起一行。有效内容宽度达到 640px 时切为平板双栏，左侧为运行状态、流量与网络信息，右侧为服务状态及最多四条连接摘要，完整列表通过连接入口查看，避免一侧持续拉长。字号放大或分屏导致空间不足时整页恢复单列。

网络信息、服务状态与活跃连接直接共用桌面/移动端的 `HomeSection`、`HomeSectionHeader`、`NetworkInfo`、`ServiceStatus` 和 `HomeConnections`，外层统一 12px 内边距、18px 圆角、标题层次及基础卡片间距。三块标题行使用同一高度与垂直居中规则：桌面跟随主题控件高度，移动端至少 48px；有无右侧按钮不改变标题行高度，标题至分隔线间距一致。连接的域名/线路与上传/下载速率组成完整一行，分隔线固定在整行底部的留白中。平板列宽由可用视口统一计算，等宽分配，不根据节点名或服务文案伸缩；同列卡片填满列宽、左右边缘对齐，手机三块使用同一正文宽度。Android 仍按系统 SP 换算字号，不把桌面鼠标控件尺寸照搬到手机。首页从现有快照通道读取真实连接摘要，共享解码器最多保留四条连接元数据，同时计数全部记录；后台及离开首页继续释放不需要的列表。

网络概览只在首页可见、应用空闲时自动启动；每次结果最长保留 180 秒，节点或网络变化后至少间隔 5 秒重测，也可手动检测。离开首页、隐藏窗口或切换配置时取消在途请求，旧代次回调不能覆盖新结果。内核未运行时只读取本机地址和 DNS 配置，不执行 DNS 查询、出口或服务请求。隐私开关在数据投影阶段替换本机、出口、DNS 配置及解析结果中的地址，手机用“已隐藏”呈现；检测失败仍显示具体原因。

服务检测通过本机混合代理端口请求真实站点，计时到收到 HTTP 响应头，不跟随重定向；包含连接、DNS、TLS 与站点响应开销。节点延迟则由 mihomo 请求轻量 `generate_204` 地址，两者的目标和测量范围不同，不能直接比较。403/429 显示“可达”，不表示解锁、登录或业务可用，5xx 保留异常。系统 DNS 的 Fake-IP 结果单独标明，不冒充真实出口。隐私按钮先在投影层替换内网、出口及 DNS 服务器地址，再绘制遮盖效果；不把原地址放入遮盖层或无障碍标签。

## 通知与警告

行为分级的权威说明见[通知与故障反馈](../crates/client-ui/README.md#通知与故障反馈)。

Claude 保护启用后，各页顶部保留只读状态条和“关闭保护”按钮；保护期间更新、切换、订阅编辑及网络设置修改操作置灰，诊断、详情和关闭保护仍可用。保护状态条不是可关闭的临时通知，只有实际关闭保护后才消失。

| 等级 | 示例 | 视觉 |
| --- | --- | --- |
| 成功 | 订阅已更新、设置已保存 | 底部紧凑反色提示，下沿进度条表示剩余时间；点击正文关闭，5 秒后自动消退，再次通知重新计时。 |
| 可恢复错误 | Geo、检查更新、订阅更新失败，原状态保留 | 实体表面浮层，错误标记和简短标题，完整原因可滚动；集中导出诊断与新建 Issue 操作，不阻断背景。 |
| 严重故障 | 内核无法启动、VPN 无法启动、保护恢复失败 | 居中圆角警告框与遮罩，先展示具体原因，诊断与可用恢复操作同排，使用一致的轻量按钮样式。 |
| 持续状态警告 | Claude 保护健康异常、外部网络接管 | 页头下的紧凑状态警告，保留原因和详情入口，随实际状态恢复；不以重复弹窗代替状态。 |

成功提示可以点击正文关闭；两类错误使用操作区的“关闭”，点击正文或卡片空白不关闭，诊断/恢复按钮各自处理。长文本不能把操作区挤出视口，手机大字号允许操作分列或纵排。关闭警告不丢弃原编辑草稿，也不表示故障已经恢复。严重故障优先于背景表单和普通提示；完整诊断不自动上传，用户通过 Issue 入口审阅后自行提交。

配置、订阅、策略组和节点的摘要名称保持单行省略，不参与决定状态、按钮及电源入口的宽度；详情保留完整原文。`preview-slint.py --long-names` 使用中英文、emoji 和不带空格的长名称验证桌面、手机及 Pad；不以改写或截断存储内容换取布局正常。

以下改动已进入本轮源码；预览和本地交互检查不代替同提交 CI 或安装后验证。按[循环审查](loop-workflow.md)和[多尺寸 UI 检查](loop-ui.md)核对。

| 任务 | 约束与验收 |
| --- | --- |
| 修复桌面滚动 | `PageScroll` 使用无滚动条的 `Flickable`，内容布局固定在原点，滚动范围按真实内容高度计算。内容缩短或窗口变高时限制偏移，短内容留在顶部；连接列表沿用同一自然布局，不再混用行坐标和手动内容高度。保留隐藏滚动条与 8px 底边。 |

| README 几何字标 | 标题使用与 `ui/components/brand.slint` 相同的路径，保存在 `resources/icons/wordmark-light.svg`、`wordmark-dark.svg`，按 GitHub 主题选择。保留 `Clash of Rust` 替代文字，不依赖在线资源或额外字体。 |
