# Windows CI 测试清单

普通 PR / main CI 在 Windows x64 和 ARM64 上各运行一套，使用原生 Rust
Release 构建。两种架构的测试内容相同，x64 使用 Python 3.11，ARM64 使用
Python 3.13。入口：`scripts/run-ci.py`；Windows 原生测试组入口：
`scripts/windows_ci.py`。

## 每次 PR 必须通过

| 编号 | 测试 | 检查内容 |
| --- | --- | --- |
| W01 | 格式 | `cargo fmt --all -- --check` |
| W02 | 静态检查 | 全目标 Release Clippy，警告视为错误 |
| W03 | 编译 | GUI、TUN launcher 和全部测试程序；工具链、Python、资源均匹配 runner 架构 |
| W04 | Rust 常规测试 | API、配置、订阅、规则、IP 检测、内存、代理状态切换、更新、错误归因及 GUI 状态；串行避免系统状态互相干扰 |
| W05 | Python 构建工具 | PE 版本读取、版本及架构校验、资源白名单、Geo 校验、打包协议、发布条件；平台不适用项显式跳过 |
| W06 | 产物协议 | 构建产物元数据、内容与哈希验证，拒绝不匹配或损坏产物 |
| W07 | 真实内核集成 | 离线 Geo、内核生命周期、端口冲突后重试、Geo 替换、模式持久化、订阅删除、磁盘失败回滚、附加规则更新与恢复、自定义规则分流和节点选择 |
| W08 | 原生托盘 | 创建和关闭；runner 没有 Explorer 时验证明确失败，不隐藏成不可见窗口 |
| W09 | 管理员任务权限 | 原生 Task Scheduler 创建、迁移、开关和删除；受限旧任务修复保留开关；拒绝覆盖其他安装目录任务 |
| W10 | 图标 | GUI PE 内嵌全部 7 个批准的图标尺寸 |
| W11 | 更新助手 | 修改或删除下载文件、损坏更新计划均在安装前拒绝；含空格路径 |
| W12 | 普通账号预检 | 临时 Users 账号确实不是管理员，完整性级别为 medium；能创建命名事件；子进程失败退出码真实传回 |
| W13 | 普通账号磁盘测试 | 10 项配置测试和 7 项事务测试：原子保存、真实文件锁、保留原文件、路径错误、升级默认值、中断及日志锁恢复 |
| W14 | 普通账号桌面控制 | 唤醒事件可发信号且只消费一次；单实例初始化与重复启动识别 |
| W15 | 普通账号新任务 | 创建、禁用、重新启用和删除随机测试任务；强制走计划任务，不用 Run 回退掩盖失败 |
| W16 | 普通账号真实 GUI | 首次配置、默认直连、内核接口就绪、前台及后台、旧版设置升级、中断事务启动回滚、管理员运行后再普通账号运行；并验证窗口尺寸恢复与缩放 |
| W17 | 自启动 CLI | 普通账号开启、状态查询、删除、关闭状态；不同账号的修复助手必须拒绝 |
| W18 | 产物导出 | 所有测试成功后才导出构建程序及源码提交、版本、平台、工具链和 SHA-256 清单 |

W05–W17 整理成 8 个有名字的原生测试组，在 Actions 日志中分别折叠显示。
它们逐组写入 `target/windows-ci-report.json`，状态为 `passed`、`failed` 或
`not_run`，并记录耗时；失败后仍上传 `windows-ci-report-x64` /
`windows-ci-report-arm64`。如果失败发生在编译之前，尚无原生组报告，以
编译步骤日志为准。不得将未执行的测试记为通过。

## 发布安装包检查（Publish Release）

以下是独立发布工作流的测试，不在每次 PR 安装正式产品：

| 编号 | 测试 | 检查内容 |
| --- | --- | --- |
| P01 | 包内容 | 架构、PE 版本、安装器和应用图标、离线资源清单及 SHA-256；排除旧 Bash / MSYS 文件 |
| P02 | 隔离安装器夹具 | 首装、重复安装拒绝、同版本更新、合作退出、拒绝退出与超时、失败恢复、重装、旧版迁移、卸载及用户文件保留 |
| P03 | 正式安装包 | 在一次性 Actions VM 安装最终包、同版本更新和卸载，验证安装文件字节与发布输入一致 |
| P04 | Defender | 扫描最终安装包，检查扫描结果 |

真实 Windows TUN 的 UAC 交互、网络路由与 DNS 接管，以及真实系统代理
切换后的网络可达性仍需人工验收；常规 CI 覆盖切换状态机、回滚及内核
配置，普通账号 GUI 测试始终关闭系统代理和 TUN。

## 本地普通权限验证

先退出正在运行的客户端，在 Windows 当前账号的普通权限终端执行：

```powershell
python scripts/test-windows-local.py 路径/clash-of-rust.exe --transaction-recovery
cargo test --lib native_ordinary_user -- --ignored --test-threads=1
```

GUI 测试使用临时数据、动态端口和独立密钥，覆盖前台、后台启动、旧设置
升级、文件保存与中断事务恢复；关闭系统代理及 TUN，不改用户自启动项。
原生任务测试只创建、开关和删除随机命名的测试任务，强制验证 Task Scheduler。
