# 网络工具箱

桌面、Android、CLI 和 TUI 共用 12 项检查逻辑，已包含在 0.7.2 正式版中；iOS 只有界面原型。工具按需运行，不常驻扫描，不保留历史。输入、操作和当前结果放在同一张卡片；切换页面或工具时取消检查并清空，迟到结果不得回填。

## 工具与路径

| 工具 | CLI 子命令 `cor network …` | 检查内容 |
| --- | --- | --- |
| 网站检查 | `check URL` | 快速定位解析、代理入口、双协议响应及真实命中规则和策略链；结果可转入专项工具 |
| DNS 查询 | `dns HOST` | 系统/内核解析对照及指定类型记录、TTL、返回码；结果不同不单独视为故障 |
| 连接耗时 | `phase URL` | 独立内核 DNS、本机 SOCKS5、代理建立目标连接、TLS、首字节的测量边界 |
| IPv4 / IPv6 | `family URL` | 分别用目标地址族经本机代理建连；HTTPS 保留原域名验证，无 AAAA 不伪造连接失败 |
| TLS 证书 | `tls HOST` | 仅握手并验证域名、有效期、信任链和证书摘要，不发送 HTTP 请求 |
| 短时稳定性 | `stability URL` | 有限次请求、传输失败数量、HTTP 状态分布和响应头耗时分布 |
| UDP 连通 | `udp SERVER[:PORT]` | 经本机 SOCKS5 UDP 中继发送 DNS 探针，默认端口 53 |
| Ping | `ping HOST` | 系统 ICMP；不代表代理节点延迟 |
| 路由追踪 | `trace HOST` | 系统逐跳响应；部分跳不响应不等于断网 |
| 限量下载 | `download URL` | 有时间和流量上限的接收检查；字节数、时长、样本吞吐和结束原因，正文即时丢弃 |
| TCP 端口 | `tcp HOST[:PORT]` | 经本机 SOCKS5 连接指定端口，不发送应用数据 |
| HTTP 检查 | `http URL` | HEAD/GET/OPTIONS、协议、状态、业务状态说明、安全响应头、最多 4 KiB 正文长度；正文丢弃 |

网站检查负责快速定位；专项工具展开相应证据，不重复整套检查。HTTP、稳定性和下载不额外查询实际策略链；需要确认规则和出口时使用网站检查。与 [Surge CLI](https://manual.nssurge.com/tools/cli.html) 的轻量检查对照；MITM、脚本环境、网关及远程组网属于架构扩展，未包含在工具中。

### 原入口迁移

“规则与出口”并入网站检查；静态规则预判和配置类型/数量差异摘要移除，不再维持另一套不完整的规则判断。配置查询使用 `cor config get`、`cor config effective`，校验使用 `cor config check`。

流量汇总已移除；当前连接的上传、下载和规则可在连接页或通过 `cor connection list` 查看。

节点详情归代理页：保留类型、所在策略组和当前选择链，最近延迟不代表当前健康；内核未提供测量时间时不猜测。内核版本与连接状态使用已有状态/诊断入口，不继续提供单次托管堆的独立“性能分析”。

旧 CLI `network explain/rule/config-diff/traffic/performance/node` 仍能识别，执行时返回非零退出码及迁移提示，不发起检查、不静默改变 JSON 结果。它们从普通工具菜单、补全和 TUI 操作列表移除，`cor help all` 与明确查询旧命令帮助仍说明迁移。

网站及 HTTP 检查经现有内核代理，不自动启动内核、切换节点或回退 DIRECT。HTTP 403、500 等只证明收到响应，不证明服务可用；下载则要求成功状态。重定向不会自动跳转。输入允许省略协议；网站检查的双协议选择见 [CLI 检查](cli/maintenance.md#配置诊断与检测)，其余 HTTP 工具使用解析后的目标，TLS 工具强制 HTTPS。

系统 Ping/追踪不经过系统 HTTP 代理，TUN 是否接管由路由决定。缺组件、权限不足、超时和非零退出分别报告，不用 TCP 冒充 ICMP；取消会终止自有子进程。Android 系统可能没有 traceroute，此时工具明确不可用。

路由追踪逐跳展示数值地址和系统给出的耗时。`*` 表示等待期间未收到该探针响应，可能是设备不回包、过滤、限速或超时；不能推断该跳丢弃了业务流量。观察到目标地址时明确“已观察到目标响应”，中间的星号不降低此结论；只到跳数上限、全无响应或格式无法识别时显示“未确认到达”，不把命令退出 0 当成到达目标。默认最多 8 跳，每个探针等待 1 秒；Linux/macOS 每跳一次，Windows 使用 tracert 的三次探针。此结果不等同代理节点到目标的完整路径。

## 参数与边界

默认 5 次、间隔 1000 毫秒、单次时限 10 秒、下载上限 8 MiB、最大 8 跳。GUI 显示对应工具的参数，切换工具恢复默认值；CLI 接受下列对应选项。TUI 在工具页按 `←` / `→` 切换工具，`o` 直接编辑当前工具的目标和适用参数；DNS 类型与 HTTP 方法用左右键选择，数值按 Enter 编辑，向下选择「应用参数」。参数仅本页生效，切页或切换工具恢复默认，不写入设置或启动新后台；Esc 丢弃未应用的草稿，检查期间 Esc 取消请求。结果随宽度折行，用上下键逐显示行滚动，缩放时保留当前结果附近的位置。

| 选项 | 有效范围 | 使用工具 |
| --- | --- | --- |
| `--count` | 1～20 | 稳定性、Ping |
| `--interval-ms` | 100～5000 | 稳定性 |
| `--seconds` | 1～30 | 耗时、地址族、TLS、稳定性、UDP、下载、TCP、HTTP |
| `--max-bytes` | 1024～16777216 | 下载；GUI 以整数 MiB、TUI 以整数 KiB 输入 |
| `--max-hops` | 1～16 | 追踪 |
| `--type` | ADDR、A、AAAA、CNAME、MX、TXT、NS、SOA、PTR、CAA | DNS；默认 ADDR（系统 A/AAAA 与内核真实地址对照） |
| `--method` | HEAD、GET、OPTIONS | HTTP 检查；默认 HEAD |

记录类型和方法接受大小写。指定 DNS 类型时仍保留系统 A/AAAA 对照，详细记录来自内核的 `/dns/query`；展示 TTL 与返回的 AA/RA 标志，缺失时明确“未提供”，不推算权威服务器。TXT/SOA 正文不进入报告，最多展示 16 条回答。PTR 输入反向查询域名，例如 `1.2.0.192.in-addr.arpa`。TCP 省略端口时为 443，HTTP URL 则使用其明确端口或协议默认端口；空端口、0、越界值拒绝。

代理建立目标连接的耗时包括代理侧 DNS、规则及出站处理，不能当成独立的远端 TCP 握手时间；单独查询的内核 DNS 耗时不与其简单相加。IPv4/IPv6 测试验证代理访问目标地址族，HTTPS 验证原域名，HTTP 只建立连接；不能据此推断本机网络、TUN 或节点入口的 IPv6 能力。TLS 成功不依赖 HTTP 响应，证书过期、尚未生效、域名不符、未知颁发机构与其他握手错误分别报告。

HTTP 403、500 属于收到响应，稳定性按传输失败与 HTTP 状态分开统计；短样本显示最低、中位和最高耗时，不外推长期可用性。下载平均吞吐包含建连等待，只代表本次限量样本，不声明线路最大带宽。CSP 只显示是否设置，Cookie、认证头、重定向地址中的路径与查询不进入报告。

稳定性总预算最多 120 秒；次数、间隔和单次时限组合过长时返回已取得的结果并明确超时。HTTP/SOCKS 请求和系统进程也有总预算；不能无限等待。系统输出最多各保留 8 KiB，报告最多 48 项，每项最多 2048 字符；原始 URL 路径、查询、账号密码和下载正文不进入报告。证书只展示受限字段。

## 保护与报告

Claude 保护开启或状态未知时，不查询系统 DNS，不发送 UDP、ICMP 或逐跳探针；这些工具返回不可用原因。用户关闭 UDP 时不发送 UDP 探针。其他工具仍经本机代理和现有规则，不借诊断绕过保护。

新增工具的 JSON 包含 `schema`、`tool`、脱敏源站 `target`、`elapsed_ms`、`status` 和逐项 `entries`，每项含 `label`、`detail`、`success`、`code`。`success=null` 表示未确认或说明；`complete`、`partial`、`failed`、`unavailable` 不能互相替代。GUI、Android 和 TUI 的共享文本报告在首行显示本次检查状态及总耗时；“完成”表示测量完成，HTTP 503 等仍按证据说明服务状态，不等同服务正常。已知状态、错误和测量文字按界面语言展示；JSON、DNS 返回内容、系统输出及其他外部原始证据保持原样。系统输出及正常达到流量/时限上限属于说明，不单独把成功检查降为部分完成；未捕获实际线路仍明确标为未确认。CLI 对 `failed/unavailable` 返回非零退出码，仍先输出报告；原有 `network check` 保留原 JSON 结构。

GUI 诊断携带当前工具、结果和错误码；CLI 用 `--json` 或 `--output FILE` 保存。TUI 按 `e` 填写 JSON 路径，将本次原报告脱敏后原子写入，不重新执行检查；失败保留路径和报告，演示模式不写文件。切页后当前结果被清除，需要时应先导出。错误码定义见[诊断说明](diagnostics.md#网络工具)。
