# 终端界面

[CLI 入口](../cli.md) · [运行与代理](runtime.md) · [内存基准](../workflows/memory.md)

在交互终端运行 `cor` 打开终端界面，见 [CLI 使用说明](../cli.md)。`cor ui --demo` 使用虚构数据，不连接后台或保存设置。TUI 有首页、节点、订阅、连接、规则、[工具](../network-tools.md)、设置和操作八页，与 CLI 共用业务、权限和诊断。本页覆盖 [0.7.3 正式版](../releases/0.7.3.md)。

导航、操作目录与设置支持简体中文和英文。首页和「设置 → 常规」均可选择语言，保存后立即刷新当前界面；其他客户端修改语言时也会同步，编辑表单期间保留草稿并在关闭表单后刷新。后台未运行时，首页也可保存语言，不会启动后台或内核。系统语言的匹配与单次覆盖见[帮助、脚本与输出](../cli.md#帮助脚本与输出)。

## 操作

| 按键 | 行为 |
| --- | --- |
| `1`～`8`、`Tab` | 首页、节点、订阅、连接、规则、工具、设置、操作间切换；表单内 Tab 选择下一项 |
| `↑` / `↓` | 选择列表项目 |
| `Enter` | 打开策略组或连接详情；编辑表单；执行前再次确认 |
| `s` | 节点页循环切换名称、延迟升序、延迟降序 |
| `o` | 工具页直接编辑当前工具的目标和适用参数 |
| `e` | 工具页将本次真实检查报告导出为 JSON，不重新执行检查 |
| `←` / `→`、空格 | 工具页左右键切换工具；表单内调整候选值，Enter 确认当前值或进入下一项 |
| `/` | 列表页搜索；工具页用于输入网址，首页不进入搜索。输入期间快捷键按普通文本处理 |
| `Esc` / 退格 | 返回组列表或清除搜索；确认框内取消操作 |
| `r` | 立即重试读取 |
| `Ctrl+U` | 清空正在输入的搜索词或字段 |
| `q` / `Ctrl+C` | 退出终端界面，保留原后台和代理 |

需要真实交互终端，自动读取尺寸并响应缩放。高度至少 24 行、导航文字能完整放下时保留两行完整导航；当前标签需要至少 50 列，不再一低于 80 列就折叠。宽度或高度不足时，使用居中的独立小标题标明当前页面，连接详情也单独注明。导航与正文/底部的压缩分别判断，50～79 列仍为按键帮助保留换行。高度至少十行时，切页提示另占一行，底部状态与按键帮助按实际宽度换行，完整按键组合尽量放在同一行，并按标题及底部实际行数为列表预留空间，不重复退出和返回提示。极小窗口优先显示选中项、编辑字段或待确认操作；不再按固定最小尺寸拒绝显示。列表名称、操作说明、空态与表单按显示宽度换行，滚动按实际显示行保留选中项目；单项超过整个正文时先显示其开头，较长输入草稿显示尾部，密钥继续掩码。连接长详情可分行滚动，即使只剩一两行仍可操作和退出。尺寸约每 40 毫秒检查一次，变化立即重排，不等待每秒的后台采样。支持 `--no-color` / `NO_COLOR`，恢复退出前的终端输入模式、光标及主屏幕。终端没有内置字体；emoji 是否可见取决于终端字体与字体回退。

## 后台与安全边界

打开、浏览和退出不会创建后台、启动内核或修改代理；后台未运行时可在首页选择「启动后台与内核」，确认后执行，也可在「操作」页使用 `start`。已有 GUI 时复用同一运行层，只请求当前页的快照。每秒采样，绘制只更新变化行，不持续积累连接历史；切页释放旧页数据和表单。

首页区分内核和后台，显示订阅、参考策略链、保护、双向速率及连接数。用上下键选择并按 Enter 启停内核，或直接修改语言、代理方式、运行模式、当前订阅及 Claude 保护；候选值、保存复核、权限、持久化与设置页共用。长项按宽度换行并跟随选中项，窄屏保留首页标题和操作提示。

首页另提供「检查更新」，区分检查中、最新版本、检查失败和当前平台缺少安装包；只有真实候选包含安装包时才显示「安装更新」。安装先复核所选版本，再恢复普通终端确认和授权，沿用 CLI 的 SHA256 校验及 `update status` 回执；交接后退出 TUI，释放程序文件。检查复用更新周期，0 关闭自动检查；手动检查推迟下次自动尝试，保护、状态过期、退出或通道变化时取消旧请求与确认。已有 GUI 后台时不重复启动自动检查，仍可手动查询。请求、候选和计时状态只由 `cor ui` 持有，关闭后释放，不增加纯 CLI 后台缓存或定时器；演示模式不查询或安装。

连接页与 GUI 共用名称、搜索和详情字段，CLI 与 Android 也使用相同的[域名与筛选约定](runtime.md#连接与日志)。回车打开详情，原始域名和真实嗅探结果分别显示，隐藏内核没有提供的空字段和尚未采样的速率，不逐行重复“未提供”；不会把原始域名或 IP 冒充嗅探结果。已有的目标 IP/端口、协议、进程、时间、规则、代理链、累计流量与速率保留。`↑` / `↓` 滚动分行后的详情，`d` 调用 CLI 补充解析，`x` 进入关闭此连接的确认表单。连接消失时保留原 ID 并明确提示，不把其他连接替换进详情；不增加常驻 DNS 解析器。

节点页显示实际已保存的排序，默认延迟从低到高；一个 `s` 入口按“名称 → 延迟从低到高 → 延迟从高到低 → 名称”循环，从当前模式接续。内置直连等特殊选项排在前面，未测速和超时节点排在已测速节点之后。排序保存在独立的 `tui_node_sort` 设置中，不改变 GUI 的 `node_sort`，刷新、筛选或测速改变顺序时继续选中原节点。保存失败不提前改变显示状态；保存只改变显示，不重载内核，保护期间仍可操作。演示模式仅改变本次画面。

节点页自动组只读，显示由内核自动选择的说明，不再允许提交其成员后误报列表变化。上级手动组选择 `AUTO` 时，自动组内部换节点不会使目标失效；订阅变化、组或成员消失、内核停止及保护开启仍拒绝提交。目标名称保留 emoji 与空格，后台执行最终校验。

工具页提供 12 项专项检查，用 `←` / `→` 切换工具，按 `/` 输入目标，回车结束输入，再按回车检查；全部工具需要目标。按 `o` 在当前页编辑目标、次数、时限等适用参数；只显示当前工具支持的字段，DNS 类型与 HTTP 方法用左右键选择，数值按 Enter 编辑，向下选择「应用参数」，再按 Enter 开始检查。校验失败保留草稿和上次参数，Esc 丢弃未应用修改；应用参数只作用于本页，不保存到磁盘，切页或切换工具恢复默认。打开参数会取消进行中的检查，原后台与内核保持复用。规则与出口并入网站检查，已移除入口及信息归属见[网络工具](../network-tools.md#原入口迁移)。结果按终端宽度折行，使用 `↑` / `↓` 逐显示行滚动到长条目的末尾，缩放后保持当前结果附近的位置；窄屏至少为结果保留一半正文区域。`Esc` 取消检查并清除结果，切页清除。演示模式只显示虚构结果，不访问网络。

真实检查完成后按 `e`，填写 JSON 文件路径并选择「导出 JSON」；失败或不可用的报告也可导出，包含原状态、总耗时和逐项错误码，不重新发起网络请求。文件使用与 CLI 相同的脱敏、结构化包装和原子写入；写入失败保留路径及原报告，可修改路径后重试。没有真实报告或处于演示模式时不写文件。当前报告与参数同属终端页面，切换工具、目标或页面后释放，纯 CLI/后台不保留专属副本。

## 设置与管理表单

设置页按常规、网络、更新、计划任务显示小标题，名称与 GUI 对应；搜索匹配分类、中文名称、配置键及 DNS 标签。提供端口、运行模式、代理方式、保护、DNS/Fake-IP、IPv6、UDP、测速/订阅/更新周期、更新通道和终端排序。自动检查更新、订阅自动更新和定时测速归入计划任务，数值标明分钟及 0 关闭。运行模式和代理方式采用后台实际观测；代理启动偏好不同时单独标明。Fake-IP 显示 DNS 覆盖影响，排除项显示实际数量，不把空数组当成缺失配置。回车打开项目；左右键或空格调整候选值，Enter 确认当前值；文字和数值按 Enter 编辑，底部标明「输入中」。保存前再次确认，普通设置直接在 TUI 内通过共享命令保存并读取实际结果；代理方式和保护沿用普通终端授权。失败保留草稿，取消本项恢复编辑前内容，退出表单丢弃草稿。后台刷新不覆盖草稿；切换订阅时清理旧订阅提示，并仅取消与原订阅绑定的管理表单。

当前源码中，Fake-IP 排除项使用独立管理页：顶部输入新增域名，多个域名用逗号分隔，粘贴换行同样识别；列表标明应用默认项、自定义项及启用状态。选中默认项可停用或恢复，自定义项可删除；恢复全部默认项会保留自定义项。每次保存使用完整设置的旧状态进行原子比对，另一客户端已修改设置时拒绝旧确认并保留输入。DNS 覆盖关闭或 Claude 保护期间仍可查看，写操作沿用共享校验。订阅原有过滤独立合并，停用应用项不等于删除订阅过滤。长条目按终端宽度换行，选中条目随视口滚动，子页保留标题；退出释放终端专属列表。

订阅页按名称列出已保存订阅，标出当前项及内置/本地/远程类型；远程订阅用量和到期摘要在当前行有足够宽度时显示。搜索后选择名称，回车打开候选值，向下选择保存并确认，复用后台 `Activate`，不要求填写 CLI 文本。成功后读回实际当前订阅；权限拒绝、离线校验或订阅被删除时保留失败原因，不提前改变当前标记。新增、来源编辑、更新和删除仍由操作页提供。

规则页列出原文、订阅/自定义/快捷规则来源、启停及重复状态，可按原文、稳定 ID 或来源搜索。回车打开该行可用操作：订阅原规则只调整顺序；自定义规则可移动、编辑、启停和删除；快捷规则转入独立管理入口。顶部可新增单行自定义规则，并查看当前可用策略。输入、重复及位置校验复用 CLI 的共享规则变更，确认后以旧规则修订值原子保存；另一客户端或订阅来源已变化时拒绝旧操作，失败保留输入。原订阅 YAML 不改写，成功后读回实际规则并保持选中项。

「快捷规则」入口单独列出当前订阅的五项开关；订阅已包含的规则禁止重复添加，内置订阅、未选订阅和读取失败分别说明。后台在同一次持锁写入中复核当前订阅和最新包含情况，拒绝旧来源确认。TUI 按需共享规则文档和短时读取状态，最多复用五秒，切页或退出释放；纯 CLI/后台不新增专属缓存、定时器或轮询。旧版后台命令不可用时先重启后台，不回退到缺少原子校验的写入。

「操作」按同一 CLI 命令目录生成表单，支持文字筛选，覆盖启动/停止、订阅、节点测试、规则、连接、日志、诊断、网络工具、Geo、更新、自启动、服务状态和补全等管理命令。每个位置参数与命令选项单独填写；含空格、emoji 或标点的值无需 shell 引号，数组使用 JSON，布尔选项填 `true` 开启或留空关闭。必填项、互斥选项和数值范围使用 CLI 原有校验。前台进程入口 `run` 和再次打开界面的 `ui` 仍直接从 CLI 使用。

确认执行后暂停 TUI，恢复普通终端，直接调用同一 CLI 分发器显示结果、下载进度及系统授权；不拼接 shell、不默认传 `--yes`、不绕过保护。沿用当前账户、数据目录、资源路径和超时，完成后按 Enter 返回界面。软件安装操作完成或交接后退出 TUI，释放 Windows 等平台需要替换的可执行文件；结果用 `cor update status` 查看，需要时重新运行 `cor ui`。持续跟随类命令或授权期间的 Ctrl+C 退出整个 CLI；已经提交的后台操作仍以实际状态为准。输出留在终端，不在 TUI 内积累历史。

Claude 保护期间仍可导航、只读查询和修改纯外观；网络、订阅、规则、更新、Geo、自启动等写操作继续由原后台拒绝。新增表单不会另开一套设置保存或权限逻辑，具体边界见[操作权限](../claude-protection.md#操作权限)。

### 三端能力与差异

| 能力 | TUI 与 GUI/CLI 的关系 | 分类与理由 |
| --- | --- | --- |
| 常用业务设置、订阅切换、规则与快捷规则 | TUI 直接选择和确认；规则共用 `RuleChange` 校验、`SaveRules` 修订校验和后台事务，快捷规则另复核当前订阅及包含状态 | 适用能力已接入；后台决定权限、当前数据与持久化 |
| 首页操作与版本更新 | 直接操作启停、代理、模式、订阅及保护；手动或按周期查询，真实候选提供安装入口，固定所选版本并交给 CLI 安装链 | 原有遗漏补齐；自动检查避开 GUI 后台，授权与安装在普通终端完成，状态不进入纯 CLI 后台 |
| 网络工具参数和结果 | TUI 在工具页直接编辑适用字段，共用 `Options`、校验与检查入口；结果按显示行滚动，原报告直接导出 JSON | 原有遗漏补齐；参数与报告仅当前页面持有，切换工具恢复默认，导出复用 CLI 文件包装和原子写入 |
| 节点排序、域名与嗅探、连接详情 | 共用排序和连接业务；TUI 独立保存终端显示偏好 | 原有遗漏补齐；嗅探空值在三端均不回填成原始域名 |
| 主题、强调色、字号、托盘和窗口布局 | 不进入 TUI 常用设置；CLI 高级配置入口保留 | 合理差异：终端由自身字体、颜色及 `NO_COLOR` 控制 |
| 文件选择、订阅来源和规则输入方式 | 操作页填写文件路径和订阅来源；规则页输入完整单行规则；GUI 保留文件选择、拖动和结构化编辑 | 合理交互差异，业务校验共用；不宣称终端无法实现更丰富的编辑器 |
| 系统授权、软件安装与持续命令 | 确认后恢复普通终端；安装交接后退出 TUI | 合理生命周期差异，沿用原有授权、输出和程序文件释放流程 |

当前未确认有必须删除的业务能力或无法实现而待取舍的项目；新增明确障碍时按[三端差异分类](../loop-checklist.md#三端差异分类)记录证据并交维护者确认。设置、候选值与详情投影只由 `cor ui` 的状态持有，切页或退出释放；持久选择使用原有磁盘设置，不向纯 CLI/后台添加专用缓存或轮询。

读取失败显示具体原因，旧快照明确标记为参考数据并禁止提交；退出后沿用原来的 `--user` / `--data-dir` / `--resources` 导出诊断。退出不撤销已经提交的后台操作。

AI 可通过 PTY 操作 TUI，自动化优先使用 `cor --json status`、`cor --json node list`、`cor --json node select GROUP NODE` 等稳定字段及退出码；不依赖颜色或屏幕位置推断执行结果。人类交互和机器入口一起维护，不削减已有命令。

## 验证与内存

CI 的 Linux CLI 专项在真实 PTY 验证非终端拒绝、无后台只读打开、搜索与确认、排序完整循环、双域名详情、小至两行的滚动与缩放、36～60 列的帮助换行与完整按键、设置编辑/撤销、网络参数应用/取消与切换工具、长结果逐行滚动和缩放、演示操作无副作用、快速按 `Esc` 后切页、`q` / `Ctrl+C` 退出及终端恢复。独立数据目录中的实际后台另验证原生保存、失败保留、磁盘持久化、重开与 CLI 修改后刷新，以及订阅名称选择、已包含快捷规则的只读状态和不同订阅间的状态隔离，并确认后台身份不变、未启动内核。按键解码覆盖单次读取和分包读取；演示帧不能代替真实节点切换或系统授权。新增场景须由修改后的同提交验证，不以旧原型证据代替。

桌面验收随既有 `linux-package-report-x64` 附件保存到 `tui/desktop/`，以 `index.html` 查看、`index.json` 核对捕获索引。八个主页面分别捕获 120×40 和 100×30 列/行；120×40 另覆盖策略组、连接详情及命令确认、十二工具参数与候选值、所有设置编辑器和保存确认、全部有效管理命令的字段、校验拒绝及虚构输入后的执行确认，以及隔离后台中的订阅候选和五项快捷规则。文字字段另捕获进入输入、清空/撤销帮助和光标状态，导出路径也展示编辑态。每帧标注来源提交、尺寸及演示/实际夹具状态；确认入口不代表已执行系统授权或安装。手机尺寸作为另外的回归证据，不代替桌面全页验收。

Memory Benchmark 对支持此原型的版本，在同一后台、内核和固定输入下依次测量纯 CLI、TUI 首页、节点、连接、网络及关闭后的后台；支持直接设置的版本另测设置列表与编辑器。前端、后台、内核分别统计，合计 PSS 对进程去重。网络场景只打开页面，不访问公网。方法见[内存基准](../workflows/memory.md)，CLI/TUI 对照与退出后的观测见[当前实测](../workflows/memory-current.md#cli-与-tui)；不承诺固定内存增量。
