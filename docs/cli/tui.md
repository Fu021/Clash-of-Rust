# 终端界面原型

[CLI 入口](../cli.md) · [运行与代理](runtime.md) · [内存基准](../workflows/memory.md)

使用 `cor ui` 打开；`cor ui --demo` 使用虚构数据，不连接后台或保存设置。原型包含首页、节点、连接和网址检查，尚未覆盖订阅编辑、规则、更新和完整设置。普通命令及 JSON 接口全部保留，后续 TUI 与命令行共用业务、权限、诊断和测试。

## 操作

| 按键 | 行为 |
| --- | --- |
| `1` / `2` / `3` / `4`、`Tab` | 首页、节点、连接、网络间切换 |
| `↑` / `↓` | 选择列表项目 |
| `Enter` | 打开策略组；选择成员后再次确认切换 |
| `/` | 搜索；网络页用于输入网址。输入期间快捷键按普通文本处理 |
| `Esc` / 退格 | 返回组列表或清除搜索；确认框内取消操作 |
| `r` | 立即重试读取 |
| `q` / `Ctrl+C` | 退出终端界面，保留原后台和代理 |

需要真实交互终端，最小 60 列 × 18 行；空间不足显示调整提示。支持 `--no-color` / `NO_COLOR`，恢复退出前的终端输入模式、光标及主屏幕。终端没有内置字体；emoji 是否可见取决于终端字体与字体回退。

## 后台与安全边界

打开、浏览和退出不会创建后台、启动内核或修改代理；后台未运行时提示先执行 `cor start`。已有 GUI 时复用同一运行层，只请求当前页的快照。每秒采样，绘制只更新变化行，不持续积累连接历史；切页释放旧页数据。

首页区分内核和后台，显示订阅、参考策略链、保护、双向速率及连接数；连接页展示选中连接实际命中的规则和线路。节点页可浏览自动组，只有可手动选择的组允许提交；目标名称保留 emoji 与空格。提交前重新核对内核运行状态、当前订阅、成员与保护，后台仍执行最终校验。Claude 保护开启时可浏览和搜索，禁止切换节点。

网络页按 `/` 输入目标，回车结束输入，再按回车检查；使用 `↑` / `↓` 滚动结果。结果与 `cor --json network check URL` 共用[双协议检查](maintenance.md#配置诊断与检测)，切页清除。演示模式只显示虚构结果，不访问网络。

读取失败显示具体原因，旧快照明确标记为参考数据并禁止提交；退出后沿用原来的 `--user` / `--data-dir` / `--resources` 导出诊断。退出不撤销已经提交的后台操作。

AI 可通过 PTY 操作 TUI，自动化优先使用 `cor --json status`、`cor --json node list`、`cor --json node select GROUP NODE` 等稳定字段及退出码；不依赖颜色或屏幕位置推断执行结果。人类交互和机器入口一起维护，不削减已有命令。

## 验证与内存

CI 的 Linux CLI 专项在真实 PTY 验证非终端拒绝、无后台只读打开、搜索与确认、缩放、`q` / `Ctrl+C` 退出及终端恢复，导出原型的真实演示帧。演示帧仅证明界面和键盘交互，不能代替真实节点切换。

Memory Benchmark 对支持此原型的版本，在同一后台、内核和固定输入下依次测量纯 CLI、TUI 首页、节点、连接、网络及关闭后的后台；前端、后台、内核分别统计，合计 PSS 对进程去重。网络场景只打开页面，不访问公网。详细口径及当前验证范围见[内存基准](../workflows/memory.md)。没有实测结果前，不承诺固定内存增量。
