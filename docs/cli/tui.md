# 终端界面

[CLI 入口](../cli.md) · [运行与代理](runtime.md) · [内存基准](../workflows/memory.md)

使用 `cor ui` 打开；`cor ui --demo` 使用虚构数据，不连接后台或保存设置。包含首页、节点、连接、[网络工具箱](../network-tools.md)、设置和管理操作。普通命令及 JSON 接口全部保留，与 TUI 共用业务、权限、诊断和测试。

## 操作

| 按键 | 行为 |
| --- | --- |
| `1`～`6`、`Tab` | 首页、节点、连接、网络、设置、操作间切换；表单内 Tab 选择下一项 |
| `↑` / `↓` | 选择列表项目 |
| `Enter` | 打开策略组或连接详情；编辑表单；执行前再次确认 |
| `/` | 搜索；网络页用于输入网址。输入期间快捷键按普通文本处理 |
| `Esc` / 退格 | 返回组列表或清除搜索；确认框内取消操作 |
| `r` | 立即重试读取 |
| `Ctrl+U` | 清空正在输入的搜索词或字段 |
| `q` / `Ctrl+C` | 退出终端界面，保留原后台和代理 |

需要真实交互终端，最小 60 列 × 18 行；空间不足显示调整提示。支持 `--no-color` / `NO_COLOR`，恢复退出前的终端输入模式、光标及主屏幕。终端没有内置字体；emoji 是否可见取决于终端字体与字体回退。

## 后台与安全边界

打开、浏览和退出不会创建后台、启动内核或修改代理；后台未运行时可在「操作」页执行 `start`。已有 GUI 时复用同一运行层，只请求当前页的快照。每秒采样，绘制只更新变化行，不持续积累连接历史；切页释放旧页数据和表单。

首页区分内核和后台，显示订阅、参考策略链、保护、双向速率及连接数。连接页回车打开详情，展示快照中的域名、嗅探域名、目标 IP/端口、协议、开始时间、规则、实际线路、累计流量与已有速率；`d` 调用 CLI 补充解析详情，`x` 进入关闭此连接的确认表单。连接消失时保留原 ID 并明确提示，不把其他连接替换进详情。

节点页自动组只读，显示由内核自动选择的说明，不再允许提交其成员后误报列表变化。上级手动组选择 `AUTO` 时，自动组内部换节点不会使目标失效；订阅变化、组或成员消失、内核停止及保护开启仍拒绝提交。目标名称保留 emoji 与空格，后台执行最终校验。

网络页用 `[` / `]` 切换工具，按 `/` 输入目标，回车结束输入，再按回车检查；配置差异、流量分解和内核运行不需要目标，可直接执行。节点详情输入完整名称，含 emoji 和空格时保持原样。使用 `↑` / `↓` 滚动结果，`Esc` 取消。结果与 CLI 共用[网络工具](../network-tools.md)，切页清除。此页使用默认参数，自定义次数与限额可在「操作」页填写对应命令的选项。演示模式只显示虚构结果，不访问网络。

## 设置与管理表单

设置表沿用 CLI 的可读和可修改字段清单。回车编辑可修改项；其他项进入 `config get` 查看完整值，通过专用命令改变代理方式、订阅、规则和保护。密钥不回填、不显示；较大的只读规则集合先显示数量，完整内容按需读取。编辑草稿不写盘，选择「检查并执行」后再次回车才提交；取消本项保留编辑前内容，退出表单丢弃全部草稿。

「操作」按同一 CLI 命令目录生成表单，支持文字筛选，覆盖启动/停止、订阅、节点测试、规则、连接、日志、诊断、网络工具、Geo、更新、自启动、服务状态和补全等管理命令。每个位置参数与命令选项单独填写；含空格、emoji 或标点的值无需 shell 引号，数组使用 JSON，布尔选项填 `true` 开启或留空关闭。必填项、互斥选项和数值范围使用 CLI 原有校验。前台进程入口 `run` 和再次打开界面的 `ui` 仍直接从 CLI 使用。

确认执行后暂停 TUI，恢复普通终端，直接调用同一 CLI 分发器显示结果、下载进度及系统授权；不拼接 shell、不默认传 `--yes`、不绕过保护。沿用当前账户、数据目录、资源路径和超时，完成后按 Enter 返回界面。软件安装操作完成或交接后退出 TUI，释放 Windows 等平台需要替换的可执行文件；结果用 `cor update status` 查看，需要时重新运行 `cor ui`。持续跟随类命令或授权期间的 Ctrl+C 退出整个 CLI；已经提交的后台操作仍以实际状态为准。输出留在终端，不在 TUI 内积累历史。

Claude 保护期间仍可导航、只读查询和修改纯外观；网络、订阅、规则、更新、Geo、自启动等写操作继续由原后台拒绝。新增表单不会另开一套设置保存或权限逻辑，具体边界见[操作权限](../claude-protection.md#操作权限)。

读取失败显示具体原因，旧快照明确标记为参考数据并禁止提交；退出后沿用原来的 `--user` / `--data-dir` / `--resources` 导出诊断。退出不撤销已经提交的后台操作。

AI 可通过 PTY 操作 TUI，自动化优先使用 `cor --json status`、`cor --json node list`、`cor --json node select GROUP NODE` 等稳定字段及退出码；不依赖颜色或屏幕位置推断执行结果。人类交互和机器入口一起维护，不削减已有命令。

## 验证与内存

CI 的 Linux CLI 专项在真实 PTY 验证非终端拒绝、无后台只读打开、搜索与确认、连接详情、设置编辑/撤销、演示操作无副作用、快速按 `Esc` 后切页、缩放、`q` / `Ctrl+C` 退出及终端恢复，导出实际演示帧。按键解码同时覆盖单次读取和分包读取，避免取消键吞掉后续快捷键。演示帧仅证明界面和键盘交互，不能代替真实节点切换或系统授权。新增设置和操作场景须由修改后的同提交验证，不以旧原型证据代替。

Memory Benchmark 对支持此原型的版本，在同一后台、内核和固定输入下依次测量纯 CLI、TUI 首页、节点、连接、网络及关闭后的后台；前端、后台、内核分别统计，合计 PSS 对进程去重。网络场景只打开页面，不访问公网。方法见[内存基准](../workflows/memory.md)，CLI/TUI 对照与退出后的观测见[当前实测](../workflows/memory-current.md#cli-与-tui)；不承诺固定内存增量。
