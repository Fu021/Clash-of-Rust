# 0.4.6 自动更新测试

正常版本安装包位于 `dist/`；相同代码、仅显示版本号降为 **0.3.0** 的测试安装包位于 `dist/update-test-0.3.0/`。测试包不作为正式 Release 附件发布。

1. 安装 0.3.0 测试包，打开设置页确认客户端版本为 0.3.0。若已有安装版本，按安装程序提示替换；订阅和设置会保留。
2. 等 GitHub 发布 0.4.6 后，在客户端检查更新，确认出现 0.4.6 以及“更新”“更新（代理）”两个选项。
3. 点击“更新”测试直连；测试代理下载时先启动内核，再点击“更新（代理）”。
4. 下载期间应显示百分比和下载大小；下载及校验完成后自动安装。完成系统授权后，客户端会正常退出并重新打开，设置页版本应变为 0.4.6。
5. 每次重复成功升级测试前，重新安装 0.3.0 测试包。

Windows 自动安装需要完成 UAC 授权。Linux 普通用户需要 `pkexec` 与可用的桌面授权服务。

## 失败情况

| 操作 | 预期 |
| --- | --- |
| 内核未启动时选择代理更新 | 上方提示先启动内核，无下载进度条 |
| 下载时断开网络或停止代理内核 | 网络错误或超时后，上方简要显示原因，进度条撤掉，允许重试 |
| 取消系统安装授权 | 上方显示授权取消，进度条撤掉，保留可操作的客户端 |
| 安装包缺失、损坏或校验不一致 | 显示原因，停止安装并撤掉进度条 |

若线上最新版本仍为 0.4.5，其 Windows 安装器不支持本次自动安装协议：Windows 测试版会发现 0.4.5，但选择更新会提示从 Release 手动升级。完整成功流程需要在线上提供 0.4.6 安装包及其同名 SHA256 文件后测试。

本地已验证真实 GitHub 代理下载和校验、Windows 隔离的 0.3.0 → 0.4.6 自动升级与写入失败恢复、Linux 隔离升级以及更新助手异常处理。桌面授权交互与完整在线升级仍需在正式安装环境确认。
