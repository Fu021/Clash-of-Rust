# Android 界面预览

[工作流索引](../workflows.md) · [应用分流](../android-application-routing.md) · [CI](ci.md)

`Android UI Previews` 经维护者授权独立运行，在可丢弃模拟器中打开生产 Slint 界面，重点检查应用分流页和实际已安装应用。复用成功 CI 的 `build-android-x64` 和 `dependency-snapshot`，不重新编译，不保存分流，不申请 VPN，不执行代理、流量、分流或输入法功能测试。

## 启动与来源

先等待目标提交的普通 CI 成功，再任选一个入口：

- 手动运行 `.github/workflows/android-previews.yml`，选择同一提交的分支，填写 `run_id`。
- 工作流尚未进入默认分支时，由维护者为同仓库 PR 添加 `android-previews` 标签触发；已存在时先移除再添加。此入口只响应本次加标签事件，不随之后的 push 自动运行，不对 fork 启用私网。目标提交没有成功 CI 时明确失败，不借用其他提交。

手动入口使用 GitHub 的 `workflow_dispatch`；默认分支的可用性受平台规则约束。标签入口使用普通 `pull_request: labeled`，不使用 `pull_request_target`，不扩大 fork 权限，不自动添加或移除标签。

`scripts/android_previews.py` 核对 CI 路径、成功终态、仓库、来源提交及两份输入附件的唯一性、有效期和 run/commit 身份。之后固定 checkout 该提交，下载对应 CI 附件，应用冻结依赖，核对 build 归档、版本、锁文件及 APK 摘要；设备实际 Android 版本也必须一致。

## 截图与边界

`androidUiPreviewCapturesPagesAndApplications` 使用真实触摸导航，采集首页、代理与订阅的宫格和列表、订阅编辑、工具页及其各页面、快捷规则、设置滚动位置和应用分流。每种尺寸先采集全部应用的收起状态，再切到仅选中查看清单和滚动；手机另点击仅选中／排除选中连续往返三轮，核对完整补集计数、两种模式截图及放弃修改提示，不保存编辑。清单核对其他应用可见、选择模式至少一个真实图标、已保存摘要及权限状态，全部模式必须没有显示应用或图标；保留图标失败计数。`applications-all/only/exclude` 替代旧下拉菜单和重复的模式按钮截图。此流程在同提交普通 CI 的模式与真实分流回归通过后进行。另以手机横屏和平板竖横屏检查主要页面与分流，记录每张图实际逻辑尺寸。平板由模拟器调整尺寸和密度，结束后恢复；它不能替代平板真机。

平板模拟使用 160 dpi，触摸前及清单验收都要求 Slint 缩放因子为 1，不能仅凭物理像素变化认定平板布局已生效。手机先确认回到竖屏，再调整尺寸、密度并重新固定平板方向，避免异步旋转与显示重配置相互覆盖。布局切换和截图前有界等待窗口重新获得焦点、Slint 恢复 live、实际窗口尺寸与逻辑尺寸乘缩放因子一致；持续失焦或无法恢复仍失败。运行 `42709003528`、`42715762792` 的 Android 12 在平板横屏切换时发生模拟器 SystemUI 导航栏空指针崩溃，与应用崩溃分开记录；`runtime-status.json` 和原 logcat 保留进程及异常，SystemUI 崩溃输出 warning，应用崩溃和原生运行时错误仍使任务失败。不能将尺寸已更新或截图恢复当作整个模拟器系统稳定的证据。

后台更新检查可能在截图过程中返回网络错误；操作前通过实际关闭按钮收起非模态错误，原截图和 logcat 仍保留错误证据。阻塞性错误继续使预览失败，不修改产品设置或跳过应用枚举、滚动断言。

清单 schema 3 为每个页面同时保留 `PixelCopy` 直接取得的窗口缓冲 PNG 与原始全屏 `*-screen.png`，不裁切、缩放或重绘。窗口图的像素尺寸必须与 Slint 的逻辑尺寸乘缩放因子一致，大面积黑色或透明样本明确失败。旧 Android 在模拟器强制调整尺寸后，自动化全屏截图曾出现黑边、缩放和裁切；窗口图用于对照应用实际缓冲，原全屏图继续保留系统合成证据，不能以尺寸正确或任务绿色代替阅图。

当前证据为提交 `8312c60`：CI `42785818645` 必需 14 项成功，预览 `42789444152` 的 Android 8.0～16 共 11 版本全部成功。每版 57 张窗口图和对应原屏幕图，共 627 对，摘要、布局、三种模式、应用枚举和滚动状态校验通过，应用及 Rust 崩溃为零。抽查 8.0、8.1、9、12、16 的手机和平板应用分流、图标、列表收起／滚动及设置页，未见此前黑边、缩小或裁切；Android 12 的一次模拟器 SystemUI 导航栏异常单独保留。多版本截图不执行 VPN 流量测试，真机及厂商 ROM 未验收。

加载失败、只剩本应用、列表滑动后偏移未变化、截图缺失、页面状态或布局尺寸不符、意外启动 VPN 均明确报错，不能把空白截图当成完成。触摸坐标计入实际窗口的屏幕原点，避免带刘海的横屏模拟器点偏。每个 `android-<版本>-ui-screenshots` 附件保留七天，包含各页面 PNG、`manifest.json`、设备版本、instrumentation 输出和 logcat。清单记录每张截图的页面、视图模式、逻辑及物理尺寸、窗口原点、列表偏移与应用枚举状态；信息仅来自 CI 模拟器。

证据目录读取失败时，只有同时确认是模拟器且支持调试，才允许重启该模拟器的 adbd 为 root 并重取；不用于真机或非调试系统。提取失败仍保留原始测试结果与导出日志，不改写为通过。

这些结果用于检查页面和应用枚举，不证明实际分流、VPN、厂商 ROM 或真机可用。本地 Slint 固定数据预览也不能替代本流程的真实枚举结果。代理/TUN 验证仍由普通 CI 执行，iOS 仍为 UI 原型。
