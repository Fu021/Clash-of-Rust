# 当前内存结果

[方法与范围](memory.md) · [loop 内存分析](../loop-workflow.md#统一收尾)

## Rust 1.100 与关闭跨 crate ThinLTO

预发布候选 `0.7.2-fix.1.rust100-cache`、提交 `2d4de9821701e49bdc6227ac3b4556435a9969de` 的 [Memory Benchmark `43396837393`](https://github.com/Fu021/Clash-of-Rust/actions/runs/43396837393) 为 release/light，2/2 成功。仍使用 100 节点、5 组、1,000 条规则与每场景 10 秒采样；24 场景、240 次映射采样有效，缺失为零。普通和快捷规则两组分别完成 20 次窗口销毁/重建，界面进程退出、内核驻留及纯 CLI 无图形会话证明均通过。

| 客户端 RSS 峰值场景 | 0.7.1（MiB） | 本次候选（MiB） |
| --- | ---: | ---: |
| 首页 | 53.80 | 53.95 |
| 代理组折叠 | 54.23 | 54.33 |
| 节点搜索 | 64.81 | 64.99 |
| 搜索后返回首页 | 57.16 | 57.32 |
| 首页、托盘可用 | 55.15 | 55.34 |
| 关闭窗口、驻留托盘 | 23.10 | 23.15 |
| 20 次窗口重建后 | 61.03 | 60.92 |
| 纯 CLI 后台 | 14.86 | 15.21 |

代表场景变化约 −0.11～+0.35 MiB，不能宣称内存优化。首页合计 PSS 为 89.69 → 92.33 MiB，托盘后台为 63.94 → 64.51 MiB；本次 Rust 由 1.99.1 变为 1.100.0，应用修复与 runner 实例也不同，不是只改变压缩强度的受控实验。安装包压缩在运行前完成，不据归档大小推断驻留内存。跨平台、真机及长期业务仍未在此基准验收。

## 0.7.1 正式版与 0.7.0

0.7.1 正式版提交 `2658c57ca55b207ad534c2acd129b392713579e2` 的 [Memory Benchmark `43298403773`](https://github.com/Fu021/Clash-of-Rust/actions/runs/43298403773) 为 release/light，2/2 成功。与 0.7.0 提交 `1af3ca9`、运行 `42978712845` 对比；输入均为 100 节点、5 组、1,000 条规则，工具链、采样时长及内核/Geo 字节一致，runner 实例不同。以下为客户端 RSS 观测峰值，不能推广为全部平台或负载的性能保证。

| 场景 | 0.7.0（MiB） | 0.7.1（MiB） |
| --- | ---: | ---: |
| 首页 | 53.34 | 53.80 |
| 代理组折叠 | 53.58 | 54.23 |
| 节点搜索 | 64.21 | 64.81 |
| 搜索后返回首页 | 56.49 | 57.16 |
| 首页、托盘可用 | 53.99 | 55.15 |
| 关闭窗口、驻留托盘 | 21.99 | 23.10 |
| 20 次窗口重建后 | 59.15 | 61.03 |
| 纯 CLI 后台 | 14.77 | 14.86 |

上述客户端 RSS 高约 0.09～1.88 MiB，不宣称内存改善。首页客户端与内核合计 PSS 为 92.38 → 89.69 MiB，关闭窗口后为 63.68 → 63.94 MiB；RSS 与 PSS 口径不同，不相加。普通规则及快捷规则全开两组各完成 20 次销毁/重建，均确认界面进程退出、内核保持运行及纯 CLI 无图形会话；单次短基准不能证明长期无泄漏。

24 个场景共 240 次映射采样均有效，没有缺失。渲染器匿名加堆私有页的同时间峰值：首页约 3.07 MiB，搜索约 13.28 MiB，返回首页约 5.64 MiB；宿主相应约 4.26、4.61、4.61 MiB。它们是映射采样，不是 RSS 或分配器精确峰值，也不与不同时间的进程峰值相加。

后续优先评估只为视口内节点创建控件：现有 light 搜索最多同时创建 240 张卡片，离页后已释放大部分，但仍存在明确的渲染器增量。实现必须保留原输入、分页、详情、滚动和动效语义，并复测；本轮没有通过减少节点、缩小输入或隐藏进程降低指标。没有新证据时不为微小单轮差值继续改动分配器或全局缓存。

本次仅 Linux x64 隔离环境；Android、Windows、macOS、真实网络业务与长期驻留内存未在此基准验收。
