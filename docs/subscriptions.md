# 订阅与自动更新

## 客户端兼容与格式

桌面 GUI、`cor` 与 Android 共用订阅下载器。请求的 User-Agent 为 `clash.meta mihomo ClashMeta clash-verge ClashVerge ClashMetaForAndroid clash-of-rust`，本客户端标识不携带版本号；同时接受 YAML 响应。标识只参与服务端格式识别，不转换节点协议。

每条可用路线使用同一 User-Agent 请求，单条路线最多等待 30 秒；响应不兼容、HTTP 错误或网络故障可尝试其他可用代理及[内核直连入口](agent-failures/downloads.md#tun-下的更新直连)，不重复发送相同的客户端标识。直连回退不要求切换节点、规则模式或订阅；最后的系统网络仍可能受其他 VPN/TUN 影响。仅含复制同一 SS 配置的“不支持本机场协议”提示节点时拒绝更新；提示旁仍有真实节点或非空 provider 时保留配置，避免误拒可用订阅。

订阅 URL 和显式格式参数保持原样；若链接固定了旧客户端格式，应在机场取得 Mihomo/Clash Meta YAML 链接。最终仍只接受有效的 mihomo YAML，协商全部失败不会覆盖已有订阅或运行状态。

遇到节点链接、Base64、sing-box/Xray 等其他内核配置，或 `proxies` / `proxy-providers` 结构错误时，桌面与 Android 顶部通知会明确提示“订阅格式不兼容，请选择 Mihomo/Clash Meta YAML 订阅”；`cor` 返回相同原因及失败退出码。不转换订阅，也不显示响应原文、节点凭据或订阅令牌。其他路线获取有效 YAML 时不报错，HTTP 拒绝和网络故障不冒充格式问题。定时更新的格式错误同样通知并记日志，桌面按事件去重，刷新不重复弹出；订阅已改变或关闭定时更新时，丢弃迟到的格式通知。

实现参考 Clash Verge Rev 的[默认 UA 与自定义入口](https://github.com/clash-verge-rev/clash-verge-rev/blob/4337bd85758d54d7b9044b2da3c9ac1176eae1f3/src-tauri/src/utils/network.rs#L244)。服务端实际匹配规则及用户订阅仍需现场验证，不能仅凭截图认定故意封禁。

运行配置保留节点、规则、provider 和 DNS 上游语义；控制器、代理入口与 TUN 启用由应用管理。订阅提供的 `listeners`、`tunnels`、外部控制器变体、面板、DoH 服务和 `iptables` 均被清除，`ntp.write-to-system` 强制关闭，DNS 覆盖关闭时也不保留订阅的 `dns.listen`。原始订阅不被改写。特权内核复用[共享入口校验](../crates/client-core/src/config/ingress.rs)，仅接受带密钥的本机控制器、本机 DNS 及受限 TCP 下载入口；这不是对所有未知 Mihomo 字段的允许列表。

## 订阅操作

桌面和 Android 订阅页支持按名称或来源搜索，宫格和列表默认显示全部订阅，也可切换为分页显示。已保存的分页偏好会在重开后恢复。

桌面宫格、列表保留“使用／使用中”“更新”“编辑”和“详情”入口，详情内保留“删除”。移动端宫格、列表常显“使用／使用中”和“详情”，展开详情后统一显示“更新”“编辑”“删除”，减少卡片占用。远程来源统一标为“订阅”，文件路径或空来源标为“本地”，不按来源是否为空区分。本地导入的订阅可以编辑、删除，“更新”置灰；改名读取已保存的 YAML，不要求原始导入文件仍存在。内置默认直连的“更新”“编辑”“删除”均置灰，后端仍拒绝编辑和删除默认直连。各端同一区域内的不可用操作不隐藏，避免不同类型订阅的按钮位置跳动。

当前订阅用强调色显示“使用中”，不能重复点击；其他不可用按钮置灰。Claude 保护及切换期间继续禁止修改，详情仍可查看。本地导入配置改名保留已有 YAML；编辑来源不等于已经成功更新配置，仍按各端既有校验和保存流程处理。

内置默认配置使用持久化的 `builtin` 身份，不再依赖显示名称。首次读取旧索引时按原名称与本地 `default.yaml` 来源迁移；旧 Android 空来源记录还须与随包默认 YAML 内容一致。迁移保留 ID、活动配置与原文件，之后改名或资源路径变化不改变身份；普通配置即使使用相同名称也不会被重新识别为默认直连。

已有活动订阅时，索引丢失、为空、损坏或缺少活动项会报告错误并保留原设置和订阅文件，不会改用默认直连。修复索引后可重新附着已有内核。

## 全局 YAML 覆写

桌面和 Android 的订阅页提供「全局覆写」，编辑数据目录内的 `merge.yaml`。覆写默认停用，停用后保留文件。应用时校验 YAML 和活动订阅引用，再沿用配置事务一并保存开关、覆写及所需的运行配置。运行中重载失败会恢复旧文件和运行配置，编辑器继续保留草稿。后续订阅切换和更新按相同生成链校验。内置默认直连始终使用自身规则，Claude 保护及切换期间覆写只读。

覆写支持 `rule-providers`、`prepend-rules` 和 `append-rules`。先应用单订阅规则，再将前置规则放在最前，将追加规则放在第一条无条件 `MATCH` 之前。无 `MATCH` 时放在末尾。新增规则集名称须与订阅中的名称不同，显式路径须位于运行目录内的子目录。规则页保留单订阅草稿和排序。全局覆写启用后，规则页可从页头进入覆写编辑器，合并结果可在订阅的运行 YAML 中查看。

也可以只在全局覆写中定义规则集，再到规则页新建 `RULE-SET,规则集名称,策略`，放在兜底规则之前。点击「应用修改」后，该自定义规则按订阅保存，订阅更新后重新合并。HTTP 规则集的下载也会受分流影响。若兜底规则会拦截下载地址，可给该规则集指定 `proxy: DIRECT` 或可用策略。此选项控制下载路径，匹配流量仍按引用规则的策略分流。

桌面可点击编辑区工具栏的外部打开图标，用系统为 `.yaml` 关联的默认应用打开当前草稿的临时副本。Linux 无法用关联应用打开时可回退到纯文本默认应用。副本位于系统临时目录的 `cor-override-*/merge.yaml`。外部编辑期间，客户端约每 1.5 秒同步一次已保存的修改。关闭外部编辑器后，再点同一图标可重新打开原副本。保存并退出外部编辑器后，回到客户端点「应用并关闭」。客户端会再读一次临时文件，经原配置事务保存，确认副本未变化后删除并退出覆写页面。校验或保存失败会保留草稿和临时副本；若应用期间另有外部保存，编辑会话会保持打开。Android 使用内置编辑器。

主动离开时，如有未应用的修改或正在外部编辑，客户端会打开弃稿确认弹窗。选择继续编辑会保留草稿，确认放弃会退出并清理编辑会话。校验及应用成功沿用普通状态栏提示。

```yaml
rule-providers:
  examples:
    type: inline
    behavior: domain
    payload: ['+.example.invalid']
prepend-rules:
  - RULE-SET,examples,DIRECT
append-rules:
  - DOMAIN,other.example.invalid,REJECT
```

## 查看订阅源码

在订阅详情选择「订阅源码」可查看原始 YAML 和运行 YAML。原始视图保留已保存订阅的注释和顺序。运行视图标明内容来自活动内核已应用的文件，还是按已保存设置生成的预览，并将与父级键对齐的列表向内缩进一个 Tab 的宽度（四个空格）。两种视图默认显示源码凭据；截图或分享前可点击眼睛图标，隐藏识别到的节点、订阅和 provider 凭据，再点可恢复。隐藏状态在本次应用会话内随两种视图共享，不改写文件。客户端生成的控制密钥始终遮盖。查看无须启动或重载内核，也不会下载规则集。

点击编辑区右上角的放大镜，或在桌面按 `Ctrl+F`（macOS 也可用 `⌘F`），即可展开浮动查找栏，编辑区大小保持不变。查找按字面区分大小写，显示当前位置与匹配总数，`Enter` / `Shift+Enter` 前往下一处 / 上一处，`Esc` 收起查找。覆写草稿输入时即查找。只读源码确认搜索词后才发起整份文档的后台查找，匹配可以跨段定位。

覆写编辑和源码查看都为可见范围内常见的 YAML 键和短注释着色，正在输入的行保留原生光标与输入法显示。源码视图按段浏览。选中文本后可点击复制图标，也可用 `Ctrl+C`（macOS 为 `⌘C`）。覆写编辑上限 128 KiB，按一次 `Tab` 插入四个空格，支持 `Ctrl+Z`（macOS 为 `⌘Z`）撤销。「校验」检查当前草稿，「应用」才会写入。关闭页面、切换页面、退到托盘或将 Android 应用转入后台会释放文本、编辑历史和查找状态。各项提示按[错误分级](error-feedback.md#业务系统与检测)呈现。CLI 与 TUI 沿用同一配置生成链。

## 自动更新

桌面 GUI、`cor` 后台与 Android 共用 `subscription_update_interval_minutes`，默认 360 分钟，范围 0–10080；0 关闭。桌面和 Android 设置页可修改，CLI 使用 `cor config set subscription_update_interval_minutes 360`。该间隔与节点定时测速独立。

桌面调度由当前数据目录的后台所有者执行，GUI 重开或 CLI 附加不会启动第二份任务。Android 调度属于 Activity 创建的移动会话：界面隐藏而会话仍在时可继续检查，Activity 销毁时取消会话并等待其运行时与写入任务退出，再允许新 Activity 打开同一配置。VPN 由独立服务维持，不随界面会话停止；重新打开界面后恢复定时检查，不提供无 Activity 时的独立订阅调度。

每 30 秒检查一次，只选择 HTTP(S) 来源且已超过间隔的订阅；本地 YAML 和默认直连跳过。Claude 保护及切换期间锁定网络修改，所有订阅的定时和手动更新暂停，恢复后重新等待间隔；外观和只读操作见[操作权限](claude-protection.md#操作权限)。桌面定时和手动下载共用门禁，忙时跳过本轮检查而不消耗重试间隔，停止内核或关闭后台会取消下载。Android 同一会话处理手动订阅操作前取消定时任务，并丢弃已排队的旧结果；界面退出路径即使遇到错误，也通过会话所有权回收后台任务。

下载沿用订阅现有代理/直连、慢速与断流回退。定时下载成功后先校验 YAML，再核对当前所有者已载入的订阅、来源、开关和保护状态，以及文件是否被编辑；任一变化即丢弃结果。成功才更新内容、用量和更新时间，刷新界面并清理旧测速与检测结果；保留未应用的规则草稿。失败记录原因及“保留原配置与运行状态”，格式错误另按上文通知；不改内容、设置、草稿或检测结果。下次重试从本次尝试开始计时，不会持续请求。跨 Activity 取消回归与真实设备验证分别记录于[Android 生命周期复盘](agent-failures/android.md)，实现接入不代表已经完成设备验收。

所有订阅内容在写入前完成 YAML 与规则结构校验，未选中的订阅也不能用错误规则覆盖有效缓存。配置事务恢复记录未清除时，移动会话拒绝设置、订阅和规则写盘并要求重启；启动时若 `profiles/` 已有 YAML 而 `settings.json`、`profiles.json` 缺失或索引为空，也拒绝创建新默认订阅，保留原文件供恢复。

权威实现见[共享调度](../crates/client-core/src/subscription/schedule.rs)、[桌面/CLI 后台](../crates/client-runtime/src/control/subscriptions.rs)与[Android 宿主](../apps/android/native/src/android.rs)。
