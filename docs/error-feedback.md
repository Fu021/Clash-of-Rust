# 通知与错误分级对照

[文档导航](README.md) · [界面行为](../crates/client-ui/README.md#通知与故障反馈) · [诊断字段](diagnostics.md)

按失败后的实际影响分级，由宿主明确传入，不能按错误文字、页面名称或是否开启 Claude 保护猜测。下表按源码入口覆盖错误类别；操作系统、网络库及第三方返回的具体原因原样保留在受限诊断中，不穷举其所有文案。

## 呈现与优先级

| 类型 | 条件 | 呈现及关闭 |
| --- | --- | --- |
| 状态栏 | 成功、进度、已完成的取消和操作说明 | 普通消息 5 秒后消失，可点击正文关闭；下载进度和更新候选是独立持续状态，不按 5 秒清除。 |
| 可恢复错误 | 本次操作失败，其他功能仍可继续 | 非模态错误框，保留原因、导出诊断、新建 Issue 和关闭；不自动消失。字段校验可留在表单内，保留输入及诊断入口。 |
| 严重错误 | 内核不可用、VPN 建立失败、恢复失败或无法安全退出 | 居中警告，保留具体原因、诊断和可用的重试入口；关闭只收起提示，不表示修复。 |
| Claude 保护状态 | 保护切换、已生效、接管/实时监控异常、只读限制 | 持续状态条及关闭保护入口，随实际状态刷新；真实恢复失败另显示严重错误。检测网页打不开不等于保护失效。 |

严重错误优先，普通成功不能覆盖任何未关闭的错误；后台可恢复失败不能顶替严重错误，但仍写入有界诊断事件。安装成功也不能清除另一个尚未处理的严重错误。诊断导出或打开 Issue 失败追加到原错误，不抹掉原始原因。两种错误都不能通过点击正文误关闭。

CLI 没有界面弹窗：失败返回非零退出码、具体原因与在线/离线诊断命令；JSON 保留错误。预期取消、只读状态查询及进度不能冒充操作成功。iOS 只有共享界面原型，没有可验收的原生 VPN 或安装功能。

## 更新与写盘

| 场景 | 正常等级 | 升级条件或边界 |
| --- | --- | --- |
| 更新检查连接、HTTP、解析、版本或附件校验失败 | 可恢复错误 | 保留已发现候选；设置页继续显示检查结果。过期任务不能重新弹错。 |
| 下载断流、超时、持续低速及代理/DIRECT 全部失败 | 可恢复错误 | 有界重连和路线回退仍失败后才报告；不擅自切节点或关闭接管。 |
| 安装包长度、SHA256、签名、架构或版本不符 | 可恢复错误 | 拒绝安装，不提供绕过校验的按钮。 |
| 临时目录、安装计划、助手复制或结果保存失败 | 可恢复错误 | 保留实际系统错误，不把临时目录错误统称为安装目录权限问题。 |
| 非受支持的安装来源、UAC/polkit 取消或拒绝 | 可恢复错误 | 说明未安装，不把“转交助手”作为成功；Linux 终端恢复另有结果记录。 |
| 助手意外退出、交接取消、交接/授权超时 | 可恢复错误 | 原客户端可用时允许重试；退出或恢复本身失败按严重错误处理。 |
| Windows 安装文件被占用、拒绝写入、只读或磁盘已满 | 可恢复错误 | 全量写入预检先于旧 EXE 备份；共享锁短时重试，持续失败在替换前拒绝。安装中失败仍记录实际阶段和目标，不能宣称整套资源已回滚。 |
| Windows 卸载器、网络助手或安装登记失败 | 可恢复错误 | 记录安装器退出码；现有主程序/界面回滚不等于全部资源事务回滚。 |
| 更新后重新打开客户端失败 | 可恢复错误 | 持久保存结果；若重新启动内核失败，启动入口再按严重错误提示。 |
| 用户取消下载且清理成功 | 状态栏 | 清理失败仍为可恢复错误，不能隐藏残留问题。 |
| Geo 下载、校验或重载失败，旧数据及内核已恢复 | 可恢复错误 | 文件恢复失败或内核无法重启时升级严重错误；中断事务保留取证。 |
| 设置、窗口、日志、报告或诊断写入失败 | 可恢复错误 | 保留原文件及原错误；初始化因此无法完成时属于严重错误。 |

桌面下载、安装资格、助手交接、轮询结果和更新后启动均进入同一个可恢复提示入口，不能仅写顶部更新栏。具体实现见 [notice.rs](../apps/desktop/src/application/notice.rs)、[更新任务](../apps/desktop/src/application/mod.rs)及[安装交接](../crates/client-runtime/src/update/install.rs)。

## 业务、系统与检测

| 场景 | 等级或呈现 | 来源与边界 |
| --- | --- | --- |
| 内核/共享后台初始化、启动、重试失败或意外退出 | 严重错误 | 桌面 `CoreReady` / `Finished`；Android 初始启动、原生状态观察及重启入口。 |
| 代理/TUN、端口、DNS、IPv6、UDP 修改失败且原状态可用 | 可恢复错误 | 共享业务拒绝或回滚结果；若内核实际停止则升级。 |
| 退出时系统代理/DNS恢复或所有者停止失败 | 严重错误 | 桌面 `ExitFinished`；不能强行退出并报告已恢复网络。 |
| Android VPN 无法建立 | 严重错误 | `TunnelService`；重建失败但旧连接与保护均保留时为可恢复错误。 |
| Android VPN 授权被系统撤回 | 可恢复错误＋实际 VPN 状态 | 不宣称仍接管；保护启用时同时保留未就绪状态。 |
| 托盘宿主、Dock 重开、通知授权/发送或设置入口不可用 | 可恢复错误或权限引导 | 内核仍运行，不能将桌面集成失败写成内核启动失败。 |
| 窗口进程退出、版本不匹配或界面重开失败 | 可恢复错误 | 保留后台；从托盘/Dock重开。若后台也失败，另显示严重错误。 |
| 订阅导入、编辑、更新、删除或应用规则失败 | 可恢复错误；校验可留表单 | 保留原配置与草稿；自动更新失败同样记录，不能只打日志。 |
| 规则/Fake-IP/应用规则的重复、非法值、过期草稿或并发冲突 | 可恢复错误；校验可留表单 | 不污染持久配置，不因校验失败丢弃用户输入。 |
| 应用指定出口失效、默认 REJECT 或目标不支持 UDP | 可恢复警告＋规则状态 | 只影响匹配连接，不能报所有节点失效；仍按规则拦截，不自动放行。 |
| 节点测速的控制连接、认证、响应或探针失败 | 可恢复错误 | 与真实节点不可达分开；全失联复核通过后提示及提供可选恢复，不自动停 TUN。 |
| 网络诊断连接/HTTP/DNS查询失败 | 可恢复错误＋该项结果 | 不把一次失败当作整机断网。 |
| 首页服务状态、IP检测的不可达/受限/部分可用/未确认 | 对应结果卡片 | 批量探测不逐项弹窗；403、验证拦截和缺证据不能冒充程序故障。日志页可导出诊断。 |
| Claude 检测会话、浏览器打开、采样导入或报告导出失败 | 可恢复错误＋检测页状态 | 保留已有报告；与保护接管状态分开。 |
| 文件选择、外链、报告/诊断导出失败 | 可恢复错误 | 原错误追加跟进；正常关闭系统选择器不制造故障。 |
| 连接关闭、日志清空/导出、系统集成查询失败 | 可恢复错误 | 保留实际失败，不用“已完成”覆盖。 |
| 刷新/观察暂时失败、无数据或权限不足 | 未知状态及诊断；交互请求失败可恢复 | 未知不等于内核退出；不依据一个缺失采样制造严重错误。 |
| 外部 TUN 或确认流量绕过当前接管 | 持续网络警告 | 归属/权限未确认不单独报警，不关闭其他用户的 TUN。 |

桌面通用命令结果见 [commands.rs](../apps/desktop/src/application/commands.rs)；表单、文件及诊断见 [interaction.rs](../apps/desktop/src/application/interaction.rs)；检测结果见 [claude.rs](../apps/desktop/src/application/claude.rs)。Android 的 [Rust 事件循环](../apps/android/native/src/android.rs)、[VPN 服务](../apps/android/app/src/main/java/org/clashofrust/android/TunnelService.java)与[系统通知](../apps/android/app/src/main/java/org/clashofrust/android/IncidentNotifications.java)分别决定宿主、VPN和系统提醒等级。

## Claude 保护的特殊边界

| 场景 | 归类 |
| --- | --- |
| 开启/关闭中，尚在等待授权、DNS或接管验证 | 持续“检查中”状态；旧采样不能短暂报绕行。 |
| 已启用且确认正常 | 主题自适应的持续只读状态条；不是可关闭的错误。 |
| 保存的保护开启，但 VPN/TUN、DNS或实时监控未就绪 | 保护健康警告及诊断；真正内核启动失败另按严重错误处理。 |
| Android 保护状态样本无法解析或暂时不可读取 | 显示检查中/未知并保留原因，不冒充内核退出或网络恢复失败；待执行的保护切换仍按原超时执行回滚。 |
| 开启失败但原网络状态已恢复 | 可恢复错误，保留具体原因。 |
| 开启、关闭或回滚后无法恢复网络/保护 | 严重错误，不用普通成功通知遮盖。 |
| 拦截到保护名单中的异常出口 | 保护详情和原生提醒；保存观察、拦截及失败计数，不重复模态弹窗。 |
| 保护期间尝试修改网络、订阅、规则、应用出口、更新或调度 | 拒绝操作，保留只读原因/状态；不是内核故障。 |
| 改主题、强调色、字号、排序、导航或只读导出 | 允许；自身操作失败按可恢复错误，不因为开启保护就升级。 |

[操作权限](claude-protection.md#操作权限)及[健康状态](../crates/client-core/src/protection/status.rs)是判定依据。保护页面的风险/未知检测结果仍是报告，不能仅因出现“风险”文字就弹严重错误。

## 源码入口核对

以下是类别的权威入口；底层返回的具体异常沿调用链进入对应结果，不按文字匹配等级。

| 入口 | 检查的反馈路径 |
| --- | --- |
| 桌面 `application/mod.rs` | `CoreReady`、`Finished`、`ExitFinished` 为初始化、命令和退出的分界；更新检查、下载、交接及安装结果进入可恢复入口，Geo 失败后再刷新实际内核状态。 |
| 桌面 `application/commands.rs` | 设置、网络、订阅、规则、连接及日志共享结果；根据实际内核是否停止升级，不能把任意命令失败都当作内核不可用。 |
| 桌面 `application/interaction.rs`、`rules.rs` | 文件选择、订阅和规则表单、诊断导出与打开反馈页；取消不造错，字段错误保留草稿，诊断追加不替换原错误。 |
| 桌面 `application/claude.rs` | 会话、网络检测、浏览器、剪贴板、报告导入/导出失败进入可恢复入口；风险、未知及不完整扫描仍留在报告中。 |
| 桌面 `application/bindings.rs`、`bootstrap.rs`、`startup.rs` | 窗口初始化/重开、进程协议、托盘尝试和后台启动；没有可用窗口时保留启动日志与 CLI 离线诊断。 |
| 桌面 `application/network_watch.rs`、`overview.rs`、`connection_lookup.rs` | 接管警告持续显示；服务探测、IP/地址信息失败留在结果或未知状态中，不产生逐项错误弹窗。 |
| Android `native/src/android.rs` | 用户操作、异步更新/Geo/测速、原生回调、保护切换与内核运行状态；可恢复和严重等级同步到原生系统通知及最近事件。 |
| Android `native/src/application_routing.rs`、`application_policies.rs` | 应用目录、选择、规则草稿及目标失效；权限/目录加载失败可恢复，目标失效保留规则拦截和可恢复提醒。 |
| Android `MainActivity`、`UpdateInstaller`、`TunnelService` | 文件、外链、APK 安装授权/身份校验与 VPN 建立/恢复；Android 系统安装界面的结果不冒充本程序已确认安装成功。 |
| Android `IncidentNotifications`、`ProtectionRuntime` | 系统通知不可用不抹掉界面错误；保护异常保留专用健康状态、观察与拦截记录。 |
| `client-runtime/update/install.rs`、平台安装模块、NSIS | 安装资格、授权、交接、目标写入及重启；安装器退出码和有效的文件失败记录共同解释结果，缺失信息保持未知。 |
| CLI `main.rs`、`diagnostics.rs`、`commands` | 统一失败出口、非零退出码、在线/离线诊断命令；安装有最终结果记录，移交助手不等于安装成功。 |

这些入口还覆盖不能显示弹窗的阶段（窗口尚未创建、Android Activity 不在前台、CLI 无显示环境）。不能以界面有错误框推断所有原生启动失败都能立即展示；用启动记录、Android 日志与系统通知、CLI 离线报告保留替代取证入口。

## 诊断与验证

桌面与 Android 最近 20 条错误事件携带 `level=recoverable/critical`、时间及脱敏原因；关闭提示后仍保留。保护健康、网络警告、逐项探测及表单校验分别在状态、检测结果和当前上下文中取证，不强行伪装成普通错误事件。

Windows 安装失败追加[安装阶段记录](diagnostics.md#windows-更新安装)，在临时目录清理前持久保存。旧版本或旧安装器缺失字段时保持未知，不能反推其故障原因。

回归入口覆盖更新检查/下载/交接/重启结果的可恢复提示、严重错误优先及诊断追加、Claude 检测报告保留、显式事件等级，以及 Windows 真实文件占用、只读文件、全量文件未被预检修改和解锁后重试。执行结果见[最近复盘](agent-failures/reviews.md)。脚本静态检查不能代替 Windows 原生执行、人工 UAC、真实设备和第三方杀毒软件现场。
