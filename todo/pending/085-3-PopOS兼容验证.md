# Pop!_OS 兼容验证

## 需求与顺序

Linux 系列第三项，候选为 22.04 GNOME、24.04 COSMIC 的 x64。首批不扩展 ARM 专用镜像；已有 COSMIC 启动诊断仍保留独立职责，不替代完整发行兼容门禁。

共同验收、授权边界、System76 官方来源和未核实的维护终点见 [Linux 扩展索引](../pending/085-Linux发行版与安装格式扩展.md)。

## 验收

- [ ] 接手时核对官方镜像、校验来源、桌面及支持期限，不直接把 Ubuntu 的生命周期当成 System76 承诺。
- [ ] 分别核对 GNOME/COSMIC 的普通用户启动、渲染、托盘、桌面入口、用户服务、授权代理及系统代理；明确适用的正常桌面差异。
- [ ] 复用既有 DEB 验证入口，提交必要的矩阵/镜像变更供审核；不复制一份 COSMIC 诊断入口。
- [ ] 两个版本真实 VM 完成索引规定的全套安装、更新、三端运行、TUN/DNS、拒绝恢复和持久化，并记录来源 CI、镜像与回执。
- [ ] 完成多轮复核，区分平台差异、限制及遗漏；未验证的桌面能力不写入公开支持承诺。
