# openSUSE RPM 兼容验证

## 需求与顺序

Linux 系列第六项，依赖 Fedora 项已经验收的 RPM 基础。候选为 Leap 16.0/16.1 的传统可写安装与 Tumbleweed，首批 x64。

共同合同、官方来源及当前维护期限的核实边界见 [Linux 扩展索引](../pending/085-Linux发行版与安装格式扩展.md)。Immutable Mode 与 ARM64 不在首批，不能因同为 RPM 自动声明支持。

## 验收

- [ ] 接手时核对实际发行版本、传统安装镜像、官方签名/摘要及维护期限；Tumbleweed 记录快照日期与完整镜像身份。
- [ ] 复核 SUSE 与 Fedora 的依赖名、包脚本、polkit、权限、用户服务、包管理器与桌面差异，尽量复用单一 RPM 规范。
- [ ] 核对 zypper/RPM 的安装升级、占用和错误恢复；应用内更新沿用已验证的来源/格式合同，不绕开包所有权。
- [ ] 必要矩阵变更完成审核，复用 RPM Compatibility，不为相近发行版重复构建二进制。
- [ ] 三个候选目标分别在真实 VM 完成索引要求的全套验收及同提交回执，复查 GUI/TUI/CLI、DNS/权限恢复与持久化。
- [ ] 明确只验证传统可写安装的边界，循环审查结束后再更新支持声明。
