# Linux Mint 兼容验证

## 需求与顺序

Linux 系列第二项，候选为 Mint 21.3/22.3 的 Cinnamon x64，复用 Debian 项沉淀的 DEB 验证入口。MATE、Xfce 与 ARM64 不根据相邻平台结果声明已验。

共同验收、授权边界及已核对的生命周期来源见 [Linux 扩展索引](../pending/085-Linux发行版与安装格式扩展.md)；一次只推进一个 Linux 子项目。

## 验收

- [ ] 接手时重新确认官网最低版/主流版、支持期限、Cinnamon 镜像和摘要；若候选过期，记录调整依据。
- [ ] 复核 DEB 依赖、Cinnamon 托盘、桌面入口、自启动、polkit、系统代理及普通用户启动，差异留在合适的平台/安装层。
- [ ] 准备复用既有入口的最小兼容矩阵变更并完成所需审核，不为 Mint 重复编译 Rust 或另开常驻工作流。
- [ ] 两个版本的真实 VM 均完成索引规定的安装、升级、卸载、GUI/TUI/CLI、TUN/DNS、拒绝与恢复、持久化及同提交回执。
- [ ] 复查三端差异、共享后台及纯 CLI 内存边界，完成循环审查后才声明具体已验证的桌面范围。

2026-11-17 拆分排队，尚未实施。等待 Debian 项完成或明确外部阻塞后接手；不把 Ubuntu 或 Debian 的证据当作 Mint 的真实桌面证据。
