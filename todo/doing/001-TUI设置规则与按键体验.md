## 需求与验收

- [x] 导航按首页、节点、订阅、连接、规则、工具、设置、操作排列；数字键、Tab 和帮助统一，工具用左右键切换。
- [x] 设置的标题、分类和名称对齐 GUI；不加入终端无用的 GUI 外观选项。单值选择用左右键，Enter 确认当前值，不再循环；多字段工具保留下一项与整表执行。
- [x] Fake-IP 独立管理已有项、来源和停用状态，支持新增、停用和恢复默认；保留用户项与订阅过滤，共用校验、保护和原子保存。
- [x] 完整规则页显示来源，支持按来源允许的新增、编辑、启停、调序和删除；快捷规则独立入口，复用订阅包含时的去重及后台事务，并拒绝过期修订。
- [x] 首页可操作启停、代理方式、运行模式、当前订阅和保护；更新检查及安装入口展示真实状态，固定所选候选版本，沿用 CLI 确认、SHA256、系统授权和失败恢复。
- [x] 紧凑导航用 ASCII `[]`，小屏保留独立页标题；按显示宽度选择导航、换行帮助，缩放后保留选中项。
- [ ] 最新列表换行补丁：节点、连接、订阅、快捷规则和操作说明尽量完整换行，按实际显示行保持选中项可见；验证 40×24、60×24 和桌面各页及子页。
- [ ] 最新提交的 Rust 回归、真实 PTY 与实际帧读回；失败时恢复本项修复，不用历史成功替代。
- [ ] 最终三端差异和退出释放复查；没有同提交实测时不得宣称合计内存完全回落或纯 CLI 零增长。
