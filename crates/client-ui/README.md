# Slint 界面

按维护者提供的交互 HTML 重构桌面、手机及平板界面，页面与各类确认、编辑、详情弹窗共用正式 Slint 组件。支持深色、浅色、跟随系统、字号缩放及六种强调色；外观设置自动保存。[界面设计与审阅](../../docs/ui-design.md)集中说明几何线条字标、整体布局、页面结构和本轮验证边界。

- `ui/state.slint`：界面数据与操作协议，不包含网络、文件或授权逻辑。
- `src/models.rs`：复用列表模型，按变更更新行；桌面投影按页构建，隐藏后释放列表。
- `apps/desktop/src/application`：应用状态与校验、可取消任务、桌面绑定；原生事件只由 `bindings.rs` 接触 Slint/winit。
- `ui/pages`、`ui/components`、`ui/dialogs`：正式程序与 Slint Viewer 预览使用同一套组件。

默认窗口 **950×700**，最小 **800×450**；44px 品牌栏、216px 侧栏和圆角主画布。正文与按钮 15px，辅助信息 13px，常规控件至少 36px，紧凑辅助操作随字号增高，页头至少 52px。间距集中在 `Theme`：卡片内边距 16px、卡片间距 12px、内容间距 8px、设置分组间距 20px，弹窗内边距 24px、分区间距 16px。超出窗口的内容滚动显示。

订阅采用顶部链接导入器与自适应卡片，名称、来源和用量文字直接展示，低频删除进入详情。桌面按卡片参考宽度、内容区和字号计算列数：订阅 288px、节点 196px，宽窗口增加列数，大字号减少列数，奇数尾项保留空槽。布局只重排现有分页模型，不重新获取网络数据；详情按订阅 ID 或组名/节点名保留。完整名称与协议可在详情查看，使用、更新和测速直接可达；订阅搜索、分页和保护门禁保留。没有结构化流量/到期元数据时不虚构进度条或状态。

桌面与 Android 首页增加网络信息、服务状态及地址隐私开关，手机纵向滚动并按可用宽度压缩网络/服务卡片，平板把网络信息放在运行状态/流量列；iOS 只同步界面原型。探测范围、取消/防抖与融合回归边界见[PR #36 的融合与兼容](../../docs/ui-design.md#pr-36-的融合与兼容)。模式选择条按布局分配等宽按钮，真实点击回归核对命中范围和派发操作；设置页保留垂直分组定位与未保存输入。

设置页“网络”提供 DNS 覆盖、Fake-IP 开关和独立排除项页面。列表合并同名域名并标注自定义/DNS 覆盖来源；删除内置项后显示移除数量及“一键还原 DNS 覆盖项”，还原保留自定义项。关闭 DNS 覆盖时关闭 Fake-IP，但保留列表和移除记录，订阅原有过滤仍生效。额度、持久化和 CLI 格式统一见[配置说明](../../docs/cli/maintenance.md#配置诊断与检测)。

滚动容器按分页、筛选或详情身份变化回到顶部；同一内容的后台刷新保留阅读位置，内容缩短时限制偏移，避免空白正文。桌面使用 `PageScroll`，移动端使用 `MScroll` / `ListView`，不要用变化中的条目总数或检测进度作为内容身份。移动虚拟列表的封装必须保留 `ListView` 名称，Slint 1.18 按重复项直接父组件的名称启用行布局与虚拟化；改名会使多条记录重叠。

桌面规则页通过左侧手柄直接拖动排序，移动端长按后拖动。拖动时整条规则浮起并跟随鼠标或手指，保留按下位置，原位淡化并高亮目标；靠近列表上下边缘时连续滚动，源规则滚出屏幕仍可继续，松手才提交排序。支持键盘上下键和 Esc 取消。移动结果按规则 ID 定位到完整草稿，搜索或来源筛选不会把可见行号误当作实际位置。右箭头打开完整规则、来源、策略、启停状态及编辑、删除、跨页移动等操作，修改仍需应用。规则页顶部操作随列表滚动，移动连接与日志页的搜索和筛选同样随内容滚动；工具栏不随列表数据或键盘可用高度变化而重建，以保留输入焦点；键盘展开时规则和连接尾栏随内容滚动，给搜索结果留出空间。

正式应用使用 winit 与软件渲染器。系统代理、TUN、托盘、Dock、更新与文件选择由桌面平台负责；共享业务不依赖 Slint，Android 使用原生宿主，iOS 保留占位。

节点名称、策略组名称和当前策略在列表、首页、详情和操作中均保持订阅原文，包括前后空格、国家代码、旗帜及普通 emoji；不删除前缀、不推断地区，也不自动补旗帜。桌面和 Android 使用随包的 [Noto Color Emoji](../../resources/fonts/SOURCE.md#noto-color-emoji) 及共享字体回退注册。桌面保留软件渲染器，局部回移 Slint 已合入的[彩色字形修复](../../vendor/slint-renderer-software/PATCHES.md)，Android 保留现有 Skia 路径。IP 检测与 Claude 保护/检测同样使用 emoji 国旗，摘要、结果、递归 DNS 和详情均传递文本，不再维护独立国旗图片或图片缓存。港澳台在报告中仍映射中国国旗并保留地区文字；这套报告映射不参与节点或策略组名称显示。

输入框在已提交文字和输入法组词文字均为空时才显示占位提示；组词尚未提交时也须隐藏提示，桌面与移动端共用这个条件。移动行标题可换行，右侧值限制宽度，完整内容仍在详情中展示。手机页头省去重复节点/订阅说明，字号至少 125% 时将必要运行状态另起一行，避免挤压页名与返回入口。

桌面窗口进程在原生窗口建立后才报告就绪，统一处理显示、取消最小化、位置校正与激活；移动或主题变化不重复触发尺寸调整。Windows 的 `apps/desktop-ui/tests/window_reopen.rs` 使用真实界面进程检查关闭重开、屏幕外位置恢复、最小化/隐藏恢复与窗口消息响应，不启动内核或修改网络。

## 无需 Rust 编译的外观预览

语法检查使用与应用依赖一致的官方 **Slint Viewer 1.18.1**（`slint-viewer`）。截图和交互预览使用含彩色字形支持的官方主线 **Viewer 1.19.0**（`slint-viewer-main`），安装到用户持久目录并校验官方下载摘要。脚本优先选择后者渲染；可通过 `--viewer PATH` 和 `--check-viewer PATH` 分别指定，不把个人路径写入仓库配置。

```sh
python3 scripts/preview-slint.py --check
python3 scripts/preview-slint.py --dialogs --pairs
python3 scripts/preview-slint.py --page settings --theme both --full-settings
python3 scripts/preview-slint.py --page connections --size 800x450
python3 scripts/preview-slint.py --mobile --platform android --page rules --theme light --size 360x800 --scroll-y -360 --output /tmp/clash-rules-preview
```

输出默认在 `dist/slint-preview/`。`ui/preview.slint` 只向正式组件填入固定演示值，不接入真实操作；此工具用于外观检查。它无需 Cargo、Xvfb 或桌面会话。

截图工具拒绝使用缺少彩色字形支持的旧 Viewer。仅导入字体仍可能让系统回退先选中不支持组合 emoji 的字体；脚本通过 `SLINT_DEFAULT_FONT` 与 `SLINT_FONT_PATH` 明确设置随包正文和 emoji 回退，保持节点及策略组原文。每份截图目录的 `preview-viewer.json` 记录工具版本与字体身份。预览使用主线 Viewer 的无窗口渲染，应用仍使用已提交依赖及软件渲染器回移；二者并非同一构建。正式软件渲染的颜色、输入框、透明度、裁切和重绘由 `tests/emoji.rs` 在 Actions 验证，预览不替代设备验收。

资源受限（例如 1 核 CPU、约 1 GiB 内存）时优先运行 `--check`，或按[多尺寸检查](../../docs/loop-workflow.md#多尺寸-ui-检查)串行预览必要页面；维护者明确要求全量浅深主题时也须串行。`--pages-only` 可跳过额外移动情境矩阵，`--scroll-y` 检查移动首页与规则页滚动后的内容。使用 `--output /tmp/...` 等工作区外目录保存审阅产物，按维护者要求保留或清理，不在仓库留下 `dist/`、缓存或截图：

```sh
python3 scripts/preview-slint.py --check
python3 scripts/preview-slint.py --page settings --theme light --output /tmp/clash-slint-preview
```

## Android / iOS 界面

移动端沿用当前桌面的配色、图标、卡片与操作层次，正文 16px、辅助信息 13px、触控区至少 48px。Android 与 iOS 分别维护页面组合、导航入口、设置与系统操作协议，未来可独立增减功能：

移动订阅使用链接导入器与单列卡片，名称、来源和用量文字可直接查看，低频操作进入详情。节点常规内容宽度至少 340px 且字号不超过 125% 时固定双列，过窄或更大字号用单列，不套用桌面的动态列数算法。名称、协议和独立详情/延迟操作分行，完整名称保留在详情；触控按钮至少 48px，字号遵循系统无障碍设置。

| 目录 | 职责 |
| --- | --- |
| `ui/mobile/shared` | `state.slint` 定义协议与草稿；`controls.slint` / `frame.slint` 管理触控、导航、安全区与键盘；`pages.slint`、`details.slint`、`settings.slint` 为共用业务界面。 |
| `ui/mobile/android` / `ui/mobile/ios` | 各自的 `app.slint`、`settings.slint`、`state.slint` 组合平台页面、设置及原生操作协议。 |
| 各平台 `preview.slint`、`shared/fixtures.slint` 和 `preview-data` | 固定演示数据、状态栏、键盘示意及预览资源；正式窗口不导入。 |

`MobileData` 不依赖桌面 `UiData`，只复用不含平台行为的列表行类型；界面请求交由各平台宿主执行，VPN 会话与内核进程状态分别传入。移动端不显示桌面安装器、托盘或窗口尺寸。两端都保留订阅、节点、连接、规则、日志、网络诊断、IP 检测和 A÷检测。

### 通知与故障反馈

桌面点击左上角应用图标发送测试系统通知，也可聚焦图标后按 Enter 或空格；发送期间及模态弹窗内禁用，通知权限和失败反馈沿用宿主处理，不额外占用右上角按钮。

通知由宿主显式分级，不按错误文字推断：

| 等级 | 例子 | 呈现 |
| --- | --- | --- |
| 成功或信息 | 已保存、检测完成 | 底部轻量浮层，8 秒后自动关闭，也可点击正文关闭 |
| 可恢复失败 | Geo 更新、检查更新、测速、订阅更新失败且原状态保留 | 底部详细错误浮层，使用“关闭”，不阻止其他页面操作 |
| 严重故障 | 内核初始化/启动失败、意外停止、VPN 无法启动、保护恢复失败 | 屏幕中央警告弹窗，使用“关闭”、Escape 或 Android 返回关闭，暂时阻止背景操作；普通后台结果不能覆盖 |

分级依据是失败后的实际影响：旧数据和运行状态保留时不打断用户；内核不可用、意外退出或保护恢复失败才升级为严重故障。相同的 Geo/订阅操作若在初始化时导致内核无法启动，仍按严重故障处理。用户主动取消且已恢复原状态时不升级为严重故障。表单校验留在表单内，保留输入并提供诊断入口；外部 TUN 接管及保护健康异常使用持续状态警告，观察到恢复后更新，不因每次采样反复弹窗。

两类错误都直接展示详情、保留到主动关闭，成功提示不能覆盖未关闭的错误。操作区集中“导出诊断”“新建 Issue”和“关闭”，不再重复提供复制诊断/命令；点击错误正文或空白不关闭，方便阅读与滚动。桌面与 Android 严重故障有可用恢复入口时增加“重启内核”；Android 仅在内核未运行且不处于保护切换时显示，沿用既有重启入口，提交后等待结果，成功才收起原严重错误并提示“内核已启动”，失败继续显示具体错误。失联警告可提供“停止接管”，仅停止当前实例管理的 TUN、Android VPN 或系统代理，属于可选操作，不能作为更新前提、自动执行或把关闭警告当成网络恢复。恢复动作沿用轻量按钮；手机按可用宽度和字号决定分列或纵向排列，触控区域不缩小。过长正文独立滚动，操作保持可见，页面布局不移动。关闭报错保留原页面与表单草稿；Android 的 Back 先由 Slint 消费并设置一次性标记，随后到达的原生 Back 回调只抵消该标记，不再关闭下面的编辑页；输入法可见或订阅字段有焦点时只让系统收起键盘，不触发页面返回或草稿确认。诊断采集、导出或浏览器失败追加具体结果并保留原始故障，不能误报故障已恢复。日志页保留常驻诊断入口。

一次测速全部失败时，后台重新核对全部真实叶子节点，分别使用两个独立目标复测；确认全失联后仅提示，不自动解除系统代理、TUN 或 Android VPN。这些状态下的更新均先代理、失败后独立 DIRECT，不要求关闭接管或切换配置；其他应用仍可能无法联网，用户可更换节点或主动停止接管。启用 Claude 保护时客户端进入只读状态，更新、下载及设置修改暂停；保护状态条持续显示并提供“关闭保护”，但不作为普通可关闭通知。复测最多 120 秒，失败、超时、空节点、配置或内核变化、用户切换及 Claude 保护边界见[联网恢复](../../docs/agent-failures/network-recovery.md#全部节点不可达时的更新与警告)。

全端共用暖色中性画布、低对比边框与柔和卡片阴影；强调色按保存索引选择，默认索引 0 的视觉改为参考稿陶土色。桌面和平板侧栏与内容区使用底色区分，移除竖向分割线及内容区外框；页面、列表、侧栏和下拉选项隐藏可见滚动条，保留滚轮与触摸滚动。桌面内容区底部只保留 8px 边距，滚动内容更接近窗口底边。桌面宽度低于 880px 时将侧栏收为图标导航，每个入口保留无障碍名称；代理与订阅卡片按内容宽度增加列数，手机订阅保持单列。

点击“新建 Issue”才在后台采集脱敏现场，并打开 GitHub 填写页：自动预填版本、系统、架构、采集时间、运行状态及有界错误摘要，编码后的地址最多 6500 字节；用户检查内容后提交。摘要排除完整日志、数据目录、路由与凭据，不把预填称为附件上传。桌面同时保存完整 JSON；Android 通过导出取得完整报告。未配置自动上传服务，也不保存用户 GitHub 令牌；完整附件仍需在 GitHub 页面附加。采集、保存或浏览器打开失败保留具体错误和原严重故障。报告范围、脱敏与失败处理以[故障反馈](../../docs/cli/runtime.md#故障反馈与诊断报告)为准。

用 `preview-slint.py --notice "Geo 更新失败：连接超时，旧数据仍可用" --notice-error` 预览错误栏，改用 `--notice-critical` 预览居中弹窗；预览不能代替原生保存、浏览器或 Issue 提交交互验证。

Android 已接入 `apps/android/native`、`apps/android/app` 与 `crates/mobile-ffi`：正式窗口不导入 fixtures，业务操作进入共享会话，VPN、文件与通知进入 Android 宿主，详见 [Android 说明](../../apps/android/README.md)。iOS 保持独立界面原型和宿主占位。两端预览仍使用固定数据，只用于检查外观与导航，不能代替实际设备上的操作验证。

```sh
python3 scripts/preview-slint.py --mobile --check
python3 scripts/preview-slint.py --mobile --platform both --theme both --pairs
python3 scripts/preview-slint.py --mobile --platform android --page proxies --size 834x1194
python3 scripts/preview-slint.py --mobile --platform ios --page settings --size 1194x834
```

资源充足时输出分别位于 `dist/mobile-preview/android/` 与 `dist/mobile-preview/ios/`；资源受限时使用 `--output /tmp/...` 并清理。全量预览涵盖全部页面、深浅色、手机横屏、Pad 双方向和分屏、小屏、125% 字号、未连接、通知进度及详情/编辑/确认场景。宽度均为逻辑尺寸，布局按扣除安全区后的可用宽高决定：

- 宽度不足 640 且非短窗口：底部五个入口，详情进入独立页面；工具页收纳连接、规则、日志和检测入口。
- 中等宽度或高度不足 480：紧凑侧栏，减少横屏头部占用；节点按内容空间改为双列。
- 可用宽度至少 1024、非短窗口：完整侧栏；内容宽度达到 880 时支持列表与详情并排，设置分两列。

手机底栏与紧凑侧栏保留首页、代理、订阅、工具和设置五个入口，连接、规则、日志及检测从“工具”进入。Android 与 iOS 的完整平板侧栏直接列出这些页面并将设置放在底部，几何字标和圆形连接入口置于侧栏上方；桌面保持独立页面与工具分组。

节点、连接和规则共用分页控件；宽内容区域使用固定触控宽度的翻页箭头和页码，规则保存操作合并到同一行右侧，避免按钮横向铺满 Pad。手机规则页将紧凑分页居中单列，下一行的放弃与应用按钮等宽展开，并与底栏留出间距；大字号同样换行，所有翻页按钮仍至少 48px。列表从顶部排列，少量记录不会垂直居中。

Android 规则页按来源筛选，长按 550ms 后拖动左侧手柄排序，靠近上下边缘会自动滚动，移回中间或松手后停止；普通滑动继续滚动列表，键盘上下键也可排序。桌面与移动端在筛选、分页或列表布局变化时取消拖动，详情均可复制完整规则原文。右箭头进入独立详情与操作页，展示原文（含 `no-resolve` 等参数），保留编辑/复制为自定义、启停、删除、跨页定位与恢复订阅顺序，所有操作先进入草稿。表单与桌面共用规则类型及重复启用规则、位置范围、数量上限校验；失败保留原草稿，逻辑规则继续使用完整文本。网络诊断的响应说明及 DNS 结果可换行显示。Fake-IP 排除项入口紧接 Fake-IP 开关，排除项、IP 结果详情/筛选和 A÷选项使用独立页面，减少主页面按钮。可用 `--mobile --platform android --page rules --detail 2 --theme light --output /tmp/...` 只预览一个表单；详情编号以 `shared/state.slint` 为准，避免运行全量矩阵。

Android 正式窗口已接入系统安全区、键盘、权限、前台 VPN、更新与文件导入；iOS 宿主保留独立占位。平板侧栏与内容区背景绘制到窗口边缘，覆盖底部及侧边系统操作栏区域；按钮、文字和编辑视口仍按安全区布局。不能重复扣除系统已经缩小的视口，状态栏只是预览示意。导航与草稿状态独立于布局，删除、离开未保存的编辑须确认。
