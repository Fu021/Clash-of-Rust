Open and exit

Cannot find cor? Check the installation location and command path first.

cor
cor ui --demo

Windows, Linux and macOS installers include cor. Use a real interactive terminal. Demo mode uses fictional data, without network access or saving.

The layout adapts to terminal size. Very small windows prioritize the focused item or confirmation prompt. You can scroll through long connection details.

Opening and browsing the interface leave the backend and core in their current state. To start them, choose Start backend and core on Home or run start from Commands. q / Ctrl+C exits while the existing backend and proxy remain running. Emoji rendering depends on your terminal font.

7 · Settings
Inspect values, edit supported fields, review and submit.
8 · Commands
Forms generated from the command catalog cover profiles, rules, updates, services and more.

Only the current page's data is read, sampled once a second. Drawing updates changed lines, without accumulating connection or command-output history.

Node selection

Press 2, find and open a manual policy group, choose a member and confirm again. Spaces, emoji and punctuation are preserved. Automatic groups show the core's choice and cannot be manually assigned a member.

Profiles, membership and protection are rechecked before submission. Choosing AUTO in a parent manual group does not become invalid just because AUTO changes its internal node.

Press s to cycle through name, ascending latency and descending latency. The page shows the mode actually saved by the backend and keeps the selected node during refresh and filtering.

Connection details

Press 4 to open Connections, then Enter on a connection for domains, destination IP/port, protocol, time, rule, actual path and traffic. d adds resolution details; x opens a close-connection confirmation.

If the connection disappears, the original ID is reported as unavailable; another connection is never substituted. The source application may reconnect after closure.

Details include original and sniffed domains plus process information; no sniffed result is guessed, and fields the core did not provide are hidden. Lists prefer sniffed domains, and search covers both domains, IPs, rules and proxy chains. Use ↑ / ↓ to scroll wrapped details.

Network tools

Press 6 and choose a tool with ← / →. Press / to enter a target. Press Enter to finish editing, then Enter again to run the check. Scroll with ↑ / ↓ and cancel with Esc.

{{terminal:network}}

All twelve checks require a target. Use Website check to see the rule and exit. The Connections and Proxies pages show individual traffic and node details. See the tool guide. Press o to edit applicable options. Choose types and methods with the arrow keys, apply your choices and press Enter to run. Switching tools restores default options. Results wrap to the terminal width and scroll one display line at a time. Press e and enter a file path to export the current JSON report. If writing fails, the path is kept for retry. Changing pages cancels the check and clears its results.

Settings forms

Press 7 to inspect settings. Drafts are submitted only after confirmation. Cancelling a field restores its previous value; leaving the form discards drafts. The backend still validates ranges, permission and current state.

Ports, DNS/Fake-IP, IPv6, UDP, update channels and intervals, and run mode have switches, choices or editors. Use Enter, Space or arrow keys to choose, then move down to Save settings and confirm. Ordinary settings save inside TUI and read back the result; failures keep drafts. Proxy and protection authorization still uses the normal terminal. GUI accent, font and tray preferences stay outside common terminal settings; advanced commands remain available.

Press 3 to choose and save the current profile, or 5 to view rules and open shortcut rule management. Shortcuts already included by the profile cannot be added again. Profile source editing and complex rule operations remain available through Commands.

Commands and authorization

Press 8 and search for an action such as profile add, rule add, update install or service status. Fill positional arguments and options separately, without shell quotes. Arrays use JSON; boolean options accept true or an empty field.

Confirmation temporarily restores the normal terminal for output, download progress and authorization. It skips neither confirmation nor system permission. Press Enter to return; software installation exits TUI after completion or handoff to release files that need replacement.

Ctrl+C during authorization or a continuous command exits the whole CLI; already submitted work may continue. Foreground run and another ui session remain direct CLI entries.

Protection and read-only access

Claude protection allows navigation, status, reports and appearance edits. Network mutations—including profiles, nodes, rules, updates, Geo and autostart—remain locked. Forms do not bypass backend permission checks.

After a read failure, old snapshots are marked as reference data and cannot be submitted. Browsing or testing cannot implicitly start a stopped core during protection.

Recovery

Press r to retry. A larger window can show more content. If recovery fails, exit and export diagnostics using the original account and data directory.

TUI does not require fixed colors or screen coordinates. Automation should prefer CLI JSON and exit codes. See the full terminal reference ↗.
