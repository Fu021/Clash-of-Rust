Windows

x64 and ARM64

    Run the installer and follow the prompts. Upgrading over an older version keeps your subscriptions and settings.

    The installer adds cor to PATH by default. Reopen your terminal to run it.

    For a Defender alert, check SHA256, then follow the alert notes.

    Linux

    DEB, RPM and native Arch packages

      Run the command for your distribution from your downloads folder. Replace the example filename with the file you downloaded.

      • On Debian, Ubuntu 20.04 or later, and compatible distributions, run sudo apt install ./package.deb
      • On Fedora, run sudo dnf install ./package.rpm
      • On openSUSE, run sudo zypper install ./package.rpm
      • On Arch Linux x86_64, run sudo pacman -U ./package.pkg.tar.zst

      Use uname -m to check your architecture. x86_64 means x64 or amd64, and aarch64 means ARM64. Run cor after installation.

      macOS

      macOS 14 or later

        Open the DMG, drag Clash of Rust into Applications and launch it once from there. It configures PATH for your account. Open a new login shell to run cor.

        The app is not notarized by Apple, so macOS stops it the first time. Allow it under Privacy & Security as Apple describes.

        Android

        Android 8.0 or later

          Most phones and tablets take the ARM64 package. Android will ask you to let your browser or file manager install apps. On the first connection, allow the VPN request.

          You can add a quick-settings tile for the switch. Giving individual apps their own exit needs Android 10 or later.

          Verify SHA256

          Compare your local hash with the installer's .sha256 file. Install when they match.

          # Windows PowerShell
Get-FileHash .\the-file-name.exe -Algorithm SHA256

# Linux
sha256sum downloaded-package

# macOS
shasum -a 256 the-file-name.dmg

          The app verifies the checksum before installing an update. On Fedora and openSUSE, install the new RPM with your package manager.

          After installing

          Choose GUI, TUI or CLI in the quick start to add a subscription, select a node and connect. Each interface has its own manual for daily use.

          Questions people ask

          Is there an iOS version?

          No. The repository has an interface prototype for iOS and nothing you can install.

          Which Linux distributions are tested?

          Version 0.7.3 passed basic proxy and TUN checks on Ubuntu, Debian, Linux Mint, Pop!_OS, Zorin OS, Fedora, openSUSE and Arch Linux. Each version's release notes describe what was tested.

          Do the Linux packages work without a desktop?

          Yes. They include cor, which needs no display. Run cor start and use TUN on a server.

          Will an update lose my settings?

          No. Upgrades keep subscriptions and personal settings. The Windows uninstaller can delete all data if you ask it to; that option is off by default.
