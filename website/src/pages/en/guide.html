From the installer to your first connection

A working guide to the parts you will use most. The app's own labels are in Chinese, so they appear here as written, with a translation beside them.

First connection

Install the package for your system from the download page. The installer already contains the mihomo core and Geo data, so the only thing you need to bring is a subscription link or a local configuration file.

  1. Open 订阅 (Subscriptions) and add the link from your provider, or import a YAML file.
  2. Choose 使用 (Use) on that subscription. Until you do, the client runs on a built-in profile that sends everything direct.
  3. Open 代理 (Proxies), test the nodes and pick one.
  4. On 首页 (Home), choose a mode, 规则 (Rule), 全局 (Global) or 直连 (Direct), and how traffic is captured: 系统代理 (System proxy) or TUN.
  5. Connect. The first time you use TUN, the system may ask for permission. On Android, allow the VPN request.

Closing the window does not stop anything. The interface process exits, the tray and the core keep running, and the window opens again from the tray.

Subscriptions

Clash of Rust reads mihomo / Clash Meta YAML. It does not convert other formats. If a link returns share links, a Base64 list, or a sing-box or Xray configuration, the client says the format is not compatible and leaves your current subscription alone. Ask your provider for the Mihomo or Clash Meta link.

  • Remote subscriptions refresh automatically every 360 minutes. Set the interval anywhere from 0 to 10,080 minutes in settings; 0 turns it off.
  • Local files can be renamed and removed but are never refreshed automatically.
  • If a download or validation fails, the saved subscription and the running state stay as they were.
  • While Claude protection is on, both scheduled and manual updates wait.
$ cor profile add home 'https://example.com/subscription'
$ cor profile list
$ cor profile update --all
$ cor config set subscription_update_interval_minutes 720

Nodes and modes

Nodes appear as a grid or a compact list. Test them, filter by name, and select one inside any group that allows manual selection. The tray menu can switch nodes and show the current speed without opening the window.

ModeWhat it does
规则 RuleEach connection is matched against the rules, which decide whether it goes through a node, straight out, or nowhere.
全局 GlobalEverything leaves through the node selected in the GLOBAL group.
直连 DirectEverything goes straight out. Nothing is proxied.
CaptureWhat it does
系统代理 System proxySets the operating system's proxy. Programs that respect that setting go through the client.
TUNCreates a virtual network device and captures traffic at the network layer, including programs that ignore the system proxy. Recommended on servers.

In rule mode the node shown on the home page is the current choice of the default rule. Another rule may send a particular connection elsewhere; the 连接 (Connections) page shows the rule and route each connection really used.

Rules

The rules that come with a subscription are read-only, though you can change their order. Your own rules can be added, edited, switched off, moved and removed. A change is saved only after mihomo accepts the resulting configuration, and the subscription's original YAML is never rewritten.

Quick rules

Five switches for common cases. They are off by default and only add what the subscription does not already have.

adsReject advertising domains
private-domainSend private and local domains direct
private-ipSend private IP ranges direct
cn-domainSend mainland China domains direct
cn-ipSend mainland China IP ranges direct
 
$ cor rule add 'DOMAIN-SUFFIX,example.com,DIRECT' --position 1
$ cor rule shortcut ads on
$ cor rule list --filter example
$ cor network explain example.com   # which rule did it match?

Android per-app routing

In settings, open 应用分流 (Per-app routing) to decide which apps enter the VPN.

ModeSelected appsOther apps
All appsEnter the VPNEnter the VPN
Only selectedEnter the VPNUse the system network
Exclude selectedUse the system networkEnter the VPN
  • Entering the VPN does not force an app through a proxy node. The current mode and rules still decide where its traffic goes.
  • On Android 10 and later you can also give an app its own exit: direct, a policy group or one node. Android 8 and 9 offer the three modes above only.
  • Save while connected and the client asks to rebuild the VPN so the change takes effect.
  • If Android's own "Block connections without VPN" switch is on, it can still block the apps you left outside.

Full behaviour: android-application-routing.md (in Chinese).

Access checks

Three pages under 工具 (Tools) answer three different questions.

网络诊断
Network diagnostics		Why does this one site not connect? Eleven on-demand checks, described on the network tools page.
IP 检测
IP check		What does the outside world see? Your exit IP, and whether GitHub, AI services and streaming sites answer through the current node. Results are grouped by category and can be filtered, re-run and exported.
A÷检测
A÷ check		Would Claude see anything unusual? Gathers clues about region, DNS, WebRTC and project configuration into one report.

A finished check means the observation was made, not that the service is available. Read the report itself: a failed item is recorded as failed and is never counted as reachable.

$ cor ip-check list
$ cor ip-check --category AI -o ai-report.json
$ cor claude check

Claude protection

Protection is for the moments when you need one fixed exit and do not want a stray click or a stray connection to change it. It is off by default and lives on the A÷ check page.

When you switch it on

  • The current node is pinned, and priority rules route Claude-related traffic through it.
  • TUN, strict routing, IPv6 and UDP handling and DNS takeover are enabled, with DNS sent over encrypted DoH through the same node.
  • Connections that would go around the pinned node are blocked as they happen. Existing connections in the core are closed first.
  • Changing node, mode or network settings is locked. Themes, accent colour and read-only pages still work.
  • Subscription updates pause. On Android, per-app exits pause and the VPN covers all apps.

When you switch it off

Your original mode, capture method and node selection return. Your subscription, rules and DNS, IPv6 and UDP preferences were never rewritten, only overridden.

The confirm button waits three seconds before it can be pressed. In global mode, if the selected chain ends in a direct exit, protection refuses to start.

$ cor claude protect on --yes
$ cor claude watch          # observe real routes and blocked requests
$ cor claude protect off --yes

Detection offers clues; it cannot promise that a third-party service will accept you. Scope and limits: claude-protection.md (in Chinese).

Command line

cor is included in the desktop installers for Windows, Linux and macOS. It needs no display and shares the backend and core with the window: if the window is running, cor talks to it; if not, commands that need a backend start one without a window.

SystemWhere cor is
Debian / Ubuntu/usr/bin/cor, on your PATH after installing the DEB
Windowscor.exe in the install folder, for example C:\Program Files\Clash of Rust\cor.exe. Add the folder to PATH if you use it often.
macOS/Applications/Clash of Rust.app/Contents/MacOS/cor. Link it into a folder on your PATH if you like.

A first session

$ cor profile add home 'https://example.com/subscription'
$ cor profile use home
$ cor start              # background; survives closing the terminal
$ cor node select        # type to filter, pick by number, q to cancel
$ cor proxy tun
$ cor status
$ cor stop               # stop the core and restore the network

Use cor start for daily use. cor run stays in the foreground and stops when the terminal closes; it is meant for debugging.

cor help lists the everyday commands, cor help all lists everything, and every command accepts --help.

For scripts

  • --json prints one machine-readable result; --jsonl prints one line per sample for status, logs and connections. Each line is wrapped as {"schema":1,"command":"…","data":…}.
  • Results go to stdout. Progress, permission prompts and errors go to stderr.
  • Secrets are hidden unless you pass --show-secrets. Destructive commands need --yes.
  • --timeout N sets the wait for one backend request in seconds: 300 by default, 3,600 at most.
Exit codeMeaning

1The operation, a validation or a permission failed
2The command or its arguments are malformed
3The backend failed to start or cannot be reached

130The query was interrupted

Terminal interface

cor ui opens a keyboard-driven interface with four pages: home, nodes, connections and network checks. It is a prototype. Editing subscriptions, rules, updates and most settings still belong to the commands above. cor ui --demo shows it with made-up data and touches nothing.

KeyAction
1 2 3 4 TabSwitch between home, nodes, connections and network
↑ ↓Move through a list
EnterOpen a group; choose a member, then confirm to switch
/Search, or type a target on the network page
EscGo back, clear the search or cancel
rRead again now
q Ctrl+CLeave. The backend and the proxy stay as they are.

It needs a real terminal of at least 60 columns by 18 rows. Opening, browsing and leaving never start a backend or change the proxy; if nothing is running, it asks you to run cor start first.

Updates and start at login

The app checks for updates on the channel you chose, stable by default, and shows download progress with a way to cancel. An installer is verified against its SHA256 before it runs. Upgrading keeps your subscriptions and settings. On Android the system confirms the install.

$ cor update check
$ cor update download -o update.deb   # download and verify, do not install
$ cor update install --yes
$ cor geo update                      # refresh Geo data

Start at login

Choose one of the two, not both.

  • Desktop app: turn on 后台自启动 (start in background) in settings, or run cor autostart on. After you sign in, the backend and your saved network mode come back; the window stays closed until you open it.
  • Command line only: cor service install --yes registers the backend for your user account. It is a per-user login item, not a system service that runs before sign-in.

When something goes wrong

"Subscription format not compatible"The link returned something other than mihomo YAML. Get the Mihomo or Clash Meta link from your provider.
One site will not openRun the website check, then rule and exit.
Windows Defender raises an alertCompare the file with its SHA256 first, then read the alert notes. Do not wave through an alert you cannot explain.
macOS will not open the appThe DMG is not notarized by Apple. Follow Apple's steps to allow it in Privacy & Security.
cor says the backend is not runningRun cor start. Read-only commands such as status and node list never start it for you.

Send a useful report

The window has an 导出诊断 (Export diagnostics) button next to errors and results. From a terminal:

$ cor diagnose --output cor-diagnose.json
$ cor diagnose --offline -o cor-offline.json   # collect without touching the network

Reports are never uploaded for you. Subscription credentials and the controller secret are left out, but logs can contain domains and IP addresses, so read a report before you attach it to an issue.

Before you uninstall

If you set up the command-line login item with a custom data folder, run cor stop and cor service remove --yes first. The Windows uninstaller offers to delete all configuration and data; that box is unticked by default.
