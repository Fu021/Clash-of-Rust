Your first connection

  1. Install the app. Open Subscriptions and add a mihomo / Clash Meta link or import YAML.
  2. Choose Use on the subscription, then test and select a node under Proxies.
  3. Return home, choose rule, global or direct mode, then connect. TUN needs system authorization; Android asks for VPN permission.

CLI equivalent

cor profile add home 'https://example.com/subscription'
cor profile use home
cor start
cor node select
{{shot:home}}

On desktop, the tray and core keep running after the window closes. Leaving the Android interface does not stop the VPN.

Subscriptions

Remote subscriptions can refresh on a schedule. Local files can be renamed, edited or removed. Failed downloads keep the existing configuration; built-in Default Direct cannot be edited or removed.

The interval is in minutes: 360 by default, 0 to disable, up to 10080. Updates pause during Claude protection.

CLI equivalent

cor profile list
cor profile update --all
cor config set subscription_update_interval_minutes 720
{{shot:subscriptions}}

Nodes and modes

Search, test latency and switch between grid and list. Selectors allow manual choices; automatic groups such as AUTO are managed by the core.

  • Rule: each connection follows its matching rule.
  • Global: uses the GLOBAL group.
  • Direct: skips proxy nodes.

System proxy handles apps that follow proxy settings; TUN takes over at the network layer. Connections shows the rule and actual path of each connection.

CLI equivalent

cor node select
cor mode rule
cor proxy tun
cor connection list
{{shot:nodes}}

Rules

Quick rules at the top right cover ads, private networks and direct access to mainland China. They start off and add only rules missing from the subscription.

Edit, disable and reorder your own rules; subscription rules stay read-only. Changes are validated before saving, without rewriting the source YAML.

CLI equivalent

cor rule shortcut ads on
cor rule add 'DOMAIN-SUFFIX,example.com,DIRECT' --position 1
cor network explain example.com
{{shot:rules}}

Android app routing

Open Settings → App routing. Choose which apps enter the VPN, search by name or package, review the selection and save. While connected, choose Save and reconnect.

On Android 10+, use App rules to name a rule group, find apps and assign a node, policy group, DIRECT or REJECT. Missing exits are blocked by default. Unassigned apps follow the current mode and rules.

Access checks

Network diagnostics checks DNS, connections and the actual exit. IP check shows your exit IP and service reachability. A÷ check collects Claude-related region and configuration clues. Finishing a check does not prove a service works: read each result.

Claude protection

Enable it on A÷ check to pin a specific node, apply strict TUN and encrypted DNS, and monitor for bypasses. Existing core connections are closed when it starts.

Network changes such as nodes, rules and updates are locked. Themes, accents and read-only pages remain available. Disabling restores your mode, node and network preferences. Protection constrains connections; it cannot guarantee a service will accept them.

CLI equivalent

cor claude protect on --yes
cor claude watch
cor claude protect off --yes
{{shot:protection}}

Open the terminal interface

Windows, Linux and macOS installers include cor. Run cor ui in an interactive terminal of at least 60 columns × 18 rows.

Opening, browsing and exiting do not start a backend or change the proxy. Add a subscription and run cor start first. GUI, TUI and CLI then share that backend.

Launch and demo

cor start
cor ui
cor ui --demo

--demo uses fictional data, without network access or saving.

CLI and automation

Use cor help for common commands, or cor help all for every entry. Read-only queries do not start the core. Add --json for machines or --jsonl for streaming output.

cor status
cor --json node list
cor --json connection list
cor service status

Results go to stdout; progress and errors go to stderr. GUI, TUI, scripts and AI use the same business logic and permissions. All commands and exit codes ↗

Updates and autostart

Choose stable or preview in Settings and set the check interval; 0 disables automatic checks. SHA256 is verified before installation. Upgrades keep your configuration; Android confirms installation.

Enable Background autostart on desktop to start at login with the window closed. CLI users can install a user service instead. Choose one autostart method.

CLI equivalent

cor update check
cor update install
cor geo update
cor service install --yes

Export diagnostics

In the GUI, export from Logs or an error notice. TUI users can exit and run these commands. Reports are not uploaded automatically; review domains and IP addresses before sharing.

cor diagnose --output cor-diagnose.json
cor diagnose --offline --output cor-offline.json

For an unreachable site, start with Website check, then Rule and exit. For installation, see the download FAQ.
