Window · GUI

Available on Windows, Linux, macOS and Android.

  1. Download and install the package for your device, then open Clash of Rust.
  2. Open Subscriptions and choose Import. Enter a name and subscription URL, or use the file picker to import YAML. Then choose Use to activate the subscription. The app does not provide proxy servers.
  3. Open Proxies, test latency and choose a member of a manual policy group. Automatic groups such as AUTO select their own member.
  4. Return Home, choose Rule mode and connect. Desktop supports system proxy or TUN; Android uses a VPN. Approve the operating system's request when prompted.
  5. Check that the core is running, then inspect traffic in Connections. Use Network diagnostics if a site does not open. On Android phones, both pages are usually under Tools.
{{shot:home}}

Phones and tablets use bottom navigation or a sidebar. Resolve any existing Android VPN conflict first. On desktop, closing the window leaves the tray running; choosing Quit ends the client.

Terminal · TUI

Desktop installers include cor. Run it in an interactive terminal. Cannot find cor?

cor
  1. Press 8 for Commands, find profile add, fill in a name and subscription URL or local path, then review and confirm.
  2. Press 3 for Profiles, select the new profile and press Enter to open its form. Save and confirm, then choose Start backend and core on Home.
  3. Press 2 for Nodes, open a manual policy group with Enter, choose a member and confirm.
  4. On Home, select Proxy mode and confirm System proxy or TUN. Use TUN on a headless server. When system authorization is required, it opens in the normal terminal. Press Enter afterwards to return.
  5. Press 1 to check status. q exits the interface while the backend and proxy keep running.

Commands · CLI

For scripts, SSH and AI. Locate cor using the installation notes, then replace the example URL with your subscription.

cor profile add home 'https://example.com/subscription'
cor profile use home
cor start
cor node select
cor proxy tun
cor status

The interactive picker accepts text filters, numbers and q to cancel. TUN may require administrator authorization; desktop users can also choose cor proxy system. Use start for everyday background operation.

Need help?

Cannot connect

Check the selected profile, node reachability and system permission. Find recovery options.

One site fails

Start with the website check, then inspect rules and exit.

An update fails

Keep your configuration, resolve the reported cause and retry, or download an installer.

On desktop, the GUI, TUI and CLI share the backend and configuration for the same account and data directory.
