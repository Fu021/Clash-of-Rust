打开与退出

cor ui
cor ui --demo

Windows、Linux、macOS 安装包附带 cor。需要真实交互终端，最小 60 列 × 18 行；太小时显示调整提示。演示模式使用虚构数据，不联网、不保存。

打开、浏览和退出不自行启动后台或内核。没有后台时可在“操作”页启动；q / Ctrl+C 退出后，既有后台和代理继续运行。终端字体决定 emoji 是否可见。

通用按键

按键用途
1–6 / Tab切换页面；表单内 Tab 选择下一项。
↑ / ↓ / Enter选择项目，打开详情或编辑；执行前确认。
/ / Ctrl+U开始搜索或输入；清空输入。
Esc / 退格返回组列表、清除搜索或取消确认。
r立即重试读取。
q / Ctrl+C退出 TUI，恢复终端显示。

输入字段时，页面快捷键按普通文本处理。可使用 --no-color 或 NO_COLOR 关闭颜色。

六个页面

1 · 首页
内核与后台状态、订阅、参考策略链、保护、速率和连接数。
2 · 节点
搜索策略组与节点，查看延迟，在手动组中确认选择。
3 · 连接
筛选活动连接，查看详情并进入关闭连接操作。
4 · 网络
按需选择工具、填写目标、运行并查看当前结果。
5 · 设置
查看设置值，编辑可修改项，检查后提交。
6 · 操作
通过命令目录生成的表单管理订阅、规则、更新、服务等。

只读取当前页所需数据，每秒采样，绘制只更新变化行；不积累连接或命令输出历史。

节点选择

按 2，搜索并打开手动策略组，选择成员后再次确认。名称中的空格、emoji 和标点原样保留；自动组只显示内核当前选择，不能手动改其成员。

等待确认期间若订阅、成员或保护状态改变，提交会重新校验。上级手动组选择 AUTO 后，AUTO 内部正常换节点不会误判目标消失。

开发中，尚未随已发布版本提供：节点页按 l 选延迟升序，按 n 选名称排序；页面显示当前状态并保存选择。

连接详情

按 3 选中连接后回车，查看域名、目标 IP/端口、协议、时间、规则、实际线路和流量。d 补充解析详情，x 打开关闭连接确认。

连接已消失时会说明原 ID 已不可用，不把其他连接替换进详情。关闭后，原应用可能自动重新连接。

网络工具

按 4，用 [ / ] 切换工具。/ 输入目标，回车结束输入，再按回车运行；↑ / ↓ 滚动结果，Esc 取消。

设置表单

按 5，回车编辑可修改项；只读项查看完整值。代理、订阅、规则和保护使用各自的专用操作。密钥不显示、不回填。

草稿不写盘。选“检查并执行”后再次回车才提交；取消本项恢复编辑前内容，退出表单丢弃草稿。后台仍会校验数值、权限与当前状态。

操作与授权

按 6 搜索操作，例如 profile add、rule add、update install、service status。位置参数与选项分别填写，字段内不需要 shell 引号；数组使用 JSON，布尔选项填 true 或留空。

确认后暂时回到普通终端，显示结果、下载进度或系统授权，不跳过确认与系统权限。完成后按 Enter 返回；安装完成或交接后退出 TUI，以释放需要被替换的程序。

授权或持续命令期间 Ctrl+C 会退出整个 CLI，已提交操作仍以实际状态为准。前台调试 run 和再次打开 ui 不放入表单。

保护与只读

Claude 保护期间可导航、查看状态、读取报告和修改纯外观。订阅、节点、规则、更新、Geo、自启动等网络修改继续锁定，表单不另设权限后门。

读取失败时旧快照标为参考，不能据此提交。打开 TUI 不会通过测速或浏览隐式启动停止的内核。

故障恢复

先按 r 重读状态；终端太小时扩大窗口。不能恢复时退出，用独立的诊断导出，沿用原账户和数据目录。

TUI 不依赖固定颜色或屏幕坐标。自动化优先使用CLI JSON 与退出码。完整终端行为见权威说明 ↗。
