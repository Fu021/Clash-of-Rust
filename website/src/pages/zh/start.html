窗口 GUI

Windows、Linux、macOS 和 Android 均可使用。

  1. 下载并安装对应设备的安装包，打开 Clash of Rust。
  2. 进入“订阅”点“导入”，填写名称和订阅地址，或用本地文件入口选择 YAML。导入后点“使用”切换订阅。软件不提供代理节点。
  3. 进入“代理”，测速后在手动策略组中选择节点；AUTO 等自动组由内核选优。
  4. 回到首页，选“规则”模式并连接。桌面可选系统代理或 TUN；Android 使用 VPN。首次接管时按系统提示授权。
  5. 确认首页显示内核运行，到“连接”查看实际流量；网站打不开时再用“网络诊断”。Android 手机通常从“工具”进入这两页。
{{shot:home}}

手机和平板的入口在底栏或侧栏。Android 若已有其他 VPN，需先处理系统的 VPN 冲突；桌面关闭窗口后由托盘继续管理，选择“退出”才结束客户端。

终端 TUI

桌面安装包附带 cor，在交互终端中运行。找不到 cor？

cor
  1. 按 8 进入“操作”，搜索 profile add，填写名称和订阅链接或本地文件路径，检查并确认执行。
  2. 按 3 进入“订阅”，选中刚添加的订阅，回车打开表单，保存并确认。回首页选择“启动后台与内核”。
  3. 按 2 进入节点页，选中手动策略组后按 Enter，选择成员并确认。
  4. 在首页选择“代理方式”，选系统代理或 TUN 并确认。无桌面环境的服务器选 TUN。需要系统授权时会切回普通终端，完成后按 Enter 返回。
  5. 按 1 核对状态；q 只退出终端界面，后台与代理继续运行。

命令行 CLI

适合脚本、SSH 和 AI。先按安装说明找到 cor，将示例链接替换为自己的订阅。

cor profile add home 'https://example.com/subscription'
cor profile use home
cor start
cor node select
cor proxy tun
cor status

交互选择支持文字筛选、编号和 q 取消。TUN 可能请求管理员授权；有桌面环境也可使用 cor proxy system。日常后台运行用 start。

连接不顺？

还没连上

确认订阅已选用、节点可达、系统授权已完成。查看恢复入口。

某个网站打不开

先做网站检查，再查规则与出口。

更新或安装失败

保留原配置，按错误原因重试；需要时手动下载安装包。

桌面 GUI、TUI、CLI 共用当前账户和数据目录的后台与配置，可随时切换。
