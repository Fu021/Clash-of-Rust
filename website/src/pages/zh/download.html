Windows

x64 与 ARM64

    运行安装程序，按提示完成。覆盖安装旧版本时，订阅和个人设置都会保留。

    Defender 告警时先核对 SHA256，再按告警说明处理。

    Debian / Ubuntu

    Ubuntu 20.04 及以上

      在保存文件的目录里运行 sudo apt install ./安装包文件名.deb。装完之后，终端里就有 cor 命令。

      不确定架构？运行 dpkg --print-architecture 就能看到。

      macOS

      macOS 14 及以上

        打开 DMG，把 Clash of Rust 拖进“应用程序”，再从那里启动。

        应用没有经过 Apple 公证，第一次打开会被系统拦下。按 Apple 的说明，在“隐私与安全性”里放行。

        Android

        Android 8.0 及以上

          多数手机和平板选 ARM64。安装时，系统会要求你允许浏览器或文件管理器安装应用；第一次连接时，允许 VPN 请求。

          可以在快捷设置里添加开关磁贴。给单个应用指定出口，需要 Android 10 及以上。

          核对 SHA256

          将本机计算的哈希与安装包旁的 .sha256 文件比较，一致后安装。

          # Windows PowerShell
Get-FileHash .\安装包文件名.exe -Algorithm SHA256

# Linux
sha256sum 安装包文件名.deb

# macOS
shasum -a 256 安装包文件名.dmg

          应用内更新时，客户端也会先做同样的校验，再安装。

          装好之后

          从快速上手选择 GUI、TUI 或 CLI，完成添加订阅、选择节点与首次连接。日常操作见各自的功能手册。

          常见问题

          正式版和预发布版，选哪个？

          日常使用选正式版。预发布版先带上新功能，目前是网络工具箱和终端界面，验证范围比正式版小。试用之前请备份配置；桌面端可以在应用里切回正式版。

          有 iOS 版吗？

          没有。仓库里只有 iOS 的界面原型，不提供可以安装的包。

          其他 Linux 发行版能用吗？

          目前只发布 DEB 包，验证范围是 Debian 和 Ubuntu 20.04 及以上。其他发行版需要自己从源码构建，见仓库里的开发文档。

          没有桌面环境的 Linux 能用吗？

          能。DEB 包里带有 cor，它不需要显示器。运行 cor start，服务器上建议用 TUN。

          升级会丢设置吗？

          不会。升级保留订阅和个人设置。Windows 的卸载程序可以选择删除全部数据，这一项默认不勾选。
