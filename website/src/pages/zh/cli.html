找到 cor

桌面安装包已附带内核、Geo 与 CLI，不需要额外安装运行时。Android 不提供这个桌面命令行。

系统入口
Debian / Ubuntu安装 DEB 后运行 cor，路径为 /usr/bin/cor。
Windows运行安装目录下的 cor.exe，或自行将该目录加入 PATH。
macOS/Applications/Clash of Rust.app/Contents/MacOS/cor，可自建 PATH 符号链接。
cor version
cor help
cor help all
cor help profile add

每条命令支持 --help。当前文档针对最新预发布版；旧安装包缺少命令时先核对版本。

后台与代理

cor start
cor status
cor mode rule
cor proxy tun
cor restart
cor stop

start 在后台运行，关闭终端仍继续；run 是依赖当前终端的前台调试入口。代理可选 system、tun、off，模式可选 rule、global、direct。

GUI 已运行时复用同一后台。status、节点列表、连接查询、服务状态、帮助与版本不会启动后台或内核。TUN 沿用系统授权，--yes 不代替管理员许可。

cor env --shell bash 只输出代理环境变量语句，不修改父终端；以 --unset 生成清除语句。完整运行边界见运行说明 ↗。

订阅

cor profile add home 'https://example.com/subscription'
cor profile use home
cor profile list
cor profile update --all
cor profile import ./subscription.yaml --name local
cor profile export home --output profile.yaml
cor profile remove local --yes

用完整 ID 或唯一名称定位订阅；重名使用 ID。支持本地路径或标准输入导入。更新失败保留原配置；全部更新有失败项时返回非零，其他成功项正常保存。

默认隐藏凭据，完整备份须显式加 --show-secrets 并妥善保存。内置默认直连不可删除；删除当前订阅会切回默认直连。元数据编辑与原文件边界见订阅说明 ↗。

节点与策略链

cor node list
cor node select
cor node select PROXY '🇺🇸 US 01'
cor node test --group PROXY
cor node test --all

示例组名和节点名要替换为订阅中的真实名称。交互支持筛选、编号、/ 清除、q 或 EOF 取消；需要已运行的内核。脚本和 JSON 必须提供 GROUP NODE，含空格的值用 shell 引号。

离线列表读取已保存订阅，标记 offline=true 与 source=saved_profile，不冒充实时选择或测速。status 的规则参考链如 PROXY → AUTO → 节点，不代表每个连接；实际出口看连接详情。

规则

cor rule list --json
cor rule add 'DOMAIN-SUFFIX,example.com,DIRECT' --position 1
cor rule shortcut ads on

自定义规则可编辑、移动、开关或删除；脚本使用列表返回的稳定 ID。位置从 1 开始，保存前校验重复和内核配置。订阅原规则只读，原始 YAML 不被重写。

快捷规则为 ads、private-domain、private-ip、cn-domain、cn-ip，默认关闭。--profile 可指定订阅。

连接与日志

cor connection list
cor connection show CONNECTION_ID
cor --jsonl connection list --watch --sort download-rate
cor logs --follow

将 CONNECTION_ID 换成列表里的真实 ID。查询不启动内核；停止时单次连接列表为空并标记离线，详情和持续查询会说明不可用。关闭连接用 cor connection close CONNECTION_ID，原应用可能重连。

节点、连接与规则列表支持 --limit、--offset；默认 100，最大 10000，先筛选排序再分页。日志可能含域名和 IP，分享前检查。

检测与 Claude 保护

cor network check example.com
cor network explain example.com --json
cor network tls example.com --output tls-report.json
cor ip-check --category AI --output ai-report.json
cor claude protect on --yes
cor claude protect off --yes

完整工具、参数和报告状态见网络工具。检查不隐式启动内核，不把失败改成直连成功；保护开启或状态未知时禁止可能绕过保护的系统探针。

保护固定节点和严格 TUN，锁定网络修改，外观及只读操作可用；关闭后恢复原设置。它不保证第三方服务接受请求。

环境与浏览器检查

cor claude check --output claude-report.json
cor claude audit --offline --output claude-projects.json
cor claude browser --open --output browser-report.json
cor claude watch

check 查看网络和地区线索；audit --offline 读取当前终端及已记录项目的配置，不发起检测请求。browser --open 打开本机采样页，需要真实浏览器参与；SSH 中没有浏览器时不伪造结果。这些检查不读取账户 Cookie 或登录令牌。

watch 持续观察保护接管状态和相关连接，按 Ctrl+C 结束查询。检测完成的退出码为 0 只代表执行完成，可用性与风险仍看报告字段。

配置

cor config get
cor config set theme_mode dark
cor config set subscription_update_interval_minutes 720
cor config set update_check_interval_minutes 0

订阅和更新间隔单位为分钟，0 关闭，默认 360，最大 10080。纯 CLI 后台不额外启动软件自动检查任务。字段清单与可写范围由 cor help config set 提供；修改仍经共享校验。

cor config check
cor config effective --output effective.yaml

check 校验实际合并配置，effective 导出包含覆盖项的运行 YAML，默认移除凭据；不会改写原订阅。完整敏感内容仅在显式使用 --show-secrets 时提供。

同一账户默认与 GUI 共用数据。--data-dir、--resources 指定独立目录与资源；查询、更新和诊断要沿用原参数。Linux root 可用 --user 显式选择用户，TUN 不因此变成用户隔离网络。

软件与 Geo 更新

cor update check
cor update install
cor update status
cor geo status
cor geo update

默认只检查正式版；cor config set update_prereleases true 纳入更高版本预发布。确认前显示实际目标，仅预发布目标附风险提示。安装与 Geo 都先校验，失败保留恢复信息。

Linux 无窗口时在当前终端授权、等待安装并自动恢复后台；--no-start 保留原内核开关状态。其他桌面交给系统安装助手，助手启动不等于安装成功。用 update status 查看实际结果。

无人值守可用 cor update download --output cor-update.deb 下载后交管理员安装，按平台换文件名。慢网可用 --timeout N 延长等待，默认 300 秒、最大 3600。

自启与服务

cor service install --yes
cor service status
cor service remove --yes

为当前用户配置登录后 CLI 后台自启，当前会话仍用 start。Linux 使用 systemd 用户单元，macOS 使用 LaunchAgent，Windows 使用当前用户登录任务。不是登录前的系统服务。

状态区分已配置、已启用、运行中和后台归属；未观测到的值保持未确认。autostart on 管理的是桌面后台自启，建议与 CLI 服务二选一。移除自启不停止当前内核。

脚本与退出码

cor --json status
cor --json node list
cor --jsonl status --watch

JSON 外层包含 schema、command、data。结果写 stdout，进度、授权和错误写 stderr。--json 与 --jsonl 二选一，后者适合持续采样。

退出码含义
0成功或下游管道关闭；检测可用性仍看报告字段。
1操作、校验或权限失败。
2命令或参数格式错误。
3后台启动失败或不可达。
124请求超时。
130查询被中断。

completion bash、zsh、fish、powershell 输出补全脚本；--no-color 输出纯文本。AI 优先读取 JSON 和退出码，不猜屏幕坐标。

诊断导出

cor diagnose --output cor-diagnose.json
cor diagnose --offline --output cor-offline.json

诊断不会启动后台或恢复 TUN；后台不可达时仍可导出离线报告。沿用原账户、--user、--data-dir 与 --resources。报告不自动上传，分享前检查域名、IP 及日志。

系统权限、用户隔离、全部参数见CLI 权威说明 ↗。控制密钥只用于本机接口，不应分享 control.json。
