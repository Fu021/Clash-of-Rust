首页与连接

首页展示内核运行状态、当前订阅、参考节点、流量与网络信息。连接按钮启停内核；切换代理方式决定哪些程序的连接进入内核。

  • 系统代理：接管遵守系统代理设置的程序；终端和部分应用可能不使用它。
  • TUN：从网络层接管，桌面首次使用需要系统授权；Android 由系统确认 VPN。
  • 关闭：停止当前实例的系统代理或 TUN 接管，不代表其他 VPN 也已关闭。
{{shot:home}}

首页延迟属于服务检查，节点延迟属于测速目标，不能直接比较。参考节点也不是所有连接的实际出口，到“连接”页核对逐条线路。

订阅

添加远程链接或导入本地 YAML，保存后点“使用”才切换当前订阅。远程订阅可更新来源；本地订阅可编辑、改名或删除，删除不会移除用户原文件。

下载或校验失败保留原订阅与运行状态。删除正在使用的订阅会回到“默认直连”；内置默认直连不可编辑或删除。

{{shot:subscriptions}}

支持搜索、宫格与列表。手机将部分操作收在详情里。自动更新间隔见计划任务；Claude 保护期间暂停订阅修改和更新。

节点与模式

在“代理”页搜索、测速，并切换宫格或紧凑列表。手动组可以选择成员，AUTO 等自动组由内核选择。详情展示节点资料和可用操作。

{{shot:nodes}}

测速是指定目标的连通性与耗时，不代表带宽。超时不等于节点已被删除。节点全部失败时保留当前模式，并提供排错入口；更新下载有独立的恢复路径。

规则

“快捷规则”提供广告拦截、私有网络及国内直连等选项，默认关闭，只补充订阅缺少的规则。自定义规则可新增、编辑、停用、删除和排序。

规则按顺序匹配，先命中的生效。订阅原规则保持只读，可调整顺序；修改通过内核校验后保存，不改写原始 YAML。重复的启用规则会被拒绝。

{{shot:rules}}

规则模式下 Android 指定应用出口优先于普通规则；全局、直连和 Claude 保护期间暂停应用出口规则。想核对某个网址，使用规则与出口。

Android 应用分流

设置 → 应用分流，先决定哪些应用进入 VPN。按名称或包名搜索，可筛选已选应用与系统应用；“全部应用”不显示选择列表。

范围选中的应用其余应用

给应用指定出口

Android 10+ 的“应用规则”可建立命名规则组，筛选应用，选择节点、策略组、DIRECT 或 REJECT。规则跟随订阅保存；切换订阅不把旧出口套到新节点上。Android 8/9 仍可设置 VPN 范围，但不支持指定出口。

默认勾选“目标失效时阻止连接”。目标消失或身份改变时，真实连接被拦截才产生可恢复警告；单纯测速超时不是目标失效。取消该选项则跟随普通配置。应用未进入 VPN 时，指定出口不生效。

保存与恢复

连接中使用“保存并重连”，系统接受新 VPN 后才替换原连接；失败时保留原连接。普通模式遵守 UDP 开关，不支持 UDP 的出口会拦截对应 UDP，不偷偷换线路。

Claude 保护期间覆盖全部应用，暂停指定出口并锁定修改，关闭后恢复。系统“阻止不使用 VPN 的连接”可能拦住 VPN 范围外的应用。完整边界说明 ↗

连接与日志

连接页显示当前活动连接，可筛选并查看域名、目标、协议、命中规则、策略链与流量。详情支持复制和关闭连接；关闭后应用可能重新发起请求。

日志页可查看、清空消息或导出诊断。日志、域名和 IP 可能包含个人信息，分享前检查。

检测与工具

“IP 检测”查看出口与服务可达性；“A÷检测”汇总 Claude 地区、DNS 与配置线索；“网络诊断”从网站检查到 DNS、TLS 和实际出口逐步排查。

{{shot:network}}

工具按需运行，只保留当前结果，切页取消并清空。HTTP 有响应不等于能登录。各工具的输入、参数、报告状态和保护限制见网络工具手册。

Claude 保护

在 A÷检测页开启，固定具体节点，启用严格 TUN、加密 DNS 和实时拦截；开启前关闭已有内核连接。没有 IPv6 上联不视为绕行。

{{shot:protection}}

节点、规则、订阅、更新、Geo、自启动和计划任务等网络修改锁定；主题、强调色、字号和只读浏览仍可用。保护暂停 Android 应用出口并临时接管 UDP，关闭后恢复原偏好。

保护状态持久保存，重启后恢复。可随时通过原入口关闭；它约束连接，不保证第三方服务接受请求。保护范围与操作权限 ↗

设置与计划任务

常规与外观提供窗口大小、托盘速度、主题、强调色和字号；网络提供端口、IPv6、UDP、DNS 和 Fake-IP。网络修改可能重载内核，按界面反馈确认实际生效。

订阅自动更新、自动检查软件更新以分钟设置，默认 360，填 0 关闭，最大 10080。保护期间暂停相关任务；手动检查更新不受自动间隔限制。

Fake-IP 排除项使用独立编辑入口，不需要修改原订阅。手机、平板与桌面尽量保持相同的字段，空间不足时操作收进详情。

更新与自启动

设置 → 更新，默认只检查正式版，开启“包含预发布版本”后才纳入更高版本的预发布。安装前验证 SHA256；Android 还需系统确认，不能降回低版本安装包。

Geo 更新校验整组数据后替换，失败保留原数据。遇到下载、权限或安装失败，先按可恢复提示处理，也可手动下载，不要删除配置。

桌面开启“后台自启动”后，登录时保持窗口关闭；若托盘最终不可用，才打开窗口提示。CLI 用户服务是另一种自启方式，二者选一种。Android VPN 由前台服务维持，不等同于桌面登录自启。

错误与恢复

普通通知会自动消失；可恢复警告提供重试或导出；严重错误说明阻塞原因；Claude 保护告警独立显示。取消提示不会修复原因。

从“日志”页或错误提示导出诊断，记录发生时间和操作步骤。报告不会自动上传；分享前检查域名、IP 等信息。内核启动失败时保留现场，用恢复入口重试。

网站问题先查网站检查，安装问题见常见问题。无界面时可用独立的CLI 诊断。
