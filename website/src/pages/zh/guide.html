第一次连接

  1. 安装客户端，打开“订阅”，添加 mihomo / Clash Meta 格式的链接或导入 YAML。
  2. 在订阅上点“使用”，再到“代理”页测速、选择节点。
  3. 回到首页，选择规则、全局或直连模式，再连接。TUN 首次使用需要系统授权，Android 需允许 VPN。

对应 CLI

cor profile add home 'https://example.com/subscription'
cor profile use home
cor start
cor node select
{{shot:home}}

桌面关闭窗口后，托盘与内核继续运行；Android 离开界面也不会停止 VPN。

订阅

远程订阅可定时更新，本地配置可改名、编辑或删除。下载失败会保留原配置；内置“默认直连”不可编辑或删除。

设置中的自动更新间隔以分钟计，默认 360，填 0 关闭，最大 10080。Claude 保护期间暂停更新。

对应 CLI

cor profile list
cor profile update --all
cor config set subscription_update_interval_minutes 720
{{shot:subscriptions}}

节点与模式

代理页支持搜索、测速及宫格 / 列表切换。手动策略组可选节点；AUTO 等自动组由内核选择。

  • 规则：按每条连接匹配的规则选择出口。
  • 全局：使用 GLOBAL 策略组。
  • 直连：不经过代理节点。

系统代理接管遵守代理设置的程序；TUN 在网络层接管。连接页显示每条连接的实际规则与线路。

对应 CLI

cor node select
cor mode rule
cor proxy tun
cor connection list
{{shot:nodes}}

规则

右上角“快捷规则”提供广告拦截、私有网络及国内直连。默认关闭，只补充订阅中缺少的规则。

自定义规则可编辑、停用和排序；订阅原有规则保持只读。修改校验通过后保存，不改写原始 YAML。

对应 CLI

cor rule shortcut ads on
cor rule add 'DOMAIN-SUFFIX,example.com,DIRECT' --position 1
cor network explain example.com
{{shot:rules}}

Android 应用分流

设置 → 应用分流，先选哪些应用进入 VPN。搜索名称或包名，核对已选列表，再保存；已连接时用“保存并重连”。

模式选中的应用其余应用
全部应用进入 VPN进入 VPN
仅选中进入 VPN使用原有网络
排除选中使用原有网络进入 VPN
{{shot:applications}}

Android 10+ 可在“应用规则”中命名规则组、筛选应用，并指定节点、策略组、DIRECT 或 REJECT；默认拦截失效出口。未指定出口的应用仍遵循当前模式和规则。

Claude 保护期间覆盖全部应用，暂停应用指定出口，关闭后恢复。系统若启用“阻止不使用 VPN 的连接”，VPN 外的应用也可能被拦住。完整分流说明 ↗

访问检测

“网络诊断”排查解析、连接与实际出口；“IP 检测”查看出口 IP 和服务可达性；“A÷检测”汇总 Claude 相关地区与配置线索。完成检查不代表服务一定可用，结论以逐项结果为准。

{{shot:network}}

查看全部网络工具

Claude 保护

在 A÷检测页开启，固定具体节点，启用严格 TUN、加密 DNS 和实时拦截。开启前会关闭现有内核连接。

节点、规则、更新等网络修改会锁定；主题、强调色与只读浏览仍可用。关闭后恢复原模式、节点与网络偏好。保护提供连接约束，不保证第三方服务接受请求。

对应 CLI

cor claude protect on --yes
cor claude watch
cor claude protect off --yes
{{shot:protection}}

打开终端界面

Windows、Linux、macOS 安装包附带 cor。安装后运行 cor ui；需要交互终端，最小 60 列 × 18 行。

打开、浏览和退出不会启动后台或改变代理。首次使用先添加订阅并执行 cor start，之后 GUI、TUI 和 CLI 管理同一后台。

启动与演示

cor start
cor ui
cor ui --demo

--demo 使用虚构数据，不联网、不保存。

{{terminal:home}}

查状态、选节点

按键操作
1–4 / Tab首页、节点、连接、网络
↑ / ↓ / Enter选择条目、打开策略组，确认后切换节点
/ / Esc输入搜索；返回、清除或取消
r / q刷新 / 退出，保留后台和代理

网络页用 [ / ] 切换工具，/ 输入目标，Enter 运行；切页清除结果。需要自定义参数时使用旁边的 CLI 命令。

同一套网络检查

cor network check example.com
cor network stability example.com --count 10

设置与管理

当前预发布版提供上面四页。源码中的 TUI 已增加“设置”和“操作”两页，尚未发布；请勿把源码功能当作当前安装包功能。

新版使用 5 / 6 进入设置和操作，表单复用 CLI 校验及系统授权，执行前确认。当前安装包可直接使用 cor config、cor profile、cor rule 等命令。

两种入口都遵守 Claude 保护。源码 TUI 操作说明 ↗

CLI 与脚本

cor help 找常用命令，cor help all 看全部入口。只读查询不会启动内核；需要机器读取时加 --json，持续观察用 --jsonl。

cor status
cor --json node list
cor --json connection list
cor service status

结果写入 stdout，进度与错误写入 stderr。GUI、TUI、脚本和 AI 共用业务与权限。完整命令与退出码 ↗

更新与自启动

设置中选择正式版或预发布版，调整检查间隔；填 0 关闭自动检查。安装前校验 SHA256，升级保留订阅和设置，Android 由系统确认安装。

桌面打开“后台自启动”，登录后保持窗口关闭。纯命令行可用用户服务，两种自启方式选一种。

对应 CLI

cor update check
cor update install
cor geo update
cor service install --yes

导出诊断

GUI 从“日志”页或错误提示导出；TUI 用户可退出后运行下列命令。报告不自动上传，分享前检查域名、IP 等信息。

cor diagnose --output cor-diagnose.json
cor diagnose --offline --output cor-offline.json

网站打不开，先做网站检查，再查规则与出口；安装问题见下载页常见问题。
